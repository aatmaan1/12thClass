### Q1 — दो विषमतलीय रेखाओं के बीच न्यूनतम दूरी

**चारों अवयव पहचानिए:**

```
      a₁ = î + 2ĵ + k̂          b₁ = î − ĵ + k̂
      a₂ = 2î − ĵ − k̂          b₂ = 2î + ĵ + 2k̂
```

**जाँच:** क्या वे समांतर हैं? (1, −1, 1) तथा (2, 1, 2) समानुपाती नहीं हैं, अतः रेखाएँ **समांतर नहीं** हैं
— विषमतलीय सूत्र का उपयोग कीजिए।

**a₂ − a₁ निकालिए:**

```
      a₂ − a₁ = (2 − 1)î + (−1 − 2)ĵ + (−1 − 1)k̂ = î − 3ĵ − 2k̂
```

**b₁ × b₂ निकालिए:**

```
                | î   ĵ   k̂ |
      b₁ × b₂ = | 1  −1   1 |
                | 2   1   2 |

              = î[(−1)(2) − (1)(1)] − ĵ[(1)(2) − (1)(2)] + k̂[(1)(1) − (−1)(2)]
              = î(−2 − 1) − ĵ(2 − 2) + k̂(1 + 2)
              = −3î + 0ĵ + 3k̂
```

```
      |b₁ × b₂| = √(9 + 0 + 9) = √18 = 3√2
```

**अंश निकालिए:**

```
      (b₁ × b₂) · (a₂ − a₁) = (−3)(1) + (0)(−3) + (3)(−2) = −3 + 0 − 6 = −9
```

**सूत्र लगाइए:**

```
      d = |−9| / (3√2) = 9/(3√2) = 3/√2 = (3√2)/2
```

```
न्यूनतम दूरी = 3/√2 = 3√2/2 इकाई          ≈ 2.12 इकाई
```

*(चूँकि d ≠ 0, अतः रेखाएँ वास्तव में विषमतलीय हैं — वे न मिलती हैं न समांतर हैं।)*

### Q4 — P(1, 6, 3) से लंब का पाद

रेखा x/1 = (y − 1)/2 = (z − 2)/3 है, अतः वह (0, 1, 2) से जाती है और उसके दिक्-अनुपात **b** = (1, 2, 3)
हैं।

**चरण 1 — रेखा पर व्यापक बिंदु Q।** प्रत्येक अनुपात को λ के बराबर रखिए:

```
      Q = (λ, 2λ + 1, 3λ + 2)
```

**चरण 2 — सदिश PQ:**

```
      PQ = Q − P = (λ − 1, 2λ + 1 − 6, 3λ + 2 − 3) = (λ − 1, 2λ − 5, 3λ − 1)
```

**चरण 3 — PQ ⊥ b लगाइए, अर्थात् PQ · b = 0:**

```
      (λ − 1)(1) + (2λ − 5)(2) + (3λ − 1)(3) = 0
⟹     λ − 1 + 4λ − 10 + 9λ − 3 = 0
⟹     14λ − 14 = 0
⟹     λ = 1
```

**चरण 4 — वापस रखिए:**

```
      Q = (1, 2(1) + 1, 3(1) + 2) = (1, 3, 5)
```

**लंब का पाद (1, 3, 5) है।**

**चरण 5 — लंब की लंबाई:**

```
      PQ = (1 − 1, 3 − 6, 5 − 3) = (0, −3, 2)

      |PQ| = √(0 + 9 + 4) = √13
```

**लंब की लंबाई √13 इकाई है।**

### Q5 — उसी रेखा में (1, 6, 3) का प्रतिबिंब

Q4 से लंब का पाद **Q(1, 3, 5)** है।

Q, P(1, 6, 3) तथा उसके प्रतिबिंब P′(x′, y′, z′) का **मध्यबिंदु** है। अतः

```
      (1 + x′)/2 = 1   ⟹   x′ = 1
      (6 + y′)/2 = 3   ⟹   y′ = 0
      (3 + z′)/2 = 5   ⟹   z′ = 7
```

*(समकक्ष रूप से P′ = 2Q − P = (2 − 1, 6 − 6, 10 − 3) = (1, 0, 7)।)*

**रेखा में (1, 6, 3) का प्रतिबिंब (1, 0, 7) है।**

*जाँच:* (1, 6, 3) तथा (1, 0, 7) का मध्यबिंदु (1, 3, 5) = Q ✓

### Q6 — दिखाइए कि रेखाएँ प्रतिच्छेद करती हैं, और बिंदु ज्ञात कीजिए

**रेखा 1 पर व्यापक बिंदु** (प्रत्येक अनुपात को λ के बराबर रखकर):

```
      P₁ = (2λ + 1, 3λ + 2, 4λ + 3)
```

**रेखा 2 पर व्यापक बिंदु** (प्रत्येक अनुपात को μ के बराबर रखकर):

```
      P₂ = (5μ + 4, 2μ + 1, μ)
```

**यदि रेखाएँ प्रतिच्छेद करती हैं, तो किसी λ तथा μ के लिए P₁ = P₂।** निर्देशांक बराबर रखने पर:

```
      2λ + 1 = 5μ + 4          …(i)
      3λ + 2 = 2μ + 1          …(ii)
      4λ + 3 = μ               …(iii)
```

**(ii) तथा (iii) हल कीजिए।** (iii) से μ को (ii) में रखिए:

```
      3λ + 2 = 2(4λ + 3) + 1
⟹     3λ + 2 = 8λ + 7
⟹     −5λ = 5
⟹     λ = −1
```

तब (iii) से: μ = 4(−1) + 3 = **−1**।

**(i) में सत्यापन** — यह चरण अनिवार्य है:

```
      बायाँ पक्ष = 2(−1) + 1 = −1
      दायाँ पक्ष = 5(−1) + 4 = −1          ✓
```

तीनों समीकरण संतुष्ट हैं, अतः **रेखाएँ प्रतिच्छेद करती हैं**।

**प्रतिच्छेद बिंदु** (λ = −1 को P₁ में रखने पर):

```
      (2(−1) + 1, 3(−1) + 2, 4(−1) + 3) = (−1, −1, −1)
```

**रेखाएँ (−1, −1, −1) पर प्रतिच्छेद करती हैं।**

*μ = −1 पर P₂ से जाँच: (5(−1) + 4, 2(−1) + 1, −1) = (−1, −1, −1) ✓*

### Q11 — (x − 3)/2 = (2y − 1)/4 = z की दिक्-अनुपात

मध्य पद मानक रूप में नहीं है — y का गुणांक 1 होना चाहिए। फिर से लिखिए:

```
      (2y − 1)/4 = 2(y − ½)/4 = (y − ½)/2
```

अतः रेखा है

```
      (x − 3)/2 = (y − ½)/2 = (z − 0)/1
```

जिससे दिक्-अनुपात **(2, 2, 1)** मिलते हैं।

**उत्तर: (b) (2, 2, 1)**

> यह एक प्रिय जाल है। दिक्-अनुपात पढ़ने से पहले सदैव इस प्रकार सामान्यीकृत कीजिए कि प्रत्येक कोष्ठक के
> भीतर x, y तथा z का गुणांक 1 हो।
