### Q1 — दो थैलियाँ, लाल गेंद निकली, कौन-सी थैली?

**चरण 1 — घटनाएँ परिभाषित कीजिए।**

```
      E₁ : गेंद थैली I से निकाली गई
      E₂ : गेंद थैली II से निकाली गई
      R  : निकाली गई गेंद लाल है
```

**चरण 2 — पूर्व प्रायिकताएँ।** दोनों थैलियों में से एक यादृच्छिक रूप से चुनी जाती है, अतः

```
      P(E₁) = 1/2          P(E₂) = 1/2
```

**चरण 3 — सप्रतिबंध प्रायिकताएँ।**

```
      थैली I  : (3 + 4) = 7 गेंदों में 3 लाल    ⟹   P(R|E₁) = 3/7
      थैली II : (5 + 6) = 11 गेंदों में 5 लाल   ⟹   P(R|E₂) = 5/11
```

**चरण 4 — बेज़ प्रमेय।**

```
                        P(E₂) P(R|E₂)
      P(E₂|R) = ───────────────────────────────
                 P(E₁)P(R|E₁) + P(E₂)P(R|E₂)
```

**चरण 5 — मान रखिए।**

```
                     (1/2)(5/11)
      P(E₂|R) = ──────────────────────────
                 (1/2)(3/7) + (1/2)(5/11)
```

(1/2) पूरे में कट जाता है:

```
                    5/11
      P(E₂|R) = ─────────────
                 3/7 + 5/11
```

```
      3/7 + 5/11 = (33 + 35)/77 = 68/77
```

```
      P(E₂|R) = (5/11) × (77/68) = (5 × 7)/68 = 35/68
```

```
P(गेंद थैली II से आई | वह लाल है) = 35/68          ≈ 0.515
```

*(संगति जाँच: थैली II का लाल अंश (5/11 ≈ 0.455) थैली I के (3/7 ≈ 0.429) से थोड़ा अधिक है, और आरंभ में
दोनों थैलियाँ समान संभावना की थीं, अतः थैली II की पश्चवर्ती प्रायिकता ½ से थोड़ी ऊपर आनी चाहिए। वैसा ही
है: 35/68 ≈ 0.515 ✓)*

### Q2 — तीन मशीनें, खराब वस्तु, कौन-सी मशीन?

**चरण 1 — घटनाएँ परिभाषित कीजिए।**

```
      E₁ : वस्तु मशीन A ने बनाई
      E₂ : वस्तु मशीन B ने बनाई
      E₃ : वस्तु मशीन C ने बनाई
      D  : वस्तु खराब है
```

**चरण 2 — पूर्व प्रायिकताएँ।**

```
      P(E₁) = 0.25          P(E₂) = 0.35          P(E₃) = 0.40
```

**चरण 3 — सप्रतिबंध प्रायिकताएँ।**

```
      P(D|E₁) = 0.05        P(D|E₂) = 0.04        P(D|E₃) = 0.02
```

**चरण 4 — बेज़ प्रमेय।**

```
                            P(E₃) P(D|E₃)
      P(E₃|D) = ───────────────────────────────────────────
                 P(E₁)P(D|E₁) + P(E₂)P(D|E₂) + P(E₃)P(D|E₃)
```

**चरण 5 — मान रखिए।**

```
      P(E₁)P(D|E₁) = 0.25 × 0.05 = 0.0125
      P(E₂)P(D|E₂) = 0.35 × 0.04 = 0.0140
      P(E₃)P(D|E₃) = 0.40 × 0.02 = 0.0080
                                   ────────
      हर           =               0.0345
```

*(प्रसंगवश ध्यान दें: 0.0345, P(D) है — कुल खराबी दर — और यही कुल प्रायिकता प्रमेय है, जो अक्सर अलग भाग
के रूप में पूछी जाती है।)*

```
      P(E₃|D) = 0.0080 / 0.0345 = 80/345 = 16/69
```

```
P(मशीन C | खराब) = 16/69          ≈ 0.232
```

### Q3 — पासा दो बार, योग 6, क्या 4 आया?

**घटनाएँ परिभाषित कीजिए।**

```
      A : अंक 4 कम-से-कम एक बार आता है
      B : दोनों अंकों का योग 6 है
```

**B की सूची।** योग 6 वाले परिणाम:

```
      (1,5), (2,4), (3,3), (4,2), (5,1)          →  n(B) = 5
```

**A ∩ B की सूची।** इनमें से किनमें 4 है?

```
      (2,4), (4,2)                                →  n(A ∩ B) = 2
```

**गणना।** सभी 36 परिणाम समसंभाव्य हैं, अतः

```
      P(B) = 5/36          P(A ∩ B) = 2/36
```

```
      P(A|B) = P(A ∩ B)/P(B) = (2/36)/(5/36) = 2/5
```

```
P(4 कम-से-कम एक बार आया | योग 6 है) = 2/5
```

> योग 6 वाले पाँच परिणामों तक सीमित हो जाने के बाद उत्तर केवल "5 में से 2" है। इस प्रकार के प्रश्न के लिए
> घटे हुए प्रतिदर्श समष्टि की स्पष्ट सूची बनाना सबसे तेज़ और सुरक्षित विधि है।

### Q4 — स्वतंत्र घटनाएँ, P(A ∪ B)

```
      P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
```

चूँकि A तथा B **स्वतंत्र** हैं, अतः P(A ∩ B) = P(A)·P(B) = (0.3)(0.4) = 0.12।

```
      P(A ∪ B) = 0.3 + 0.4 − 0.12 = 0.58
```

### Q5 — इक्कों की संख्या का प्रायिकता बंटन (प्रतिस्थापन के साथ)

मान लीजिए X = निकाले गए इक्कों की संख्या। चूँकि निकालना **प्रतिस्थापन के साथ** है, अतः दोनों निकालने
स्वतंत्र हैं, और प्रत्येक बार

```
      P(इक्का) = 4/52 = 1/13          P(इक्का नहीं) = 12/13
```

X के मान 0, 1 या 2 हो सकते हैं।

```
      P(X = 0) = (12/13)(12/13) = 144/169

      P(X = 1) = (1/13)(12/13) + (12/13)(1/13) = 24/169      [पहले इक्का, या दूसरे इक्का]

      P(X = 2) = (1/13)(1/13) = 1/169
```

**प्रायिकता बंटन:**

| X | 0 | 1 | 2 |
| --- | --- | --- | --- |
| P(X) | 144/169 | 24/169 | 1/169 |

**जाँच:** (144 + 24 + 1)/169 = 169/169 = 1 ✓

**माध्य:**

```
      E(X) = Σ xᵢ pᵢ = 0(144/169) + 1(24/169) + 2(1/169)
           = (0 + 24 + 2)/169
           = 26/169
           = 2/13
```

```
माध्य = 2/13          ≈ 0.154
```

*(संगत: प्रत्येक बार इक्का 1/13 प्रायिकता से मिलता है, और दो बार निकाला जाता है, अतः औसतन 2/13 इक्के।)*

### Q6 — गेंदें जोड़े जाने वाला कलश

**घटनाएँ परिभाषित कीजिए।**

```
      R₁ : पहली निकाली गेंद लाल है          B₁ : पहली निकाली गेंद काली है
      R₂ : दूसरी निकाली गेंद लाल है
```

**पूर्व प्रायिकताएँ।** कलश में आरंभ में 5 लाल और 5 काली, अतः 10 गेंदें:

```
      P(R₁) = 5/10 = 1/2          P(B₁) = 5/10 = 1/2
```

**सप्रतिबंध प्रायिकताएँ।** निकाली गई गेंद लौटा दी जाती है, **और उसी रंग की 2 और डाल दी जाती हैं**, अतः तब
कलश में 12 गेंदें होती हैं।

```
      यदि R₁ हुआ: 5 + 2 = 7 लाल और 5 काली    ⟹   P(R₂|R₁) = 7/12
      यदि B₁ हुआ: 5 लाल और 5 + 2 = 7 काली    ⟹   P(R₂|B₁) = 5/12
```

**कुल प्रायिकता प्रमेय लगाइए:**

```
      P(R₂) = P(R₁)P(R₂|R₁) + P(B₁)P(R₂|B₁)
            = (1/2)(7/12) + (1/2)(5/12)
            = (7 + 5)/24
            = 12/24
```

```
P(दूसरी गेंद लाल है) = 1/2
```

> सुंदर परिणाम: निकाले गए रंग की गेंदें जोड़ने से अगली गेंद के लाल होने की प्रायिकता नहीं बदलती, क्योंकि
> कलश आरंभ में सममित था। इसे टिप्पणी के रूप में लिखना चाहिए — यह समझ दर्शाता है।

### Q9 — प्रतिस्थापन के बिना तीन बादशाह

**घटनाएँ परिभाषित कीजिए।**

```
      K₁ : पहला पत्ता बादशाह है
      K₂ : दूसरा पत्ता बादशाह है
      K₃ : तीसरा पत्ता बादशाह है
```

चूँकि निकालना **प्रतिस्थापन के बिना** है, अतः तीन घटनाओं के लिए गुणन प्रमेय का उपयोग कीजिए:

```
      P(K₁ ∩ K₂ ∩ K₃) = P(K₁) · P(K₂|K₁) · P(K₃|K₁ ∩ K₂)
```

```
      P(K₁) = 4/52                        [52 पत्तों में 4 बादशाह]
      P(K₂|K₁) = 3/51                     [51 पत्तों में 3 बादशाह शेष]
      P(K₃|K₁ ∩ K₂) = 2/50                [50 पत्तों में 2 बादशाह शेष]
```

```
      P = (4/52)(3/51)(2/50) = 24/132600 = 1/5525
```

```
P(तीनों पत्ते बादशाह हैं) = 1/5525          ≈ 0.000181
```

### Q10 — प्रकरण अध्ययन: बाएँ हाथ से लिखने वाले विद्यार्थी

**घटनाएँ परिभाषित कीजिए।**

```
      G : विद्यार्थी लड़की है          B : विद्यार्थी लड़का है
      L : विद्यार्थी बाएँ हाथ से लिखता है
```

```
      P(G) = 0.40          P(B) = 0.60
      P(L|G) = 0.05        P(L|B) = 0.08
```

**(i) P(L) — कुल प्रायिकता प्रमेय से:**

```
      P(L) = P(G)P(L|G) + P(B)P(L|B)
           = (0.40)(0.05) + (0.60)(0.08)
           = 0.020 + 0.048
           = 0.068
```

**P(विद्यार्थी बाएँ हाथ से लिखता है) = 0.068 = 17/250**

**(ii) P(G|L) — बेज़ प्रमेय से:**

```
                  P(G)P(L|G)          0.020
      P(G|L) = ──────────────── = ───────────── = 20/68 = 5/17
                     P(L)              0.068
```

**P(विद्यार्थी लड़की है | बाएँ हाथ से लिखता है) = 5/17 ≈ 0.294**

**(iii)** भाग (i) में **कुल प्रायिकता प्रमेय** का उपयोग है; भाग (ii) में **बेज़ प्रमेय** का।

*(ध्यान दीजिए कि 5/17 ≈ 0.294, P(G) = 0.40 से काफ़ी कम है — यह जानने से कि विद्यार्थी बाएँ हाथ से लिखता

### Q11 — k तथा माध्य ज्ञात करना

**Σpᵢ = 1 का उपयोग कीजिए:**

```
      k + 2k + 3k + 4k = 1
⟹     10k = 1
⟹     k = 1/10
```

**बंटन:**

| X | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| P(X) | 1/10 | 2/10 | 3/10 | 4/10 |

**माध्य:**

```
      E(X) = 0(1/10) + 1(2/10) + 2(3/10) + 3(4/10)
           = (0 + 2 + 6 + 12)/10
           = 20/10
           = 2
```

```
k = 1/10 तथा माध्य = 2
```

### Q12 — अभिकथन–कारण

**A:** "शून्येतर प्रायिकताओं वाली परस्पर अपवर्जी घटनाएँ स्वतंत्र नहीं हो सकतीं।" **सत्य।**
परस्पर अपवर्जी होने पर P(A ∩ B) = 0। यदि वे स्वतंत्र भी होतीं, तो P(A ∩ B) = P(A)P(B) होता, जिससे
P(A)P(B) = 0 अनिवार्य हो जाता — और यह दोनों के शून्येतर होने के विरुद्ध है।

**R:** "परस्पर अपवर्जी घटनाओं के लिए P(A ∩ B) = 0।" **सत्य** — यही परिभाषा है।

**क्या R, A को समझाता है?** हाँ — A सीधे R और स्वतंत्रता की शर्त को मिलाकर निकलता है।

**उत्तर: (a) A तथा R दोनों सत्य हैं, और R, A का सही स्पष्टीकरण है।**
