### Q1 — R पर a ≤ b³

**स्वतुल्य?** हमें *प्रत्येक* वास्तविक a के लिए a ≤ a³ चाहिए। a = 1/2 लीजिए। तब a³ = 1/8, और
1/2 ≤ 1/8 **असत्य** है। अतः R **स्वतुल्य नहीं** है।

**सममित?** (1, 2) लीजिए: 1 ≤ 2³ = 8 ✓, अतः (1, 2) ∈ R। अब (2, 1): क्या 2 ≤ 1³ = 1? **नहीं**।
अतः (2, 1) ∉ R। इसलिए R **सममित नहीं** है।

**संक्रामक?** a = 3, b = 3/2, c = 6/5 लीजिए।
- (3, 3/2): 3 ≤ (3/2)³ = 27/8 = 3.375 ✓
- (3/2, 6/5): 1.5 ≤ (6/5)³ = 216/125 = 1.728 ✓
- (3, 6/5): 3 ≤ 1.728? **नहीं**

अतः (3, 3/2) ∈ R तथा (3/2, 6/5) ∈ R पर (3, 6/5) ∉ R। इसलिए R **संक्रामक नहीं** है।

**R न स्वतुल्य है, न सममित, न संक्रामक।**

> ध्यान दीजिए कि प्रत्येक भाग एक सुविचारित प्रति-उदाहरण से तय हो जाता है। 0 और 1 के बीच की भिन्नें घन को
> तोड़ देती हैं; यह बात जेब में रखिए।

### Q2 — {1,2,3,4,5} पर |a − b| सम

**स्वतुल्य:** किसी भी a ∈ A के लिए |a − a| = 0, जो सम है। अतः सभी a के लिए (a, a) ∈ R। ✓

**सममित:** मान लीजिए (a, b) ∈ R, अतः |a − b| सम है। चूँकि |b − a| = |a − b|, अतः |b − a| भी सम है,
इसलिए (b, a) ∈ R। ✓

**संक्रामक:** मान लीजिए (a, b) ∈ R तथा (b, c) ∈ R, अतः |a − b| और |b − c| दोनों सम हैं।
|a − b| सम होने का अर्थ है a और b की **समता (parity) समान** है (दोनों विषम या दोनों सम)। इसी प्रकार b और c
की समता समान है। अतः a और c की समता समान है, इसलिए |a − c| सम है, अर्थात् (a, c) ∈ R। ✓

तीनों सत्य हैं, अतः **R एक तुल्यता संबंध है**।

**1 से संबंधित अवयव:** हमें ऐसे a ∈ A चाहिए जिनके लिए |1 − a| सम हो, अर्थात् a विषम हो।

**[1] = {1, 3, 5}**

### Q3 — f(x) = 4x/(3x + 4) एकैकी आच्छादक है

**एकैकी।** मान लीजिए x₁, x₂ ∈ **R** − {−4/3} के लिए f(x₁) = f(x₂)।

```
      4x₁/(3x₁ + 4) = 4x₂/(3x₂ + 4)
⟹     x₁(3x₂ + 4)   = x₂(3x₁ + 4)          [तिर्यक गुणा, 4 से भाग]
⟹     3x₁x₂ + 4x₁   = 3x₁x₂ + 4x₂
⟹     4x₁ = 4x₂
⟹     x₁ = x₂
```

अतः f **एकैकी** है।

**आच्छादक।** मान लीजिए y ∈ **R** − {4/3} कोई भी है। y = 4x/(3x + 4) को x के लिए हल कीजिए:

```
      y(3x + 4) = 4x
⟹     3xy + 4y = 4x
⟹     x(3y − 4) = −4y
⟹     x = −4y/(3y − 4) = 4y/(4 − 3y)
```

यह x सुपरिभाषित है क्योंकि y ≠ 4/3 (अतः 4 − 3y ≠ 0)।

हमें यह भी जाँचना है कि x **प्रांत** में है, अर्थात् x ≠ −4/3। मान लीजिए वह होता:

```
      4y/(4 − 3y) = −4/3
⟹     12y = −4(4 − 3y) = −16 + 12y
⟹     0 = −16,  विरोधाभास
```

अतः x ≠ −4/3, अर्थात् x ∈ **R** − {−4/3}, और रचना से f(x) = y।

अतः सहप्रांत के प्रत्येक y का पूर्वप्रतिबिंब है, इसलिए f **आच्छादक** है।

**f एकैकी तथा आच्छादक है, अतः एकैकी आच्छादक है।**

> जो चरण अधिकांश विद्यार्थी छोड़ देते हैं वह x ≠ −4/3 की जाँच है। वह एक अंक का है, क्योंकि "आच्छादक" के
> लिए पूर्वप्रतिबिंब का **दिए गए प्रांत** में होना आवश्यक है — प्रांत में छिद्र इसी कारण किया गया था।

### Q4 — N × N पर (a, b) R (c, d) ⟺ ad = bc

**स्वतुल्य:** (a, b) R (a, b) के लिए ab = ba चाहिए, जो सभी प्राकृत संख्याओं के लिए सत्य है। ✓

**सममित:** मान लीजिए (a, b) R (c, d), अतः ad = bc। तब cb = da (वही समीकरण पुनर्व्यवस्थित), जो ठीक
(c, d) R (a, b) की शर्त है। ✓

**संक्रामक:** मान लीजिए (a, b) R (c, d) तथा (c, d) R (e, f), अतः

```
ad = bc    …(i)
cf = de    …(ii)
```

(i) को f से और (ii) को b से गुणा कीजिए:

```
adf = bcf        तथा        bcf = bde
⟹ adf = bde
⟹ d(af) = d(be)
```

चूँकि d ∈ **N**, अतः d ≠ 0, इसलिए हम उसे काट सकते हैं: **af = be**, जो (a, b) R (e, f) की शर्त है। ✓

तीनों सत्य हैं, अतः **R एक तुल्यता संबंध है**।

> संक्रामकता को a/b = c/d लिखने के बजाय गुणा से करने से कोई भाग नहीं आता और तर्क वैध रहता है — अधिक
> स्वच्छ, और यदि प्रश्न **Z** × (**Z** − {0}) पर पूछा जाए तो भी चलता है।

### Q5 — {1,2,3} पर (1,2) तथा (2,1) वाले तुल्यता संबंधों की संख्या

तुल्यता संबंध ठीक एक विभाजन के संगत होता है। चूँकि (1, 2) ∈ R, अतः अवयव 1 और 2 एक ही वर्ग में होने चाहिए।
इससे केवल दो संभव विभाजन बचते हैं:

1. {1, 2}, {3} → R = {(1,1),(2,2),(3,3),(1,2),(2,1)}
2. {1, 2, 3} → R = A × A (सार्वत्रिक संबंध)

**उत्तर: (b) 2**

### Q6 — f(x) = x/(x² + 1) न एकैकी है न आच्छादक

**एकैकी नहीं।** f(2) = 2/(4 + 1) = 2/5। और f(1/2) = (1/2)/((1/4) + 1) = (1/2)/(5/4) = 2/5।

अतः f(2) = f(1/2) पर 2 ≠ 1/2। इसलिए f **एकैकी नहीं** है।

> व्यापक रूप से इस फलन के लिए f(x) = f(1/x) — ध्यान देने योग्य उपयोगी बात, क्योंकि इससे किसी भी x के लिए
> प्रति-उदाहरण मिल जाता है।

**आच्छादक नहीं।** परिसर ज्ञात कीजिए। मान लीजिए y = x/(x² + 1)। तब

```
      yx² − x + y = 0
```

स्थिति y = 0: इससे x = 0 मिलता है, अतः 0 परिसर में है।

स्थिति y ≠ 0: यह x में द्विघात है, और x वास्तविक होना चाहिए, अतः विविक्तकर ≥ 0 होना चाहिए:

```
      (−1)² − 4(y)(y) ≥ 0
⟹     1 − 4y² ≥ 0
⟹     y² ≤ 1/4
⟹     −1/2 ≤ y ≤ 1/2
```

अतः f का परिसर [−1/2, 1/2] है, जो सहप्रांत **R** के बराबर **नहीं** है। इसलिए f **आच्छादक नहीं** है।

### Q7 — f : N → N, f(x) = x²

**एकैकी:** मान लीजिए f(x₁) = f(x₂), अतः x₁² = x₂², जिससे x₁ = ±x₂। चूँकि x₁, x₂ ∈ **N** धनात्मक हैं, अतः
x₁ = x₂। इसलिए f **एकैकी है**।

**आच्छादक:** सहप्रांत **N** में y = 2 पर विचार कीजिए। हमें ऐसा x ∈ **N** चाहिए जिसके लिए x² = 2, अर्थात्
x = √2 ∉ **N**। अतः 2 का कोई पूर्वप्रतिबिंब नहीं है, और f **आच्छादक नहीं** है।

*(तुलना: वही नियम f(x) = x², **R** → **R** पर न एकैकी है न आच्छादक, क्योंकि f(−1) = f(1) और कोई ऋणात्मक
संख्या वर्ग नहीं है। प्रांत और सहप्रांत प्रश्न का भाग हैं।)*

### Q8 — स्वतुल्य और सममित पर संक्रामक नहीं, (1,2) तथा (1,3) सहित

प्रतिबंधों से R बनाइए:

- (1, 2) तथा (1, 3) हैं — दिया गया।
- **स्वतुल्यता** से (1, 1), (2, 2), (3, 3) ∈ R अनिवार्य।
- **सममितता** से (2, 1) तथा (3, 1) ∈ R अनिवार्य।

अब तक R में {(1,1),(2,2),(3,3),(1,2),(2,1),(1,3),(3,1)} होना चाहिए।

अब (2, 1) ∈ R तथा (1, 3) ∈ R। यदि R संक्रामक होता तो (2, 3) ∈ R चाहिए होता। R को संक्रामक **न** बनाने के
लिए हमें (2, 3) छोड़ना होगा — और सममितता से (3, 2) भी। A × A में बचे हुए केवल ये दो युग्म थे, अतः ठीक एक
ऐसा संबंध है:

```
R = {(1,1), (2,2), (3,3), (1,2), (2,1), (1,3), (3,1)}
```

**उत्तर: 1**

### Q9 — रेखाओं की लंबवतता

**स्वतुल्य नहीं:** कोई रेखा l अपने ही लंबवत नहीं होती, अतः (l, l) ∉ R। ✗

**सममित:** यदि l₁ ⊥ l₂ तो l₂ ⊥ l₁ (लंबवतता परस्पर संबंध है)। ✓

**संक्रामक नहीं:** l₁ : y = 0 (x-अक्ष), l₂ : x = 0 (y-अक्ष), l₃ : y = 5 लीजिए।
तब l₁ ⊥ l₂ तथा l₂ ⊥ l₃, पर l₁ ∥ l₃, अतः l₁, l₃ के लंबवत **नहीं** है। ✗

अतः R **सममित है पर न स्वतुल्य है न संक्रामक**।

### Q10 — प्रकरण अध्ययन

**(i)** R = {(x, y) : x तथा y एक ही सदन में हैं}।
- *स्वतुल्य:* प्रत्येक विद्यार्थी अपने ही साथ एक ही सदन में है। ✓
- *सममित:* यदि x, y के साथ एक ही सदन में है, तो y भी x के साथ एक ही सदन में है। ✓
- *संक्रामक:* यदि x, y एक सदन में हैं और y, z एक सदन में हैं, तो चूँकि y ठीक एक सदन का है, x, y, z सब उसी
  सदन में हैं, अतः x और z एक ही सदन में हैं। ✓

अतः R एक **तुल्यता संबंध** है।

**(ii)** तुल्यता वर्ग ठीक सदन ही हैं। अतः **4** तुल्यता वर्ग हैं।

**(iii)** R′ = {(x, y) : x का अनुक्रमांक < y का अनुक्रमांक}।
- *स्वतुल्य:* नहीं — कोई अनुक्रमांक अपने से छोटा नहीं होता। ✗
- *सममित:* नहीं — यदि x का अनुक्रमांक y से छोटा है, तो y का x से छोटा नहीं है। ✗
- *संक्रामक:* हाँ — यदि a < b और b < c तो a < c। ✓

अतः R′ **केवल संक्रामक** है।
