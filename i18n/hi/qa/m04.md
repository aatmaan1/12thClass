### Q1 — आव्यूह विधि से हल

**चरण 1. AX = B लिखिए।**

```
A = [ 2   3   3 ]      X = [ x ]      B = [  5 ]
    [ 1  −2   1 ]          [ y ]          [ −4 ]
    [ 3  −1  −2 ]          [ z ]          [  3 ]
```

**चरण 2. |A| निकालिए,** पंक्ति 1 के अनुदिश प्रसार करते हुए:

```
|A| = 2[(−2)(−2) − (1)(−1)] − 3[(1)(−2) − (1)(3)] + 3[(1)(−1) − (−2)(3)]
    = 2[4 + 1] − 3[−2 − 3] + 3[−1 + 6]
    = 2(5) − 3(−5) + 3(5)
    = 10 + 15 + 15
    = 40
```

चूँकि **|A| = 40 ≠ 0**, अतः A⁻¹ विद्यमान है और निकाय का **अद्वितीय हल** है।

**चरण 3. सहखंड।**

```
A₁₁ = +[(−2)(−2) − (1)(−1)]  = 4 + 1   =  5
A₁₂ = −[(1)(−2)  − (1)(3)]   = −(−5)   =  5
A₁₃ = +[(1)(−1)  − (−2)(3)]  = −1 + 6  =  5

A₂₁ = −[(3)(−2)  − (3)(−1)]  = −(−3)   =  3
A₂₂ = +[(2)(−2)  − (3)(3)]   = −4 − 9  = −13
A₂₃ = −[(2)(−1)  − (3)(3)]   = −(−11)  =  11

A₃₁ = +[(3)(1)   − (3)(−2)]  = 3 + 6   =  9
A₃₂ = −[(2)(1)   − (3)(1)]   = −(−1)   =  1
A₃₃ = +[(2)(−2)  − (3)(1)]   = −4 − 3  = −7
```

**चरण 4. adj A** = सहखंड आव्यूह का परिवर्त:

```
सहखंड आव्यूह = [  5    5    5 ]
               [  3  −13   11 ]
               [  9    1   −7 ]
```

उसका परिवर्त लेने पर (पंक्तियाँ स्तंभ बन जाती हैं):

```
adj A = [  5   3   9 ]
        [  5 −13   1 ]
        [  5  11  −7 ]
```

अतः

```
A⁻¹ = (1/40) [  5   3   9 ]
             [  5 −13   1 ]
             [  5  11  −7 ]
```

**चरण 5. X = A⁻¹B।**

```
X = (1/40) [  5   3   9 ] [  5 ]
           [  5 −13   1 ] [ −4 ]
           [  5  11  −7 ] [  3 ]

  = (1/40) [ 5(5) + 3(−4) + 9(3)   ]   = (1/40) [  25 − 12 + 27 ]   = (1/40) [  40 ]
           [ 5(5) − 13(−4) + 1(3)  ]            [  25 + 52 +  3 ]            [  80 ]
           [ 5(5) + 11(−4) − 7(3)  ]            [  25 − 44 − 21 ]            [ −40 ]

  = [  1 ]
    [  2 ]
    [ −1 ]
```

**अतः x = 1, y = 2, z = −1।**

*सत्यापन (यह सदैव कीजिए — इसमें 20 सेकंड लगते हैं):*
2(1) + 3(2) + 3(−1) = 2 + 6 − 3 = 5 ✓
1 − 2(2) + (−1) = 1 − 4 − 1 = −4 ✓
3(1) − 2 − 2(−1) = 3 − 2 + 2 = 3 ✓

### Q2 — A⁻¹ ज्ञात करना

```
A = [ 1  −1   2 ]
    [ 0   2  −3 ]
    [ 3  −2   4 ]
```

**|A|**, पंक्ति 1 के अनुदिश प्रसार:

```
|A| = 1[(2)(4) − (−3)(−2)] − (−1)[(0)(4) − (−3)(3)] + 2[(0)(−2) − (2)(3)]
    = 1[8 − 6] + 1[0 + 9] + 2[0 − 6]
    = 2 + 9 − 12
    = −1
```

|A| = −1 ≠ 0, अतः A⁻¹ विद्यमान है।

**सहखंड:**

```
A₁₁ = +[(2)(4)  − (−3)(−2)] = 8 − 6  =  2
A₁₂ = −[(0)(4)  − (−3)(3)]  = −(9)   = −9
A₁₃ = +[(0)(−2) − (2)(3)]   = −6     = −6

A₂₁ = −[(−1)(4) − (2)(−2)]  = −(0)   =  0
A₂₂ = +[(1)(4)  − (2)(3)]   = −2     = −2
A₂₃ = −[(1)(−2) − (−1)(3)]  = −(1)   = −1

A₃₁ = +[(−1)(−3) − (2)(2)]  = 3 − 4  = −1
A₃₂ = −[(1)(−3)  − (2)(0)]  = 3      =  3
A₃₃ = +[(1)(2)   − (−1)(0)] = 2      =  2
```

**adj A** (ऊपर वाले का परिवर्त):

```
adj A = [  2    0   −1 ]
        [ −9   −2    3 ]
        [ −6   −1    2 ]
```

**A⁻¹ = (1/|A|) adj A = (1/−1) adj A = −adj A:**

```
A⁻¹ = [ −2   0   1 ]
      [  9   2  −3 ]
      [  6   1  −2 ]
```

*सत्यापन — A की पहली पंक्ति गुणा A⁻¹ का पहला स्तंभ:*
(1)(−2) + (−1)(9) + (2)(6) = −2 − 9 + 12 = 1 ✓ (I का (1,1) अवयव)
*A की पहली पंक्ति गुणा दूसरा स्तंभ:* (1)(0) + (−1)(2) + (2)(1) = 0 − 2 + 2 = 0 ✓

### Q6 — संरेखता के लिए k ज्ञात करना

तीनों बिंदु संरेख हैं तभी और केवल तभी जब

```
| k       2−2k    1 |
| 1−k     2k      1 |  = 0
| −4−k    6−2k    1 |
```

स्तंभ 3 के अनुदिश प्रसार सबसे स्वच्छ है, पर यंत्रवत् रखने के लिए पंक्ति 1 के अनुदिश प्रसार करें:

```
det = k[ 2k − (6 − 2k) ] − (2 − 2k)[ (1 − k) − (−4 − k) ] + 1[ (1−k)(6−2k) − 2k(−4−k) ]
```

पद-दर-पद:

```
पद 1 = k(2k − 6 + 2k) = k(4k − 6) = 4k² − 6k

पद 2 = −(2 − 2k)(1 − k + 4 + k) = −(2 − 2k)(5) = −10 + 10k

पद 3 = (6 − 2k − 6k + 2k²) − (−8k − 2k²)
     = (6 − 8k + 2k²) + 8k + 2k²
     = 6 + 4k²
```

जोड़ने पर:

```
det = 4k² − 6k − 10 + 10k + 6 + 4k²
    = 8k² + 4k − 4
```

det = 0 रखने पर:

```
      8k² + 4k − 4 = 0
⟹     2k² + k − 1 = 0
⟹     (2k − 1)(k + 1) = 0
⟹     k = 1/2   या   k = −1
```

**k = 1/2 या k = −1**

### Q7 — आव्यूह विधि से शब्द-समस्या

**व्यवस्था।** मान लीजिए संख्याएँ x, y, z हैं।

- "तीन संख्याओं का योग 6 है" → x + y + z = 6
- "तीसरी को 3 से गुणा करके दूसरी जोड़ें, तो 11" → y + 3z = 11
- "पहली और तीसरी का योग दूसरी का दोगुना है" → x + z = 2y ⟹ x − 2y + z = 0

```
A = [ 1   1   1 ]      X = [ x ]      B = [  6 ]
    [ 0   1   3 ]          [ y ]          [ 11 ]
    [ 1  −2   1 ]          [ z ]          [  0 ]
```

**|A|**, पंक्ति 1 के अनुदिश प्रसार:

```
|A| = 1[(1)(1) − (3)(−2)] − 1[(0)(1) − (3)(1)] + 1[(0)(−2) − (1)(1)]
    = 1[1 + 6] − 1[−3] + 1[−1]
    = 7 + 3 − 1 = 9      ≠ 0, अतः अद्वितीय हल विद्यमान है
```

**सहखंड:**

```
A₁₁ = +[(1)(1)  − (3)(−2)] =  7        A₂₁ = −[(1)(1)  − (1)(−2)] = −3
A₁₂ = −[(0)(1)  − (3)(1)]  =  3        A₂₂ = +[(1)(1)  − (1)(1)]  =  0
A₁₃ = +[(0)(−2) − (1)(1)]  = −1        A₂₃ = −[(1)(−2) − (1)(1)]  =  3

A₃₁ = +[(1)(3)  − (1)(1)]  =  2
A₃₂ = −[(1)(3)  − (1)(0)]  = −3
A₃₃ = +[(1)(1)  − (1)(0)]  =  1
```

**adj A** (सहखंड आव्यूह का परिवर्त):

```
adj A = [  7  −3   2 ]
        [  3   0  −3 ]
        [ −1   3   1 ]
```

**X = A⁻¹B = (1/9)(adj A)B:**

```
X = (1/9) [  7  −3   2 ] [  6 ]   = (1/9) [ 42 − 33 + 0 ]  = (1/9) [  9 ]  = [ 1 ]
          [  3   0  −3 ] [ 11 ]            [ 18 +  0 − 0 ]           [ 18 ]    [ 2 ]
          [ −1   3   1 ] [  0 ]            [ −6 + 33 + 0 ]           [ 27 ]    [ 3 ]
```

**संख्याएँ 1, 2 तथा 3 हैं।**

*सत्यापन:* 1 + 2 + 3 = 6 ✓; 2 + 3(3) = 11 ✓; 1 + 3 = 4 = 2(2) ✓

### Q8 — A = [[2, 3], [1, −4]] के लिए A(adj A) = |A| I का सत्यापन

```
|A| = (2)(−4) − (3)(1) = −8 − 3 = −11
```

2 × 2 आव्यूह [[a, b], [c, d]] के लिए adj A = [[d, −b], [−c, a]]। अतः

```
adj A = [ −4  −3 ]
        [ −1   2 ]
```

```
A(adj A) = [ 2   3 ][ −4  −3 ] = [ 2(−4)+3(−1)    2(−3)+3(2)  ]
           [ 1  −4 ][ −1   2 ]   [ 1(−4)+(−4)(−1) 1(−3)+(−4)(2) ]

         = [ −8 − 3    −6 + 6  ] = [ −11    0  ]
           [ −4 + 4    −3 − 8  ]   [   0  −11  ]

         = −11 [ 1  0 ] = |A| · I ✓
                [ 0  1 ]
```

**अतः A(adj A) = |A| I, सत्यापित।**

> 2 × 2 का शॉर्टकट `adj [[a,b],[c,d]] = [[d,−b],[−c,a]]` — विकर्ण बदलिए, विकर्णेतर का चिह्न पलटिए —
> रटने योग्य है। जब भी 2 × 2 व्युत्क्रम आए, यह पूरा एक मिनट बचाता है।

### Q12 — अभिकथन–कारण

**A:** सत्य। व्युत्क्रमणीय-रहित का अर्थ है |A| = 0, और व्युत्क्रम का सूत्र |A| से भाग माँगता है, अतः
A⁻¹ का अस्तित्व नहीं होता।

**R:** सत्य। व्युत्क्रम का यही सही सूत्र है।

**क्या R, A को समझाता है?** हाँ — ठीक इसीलिए कि A⁻¹ = (1/|A|) adj A, अतः |A| = 0 होने पर व्युत्क्रम
अपरिभाषित हो जाता है।

**उत्तर: (a) A तथा R दोनों सत्य हैं, और R, A का सही स्पष्टीकरण है।**
