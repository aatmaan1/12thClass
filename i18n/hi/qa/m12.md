### Q1 — Z = 4x + y का अधिकतमीकरण

**प्रतिबंध:**

```
      x + y ≤ 50            …(i)
      3x + y ≤ 90           …(ii)
      x ≥ 0, y ≥ 0
```

**सीमा रेखाएँ तथा अंतःखंड:**

```
      x + y = 50    →  (50, 0) तथा (0, 50)
      3x + y = 90   →  (30, 0) तथा (0, 90)
```

**मूल बिंदु परीक्षण।** (0, 0) दोनों (i) तथा (ii) को संतुष्ट करता है (0 ≤ 50 ✓, 0 ≤ 90 ✓), अतः प्रत्येक के
लिए मूल बिंदु वाला पक्ष छायांकित कीजिए। x, y ≥ 0 के साथ सुसंगत क्षेत्र प्रथम चतुर्थांश में एक **परिबद्ध**
चतुर्भुज है।

**कोने बिंदु।**

- **(0, 0)** — मूल बिंदु
- **(30, 0)** — जहाँ 3x + y = 90, x-अक्ष से मिलती है (ध्यान दें x + y = 50 उससे (50,0) पर मिलती है, जो
  (ii) से बाहर है क्योंकि 3(50) = 150 > 90, अतः (30,0) बाध्यकारी है)
- **(0, 50)** — जहाँ x + y = 50, y-अक्ष से मिलती है (बिंदु (0,90), (i) का उल्लंघन करता है)
- **(i) तथा (ii) का प्रतिच्छेद:**

```
      x + y = 50
      3x + y = 90
```

घटाने पर: 2x = 40 ⟹ **x = 20**, और तब y = 30। अतः बिंदु **(20, 30)** है।

**Z = 4x + y की सारणी:**

| कोने बिंदु | Z = 4x + y |
| --- | --- |
| (0, 0) | 0 |
| (30, 0) | 120 + 0 = **120** |
| (20, 30) | 80 + 30 = 110 |
| (0, 50) | 0 + 50 = 50 |

चूँकि सुसंगत क्षेत्र **परिबद्ध** है, अधिकतम विद्यमान है और किसी कोने बिंदु पर आता है।

```
अधिकतम Z = 120, बिंदु (30, 0) पर
```

### Q2 — Z = 3x + 5y का न्यूनतमीकरण

**प्रतिबंध:**

```
      x + 3y ≥ 3            …(i)
      x + y ≥ 2             …(ii)
      x ≥ 0, y ≥ 0
```

**सीमा रेखाएँ:**

```
      x + 3y = 3   →  (3, 0) तथा (0, 1)
      x + y = 2    →  (2, 0) तथा (0, 2)
```

**मूल बिंदु परीक्षण।** (0, 0) देता है 0 ≥ 3 ✗ तथा 0 ≥ 2 ✗, अतः दोनों के लिए मूल बिंदु से **दूर** का पक्ष
छायांकित कीजिए। अतः सुसंगत क्षेत्र **अपरिबद्ध** है (वह ऊपर और दाईं ओर फैला है)।

**कोने बिंदु।**

- **(3, 0)** — जहाँ x + 3y = 3, x-अक्ष से मिलती है (और (2,0), (i) में विफल: 2 ≥ 3 ✗)
- **(0, 2)** — जहाँ x + y = 2, y-अक्ष से मिलती है (और (0,1), (ii) में विफल: 1 ≥ 2 ✗)
- **(i) तथा (ii) का प्रतिच्छेद:**

```
      x + 3y = 3
      x +  y = 2
```

घटाने पर: 2y = 1 ⟹ **y = 1/2**, और तब x = 3/2। अतः बिंदु **(3/2, 1/2)** है।

**Z = 3x + 5y की सारणी:**

| कोने बिंदु | Z = 3x + 5y |
| --- | --- |
| (3, 0) | 9 + 0 = 9 |
| (3/2, 1/2) | 4.5 + 2.5 = **7** |
| (0, 2) | 0 + 10 = 10 |

सबसे छोटा कोना-मान 7 है। **पर क्षेत्र अपरिबद्ध है, अतः जाँच आवश्यक है।**

**अपरिबद्ध जाँच।** खुले अर्ध-तल 3x + 5y < 7 पर विचार कीजिए। रेखा 3x + 5y = 7, (7/3, 0) ≈ (2.33, 0) तथा
(0, 7/5) = (0, 1.4) से गुज़रती है। सुसंगत क्षेत्र का प्रत्येक बिंदु इस रेखा पर या उसके ऊपर है — सुसंगत
क्षेत्र का 3x + 5y < 7 के साथ **कोई साझा बिंदु नहीं** है।

अतः 7 वास्तव में न्यूनतम है।

```
न्यूनतम Z = 7, बिंदु (3/2, 1/2) पर
```

*(ध्यान दें कि यहाँ Z का **कोई अधिकतम नहीं** है: क्षेत्र ऊपर की ओर अपरिबद्ध है और दोनों गुणांक धनात्मक हैं,
अतः Z को मनमाना बड़ा किया जा सकता है।)*

### Q3 — Z = 5x + 10y का न्यूनतमीकरण तथा अधिकतमीकरण

**प्रतिबंध:**

```
      x + 2y ≤ 120          …(i)
      x + y ≥ 60            …(ii)
      x − 2y ≥ 0            …(iii)
      x ≥ 0, y ≥ 0
```

**सीमा रेखाएँ:**

```
      x + 2y = 120  →  (120, 0) तथा (0, 60)
      x + y = 60    →  (60, 0) तथा (0, 60)
      x − 2y = 0    →  (0, 0) तथा (40, 20) से गुज़रती है
```

**कोने बिंदु।** सुसंगत क्षेत्र एक **परिबद्ध** चतुर्भुज है। उसके शीर्ष:

- **(60, 0)** — जहाँ x + y = 60, x-अक्ष से मिलती है; जाँच (i): 60 ≤ 120 ✓, (iii): 60 ≥ 0 ✓
- **(120, 0)** — जहाँ x + 2y = 120, x-अक्ष से मिलती है; जाँच (ii): 120 ≥ 60 ✓, (iii): 120 ≥ 0 ✓
- **(i) तथा (iii) का प्रतिच्छेद:**

```
      x + 2y = 120
      x − 2y = 0
```

जोड़ने पर: 2x = 120 ⟹ x = 60, y = 30। बिंदु **(60, 30)**। जाँच (ii): 90 ≥ 60 ✓

- **(ii) तथा (iii) का प्रतिच्छेद:**

```
      x +  y = 60
      x − 2y = 0     ⟹  x = 2y
```

अतः 2y + y = 60 ⟹ y = 20, x = 40। बिंदु **(40, 20)**। जाँच (i): 40 + 40 = 80 ≤ 120 ✓

**Z = 5x + 10y की सारणी:**

| कोने बिंदु | Z = 5x + 10y |
| --- | --- |
| (60, 0) | 300 + 0 = **300** |
| (120, 0) | 600 + 0 = **600** |
| (60, 30) | 300 + 300 = **600** |
| (40, 20) | 200 + 200 = 400 |

```
न्यूनतम Z = 300, (60, 0) पर

अधिकतम Z = 600, (120, 0) तथा (60, 30) दोनों पर प्राप्त
```

चूँकि अधिकतम दो कोने बिंदुओं पर आता है, अतः वह **(120, 0) तथा (60, 30) को जोड़ने वाले रेखाखंड के प्रत्येक
बिंदु पर आता है** — अनंत इष्टतम हल हैं।

### Q4 — कोई सुसंगत हल नहीं

**प्रतिबंधों को फिर से लिखिए:**

```
      x − y ≤ −1     ⟹     y ≥ x + 1          …(i)
      −x + y ≤ 0     ⟹     y ≤ x              …(ii)
```

(i) से y ≥ x + 1; (ii) से y ≤ x। मिलाने पर:

```
      x + 1 ≤ y ≤ x
⟹     x + 1 ≤ x
⟹     1 ≤ 0,   जो असंभव है
```

अतः कोई भी बिंदु (x, y) दोनों प्रतिबंध संतुष्ट नहीं करता। **सुसंगत क्षेत्र रिक्त है**, और इस समस्या का
**कोई सुसंगत हल नहीं** है।

*(ग्राफ़ीय रूप से: रेखा y = x + 1 के ऊपर का अर्ध-तल और y = x के नीचे का अर्ध-तल असंयुक्त हैं, क्योंकि ये
दोनों रेखाएँ समांतर और भिन्न हैं।)*

### Q5 — p और q के बीच संबंध

Z = px + qy, और **न्यूनतम** (3, 0) तथा (1, 1) दोनों पर आता है। उन बिंदुओं पर Z के मान बराबर:

```
      Z(3, 0) = 3p + 0 = 3p
      Z(1, 1) = p + q
```

```
      3p = p + q
⟹     2p = q
```

```
q = 2p          (समकक्ष रूप से p = q/2)
```

*(जाँचिए कि तीसरा कोना इससे कम नहीं है: Z(0, 3) = 3q = 6p, जो 3p से अधिक है क्योंकि p > 0 ✓ — अतः न्यूनतम
वास्तव में उन दो बिंदुओं पर, और अतः उन्हें जोड़ने वाले खंड पर है।)*

### Q8 — प्रकरण अध्ययन: निर्माता

**(i) सूत्रीकरण।**

मान लीजिए x = प्रतिदिन बनाई गई A की इकाइयों की संख्या, y = B की इकाइयों की संख्या।

आँकड़ों की सारणी:

| | मशीन M₁ (घंटे) | मशीन M₂ (घंटे) | लाभ (₹) |
| --- | --- | --- | --- |
| उत्पाद A (x इकाइयाँ) | 2 | 1 | 5 |
| उत्पाद B (y इकाइयाँ) | 1 | 2 | 3 |
| **उपलब्ध / कुल** | 10 | 8 | अधिकतम कीजिए |

```
अधिकतम कीजिए    Z = 5x + 3y                (लाभ ₹ में)

जबकि            2x + y ≤ 10                (मशीन M₁ का समय)
                x + 2y ≤ 8                 (मशीन M₂ का समय)
                x ≥ 0,  y ≥ 0
```

**(ii) कोने बिंदु।**

सीमा रेखाएँ: 2x + y = 10 → (5, 0) तथा (0, 10); x + 2y = 8 → (8, 0) तथा (0, 4)।

- **(0, 0)**
- **(5, 0)** — जहाँ 2x + y = 10, x-अक्ष से मिलती है; जाँच x + 2y ≤ 8: 5 ≤ 8 ✓
- **(0, 4)** — जहाँ x + 2y = 8, y-अक्ष से मिलती है; जाँच 2x + y ≤ 10: 4 ≤ 10 ✓
- **प्रतिच्छेद:**

```
      2x + y = 10          …2 से गुणा:  4x + 2y = 20
      x + 2y = 8
```

घटाने पर: 3x = 12 ⟹ **x = 4**, फिर y = 10 − 8 = **2**। बिंदु **(4, 2)**।

**कोने बिंदु: (0, 0), (5, 0), (4, 2), (0, 4)।**

**(iii) अधिकतम लाभ।**

| कोने बिंदु | Z = 5x + 3y |
| --- | --- |
| (0, 0) | 0 |
| (5, 0) | 25 |
| (4, 2) | 20 + 6 = **26** |
| (0, 4) | 12 |

```
अधिकतम लाभ = ₹26, प्रतिदिन A की 4 इकाइयाँ तथा B की 2 इकाइयाँ बनाकर।
```

*((4, 2) पर दोनों मशीन प्रतिबंध जाँचिए: M₁ में 2(4) + 2 = 10 घंटे ✓ ठीक उपलब्ध जितने; M₂ में
4 + 2(2) = 8 घंटे ✓ ठीक उपलब्ध जितने। दोनों मशीनें पूरी तरह उपयोग में हैं — यह अच्छा संकेत है कि इष्टतम
प्रतिच्छेद पर है।)*
