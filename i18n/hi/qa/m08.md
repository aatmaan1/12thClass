### Q1 — x = 2 से x = 4 तक y² = 9x के नीचे क्षेत्रफल

प्रथम चतुर्थांश में y² = 9x से **y = 3√x** मिलता है (धनात्मक मूल)।

```
      क्षेत्रफल = ∫[2,4] y dx = ∫[2,4] 3√x dx

           = 3 ∫[2,4] x^(1/2) dx

           = 3 · [ x^(3/2) / (3/2) ]₂⁴

           = 3 · (2/3) [ x^(3/2) ]₂⁴

           = 2 [ 4^(3/2) − 2^(3/2) ]

           = 2 [ 8 − 2√2 ]
```

```
क्षेत्रफल = (16 − 4√2) वर्ग इकाई          ≈ 10.34 वर्ग इकाई
```

### Q2 — दीर्घवृत्त x²/16 + y²/9 = 1 का क्षेत्रफल

यहाँ a² = 16 तथा b² = 9, अतः a = 4 और b = 3।

**सममिति से** (दीर्घवृत्त दोनों अक्षों के परितः सममित है) कुल क्षेत्रफल प्रथम-चतुर्थांश क्षेत्रफल का
4 गुना है:

```
      क्षेत्रफल = 4 ∫[0,4] y dx      जहाँ  y = 3√(1 − x²/16) = (3/4)√(16 − x²)

           = 4 · (3/4) ∫[0,4] √(16 − x²) dx

           = 3 · (π · 4²/4)                    [∫[0,a]√(a²−x²)dx = πa²/4 लेकर, a = 4]

           = 3 · 4π
```

```
क्षेत्रफल = 12π वर्ग इकाई
```

*(व्यापक परिणाम के अनुरूप: दीर्घवृत्त का क्षेत्रफल = πab = π(4)(3) = 12π।)*

### Q3 — प्रथम चतुर्थांश, x-अक्ष, y = x तथा x² + y² = 32 से घिरा

**रेखाचित्र।** वृत्त की त्रिज्या √32 = 4√2 ≈ 5.66 है। रेखा y = x मूल बिंदु से जाती 45° की रेखा है। क्षेत्र
x-अक्ष (नीचे) और रेखा y = x (ऊपर) के बीच, वृत्त तक फैला है।

**y = x तथा वृत्त का प्रतिच्छेद:**

```
      x² + x² = 32   ⟹   2x² = 32   ⟹   x² = 16   ⟹   x = 4      (प्रथम चतुर्थांश)
```

अतः वे **(4, 4)** पर मिलते हैं।

**x = 4 पर विभाजन।** 0 ≤ x ≤ 4 के लिए ऊपरी सीमा **रेखा** y = x है; 4 ≤ x ≤ 4√2 के लिए ऊपरी सीमा
**वृत्त** y = √(32 − x²) है।

```
      क्षेत्रफल = ∫[0,4] x dx  +  ∫[4, 4√2] √(32 − x²) dx
```

**पहला समाकल:**

```
      ∫[0,4] x dx = [ x²/2 ]₀⁴ = 8
```

**दूसरा समाकल**, ∫√(a² − x²)dx = (x/2)√(a² − x²) + (a²/2)sin⁻¹(x/a) का उपयोग करते हुए, a² = 32,
a = 4√2 के साथ:

```
      = [ (x/2)√(32 − x²) + 16 sin⁻¹( x/(4√2) ) ]  4 से 4√2 तक
```

x = 4√2 पर:

```
      (4√2/2)√(32 − 32) + 16 sin⁻¹(1) = 0 + 16(π/2) = 8π
```

x = 4 पर:

```
      (4/2)√(32 − 16) + 16 sin⁻¹(4/(4√2)) = 2√16 + 16 sin⁻¹(1/√2)
                                          = 2(4) + 16(π/4)
                                          = 8 + 4π
```

अतः दूसरा समाकल = 8π − (8 + 4π) = **4π − 8**।

**कुल:**

```
      क्षेत्रफल = 8 + (4π − 8) = 4π
```

```
क्षेत्रफल = 4π वर्ग इकाई
```

> **संगति जाँच।** यह क्षेत्र ठीक θ = 0 और θ = π/4 के बीच का वृत्तखंड (sector) है, जिसका क्षेत्रफल वृत्त
> का (1/8) = (1/8)π(32) = 4π ✓ है। यह पहचान लेने से प्रश्न एक पंक्ति में हो जाता, पर अंक-योजना समाकल
> चाहती है — अतः दोनों कीजिए: समाकलन कीजिए, फिर जाँचिए।

### Q4 — y² = 4x तथा x = 3 से घिरा क्षेत्रफल

परवलय y² = 4x **x-अक्ष के परितः सममित** है, और रेखा x = 3 ऊर्ध्वाधर है।

```
      क्षेत्रफल = 2 × (x-अक्ष के ऊपर का क्षेत्रफल)
           = 2 ∫[0,3] y dx        जहाँ y = 2√x
           = 2 ∫[0,3] 2√x dx
           = 4 ∫[0,3] x^(1/2) dx
           = 4 · (2/3) [ x^(3/2) ]₀³
           = (8/3) · 3^(3/2)
           = (8/3) · 3√3
```

```
क्षेत्रफल = 8√3 वर्ग इकाई          ≈ 13.86 वर्ग इकाई
```

*(वैकल्पिक रूप से, y के सापेक्ष समाकलन: क्षेत्र y = −2√3 से y = 2√3 तक चलता है, और x, y²/4 से 3 तक।
क्षेत्रफल = ∫[−2√3, 2√3] (3 − y²/4) dy = 2∫[0,2√3](3 − y²/4)dy = 2[3y − y³/12]₀^(2√3)
= 2[6√3 − 24√3/12] = 2[6√3 − 2√3] = 8√3 ✓)*

### Q5 — दीर्घवृत्त x²/9 + y²/4 = 1 तथा रेखा x/3 + y/2 = 1 के बीच का छोटा क्षेत्र

**ज्यामिति पहचानिए।** दीर्घवृत्त में a = 3, b = 2। रेखा x/3 + y/2 = 1, (3, 0) तथा (0, 2) से गुज़रती है —
ठीक प्रथम चतुर्थांश में अर्ध-दीर्घ और अर्ध-लघु अक्षों के सिरे। अतः रेखा उन दो बिंदुओं को जोड़ने वाली जीवा
है, और **छोटा क्षेत्र** प्रथम-चतुर्थांश की चतुर्थांश-दीर्घवृत्त का वह भाग है जो रेखा के **ऊपर** है।

```
      अभीष्ट क्षेत्रफल = (चतुर्थांश दीर्घवृत्त का क्षेत्रफल) − (शीर्ष (0,0), (3,0), (0,2) वाले त्रिभुज का क्षेत्रफल)
```

**चतुर्थांश दीर्घवृत्त:**

```
      = πab/4 = π(3)(2)/4 = 3π/2
```

**त्रिभुज:** भुजाएँ 3 तथा 2, अतः क्षेत्रफल = ½(3)(2) = 3।

```
      अभीष्ट क्षेत्रफल = 3π/2 − 3 = (3/2)(π − 2)
```

```
क्षेत्रफल = 3(π − 2)/2 वर्ग इकाई          ≈ 1.71 वर्ग इकाई
```

*(समाकलन से, यदि प्रश्न पूरे अंकों के लिए यही माँगे:
क्षेत्रफल = ∫[0,3] [ (2/3)√(9 − x²) − 2(1 − x/3) ] dx = (2/3)(π·9/4) − 2[x − x²/6]₀³
= 3π/2 − 2(3 − 3/2) = 3π/2 − 3 ✓)*

### Q7 — x = 0 से 2π तक y = sin x से घिरा क्षेत्रफल

वक्र [0, π] पर x-अक्ष के **ऊपर** और [π, 2π] पर उसके **नीचे** है। अतः विभाजित कीजिए:

```
      क्षेत्रफल = ∫[0,π] sin x dx  +  | ∫[π,2π] sin x dx |
```

```
      ∫[0,π] sin x dx = [−cos x]₀^π = −cos π + cos 0 = 1 + 1 = 2

      ∫[π,2π] sin x dx = [−cos x]_π^(2π) = −cos 2π + cos π = −1 − 1 = −2
```

```
      क्षेत्रफल = 2 + |−2| = 4
```

```
क्षेत्रफल = 4 वर्ग इकाई
```

> यदि आपने ∫[0,2π] sin x dx निकाला होता तो **0** मिलता, जो नेट चिह्नित समाकल है, क्षेत्रफल नहीं।
> विभाजन ही पूरा प्रश्न है।

### Q8 — y = 3x + 2, x-अक्ष, x = −1 तथा x = 1 से घिरा क्षेत्रफल

**रेखा x-अक्ष को कहाँ काटती है:**

```
      3x + 2 = 0   ⟹   x = −2/3
```

चूँकि −1 < −2/3 < 1, अतः रेखा [−1, −2/3] पर अक्ष के **नीचे** और [−2/3, 1] पर उसके **ऊपर** है। अतः
x = −2/3 पर विभाजित कीजिए।

मान लीजिए F(x) = ∫(3x + 2)dx = 3x²/2 + 2x।

```
      F(−1)   = 3/2 − 2 = −1/2
      F(−2/3) = 3(4/9)/2 + 2(−2/3) = 2/3 − 4/3 = −2/3
      F(1)    = 3/2 + 2 = 7/2
```

**भाग 1** (अक्ष के नीचे):

```
      ∫[−1, −2/3] (3x + 2) dx = F(−2/3) − F(−1) = −2/3 + 1/2 = −1/6
      क्षेत्रफल₁ = |−1/6| = 1/6
```

**भाग 2** (अक्ष के ऊपर):

```
      ∫[−2/3, 1] (3x + 2) dx = F(1) − F(−2/3) = 7/2 + 2/3 = 21/6 + 4/6 = 25/6
      क्षेत्रफल₂ = 25/6
```

```
      कुल क्षेत्रफल = 1/6 + 25/6 = 26/6 = 13/3
```

```
क्षेत्रफल = 13/3 वर्ग इकाई
```

*(ज्यामितीय जाँच: दो त्रिभुज। पहले का आधार −1 से −2/3, अर्थात् 1/3, और ऊँचाई |3(−1)+2| = 1, क्षेत्रफल
= ½(1/3)(1) = 1/6 ✓। दूसरे का आधार −2/3 से 1, अर्थात् 5/3, और ऊँचाई 3(1)+2 = 5, क्षेत्रफल = ½(5/3)(5)
= 25/6 ✓)*
