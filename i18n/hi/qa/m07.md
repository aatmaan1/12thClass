### Q1 — ∫ (x² + x + 1)/[(x + 2)(x² + 1)] dx

हर में एक रैखिक गुणनखंड है और एक **अखंडनीय** द्विघात गुणनखंड है (x² + 1 का कोई वास्तविक मूल नहीं है)।
अतः आंशिक भिन्नों में वियोजन इस प्रकार होगा —

```
      (x² + x + 1)/[(x + 2)(x² + 1)]  =  A/(x + 2)  +  (Bx + C)/(x² + 1)
```

दोनों पक्षों को (x + 2)(x² + 1) से गुणा कीजिए —

```
      x² + x + 1 = A(x² + 1) + (Bx + C)(x + 2)          …(∗)
```

**A ज्ञात कीजिए** — (∗) में x = −2 रखिए:

```
      4 − 2 + 1 = A(4 + 1) + 0
⟹     3 = 5A
⟹     A = 3/5
```

**B ज्ञात कीजिए** — (∗) में x² के गुणांकों की तुलना कीजिए:

```
      1 = A + B   ⟹   B = 1 − 3/5 = 2/5
```

**C ज्ञात कीजिए** — (∗) में अचर पदों की तुलना कीजिए:

```
      1 = A + 2C   ⟹   1 = 3/5 + 2C   ⟹   2C = 2/5   ⟹   C = 1/5
```

अतः

```
      ∫ = (3/5) ∫ dx/(x + 2)  +  ∫ [ (2/5)x + 1/5 ] / (x² + 1) dx

        = (3/5) log|x + 2|  +  (1/5) ∫ (2x + 1)/(x² + 1) dx
```

शेष समाकलन को दो भागों में बाँटिए —

```
      (1/5) ∫ 2x/(x² + 1) dx  +  (1/5) ∫ dx/(x² + 1)
    = (1/5) log(x² + 1)  +  (1/5) tan⁻¹x
```

*(पहला भाग t = x² + 1, dt = 2x dx प्रतिस्थापित करने से मिलता है।)*

```
∫ (x² + x + 1)/[(x + 2)(x² + 1)] dx = (3/5) log|x + 2| + (1/5) log(x² + 1) + (1/5) tan⁻¹x + C
```

### Q2 — ∫ 2x/[(x² + 1)(x² + 3)] dx

ध्यान दीजिए कि अंश 2x, x² का अवकलज है। अतः **t = x², dt = 2x dx प्रतिस्थापित कीजिए —**

```
      ∫ = ∫ dt / [(t + 1)(t + 3)]
```

आंशिक भिन्न —

```
      1/[(t + 1)(t + 3)] = A/(t + 1) + B/(t + 3)
⟹     1 = A(t + 3) + B(t + 1)
```

t = −1: 1 = 2A ⟹ A = 1/2. t = −3: 1 = −2B ⟹ B = −1/2.

```
      ∫ = ½ ∫ dt/(t + 1)  −  ½ ∫ dt/(t + 3)
        = ½ log|t + 1| − ½ log|t + 3| + C
        = ½ log |(t + 1)/(t + 3)| + C
```

t = x² वापस रखने पर —

```
∫ 2x/[(x² + 1)(x² + 3)] dx = ½ log [ (x² + 1)/(x² + 3) ] + C
```

*(निरपेक्ष मान की आवश्यकता नहीं, क्योंकि x² + 1 और x² + 3 दोनों धनात्मक हैं।)*

### Q3 — ∫ x/[(x + 1)(x + 2)] dx

```
      x/[(x + 1)(x + 2)] = A/(x + 1) + B/(x + 2)
⟹     x = A(x + 2) + B(x + 1)
```

x = −1: −1 = A(1) ⟹ **A = −1**
x = −2: −2 = B(−1) ⟹ **B = 2**

```
      ∫ = −∫ dx/(x + 1) + 2∫ dx/(x + 2)
```

```
∫ x/[(x + 1)(x + 2)] dx = −log|x + 1| + 2 log|x + 2| + C
```

*(अथवा समतुल्य रूप में log|(x + 2)²/(x + 1)| + C।)*

### Q4 — ∫ dx/(x² − 6x + 13)

**पूर्ण वर्ग बनाइए —**

```
      x² − 6x + 13 = (x² − 6x + 9) + 4 = (x − 3)² + 2²
```

अब ∫dt/(t² + a²) = (1/a)tan⁻¹(t/a) में t = x − 3 और a = 2 रखने पर —

```
∫ dx/(x² − 6x + 13) = ½ tan⁻¹( (x − 3)/2 ) + C
```

### Q5 — ∫ (x + 2)/√(x² + 2x + 3) dx

**अंश को तोड़िए।** x² + 2x + 3 का अवकलज 2x + 2 है, अतः लिखिए

```
      x + 2 = ½(2x + 2) + 1
```

*(जाँच: ½(2x + 2) + 1 = x + 1 + 1 = x + 2 ✓)*

```
      ∫ = ½ ∫ (2x + 2)/√(x² + 2x + 3) dx  +  ∫ dx/√(x² + 2x + 3)
          \_________ I₁ _________/            \______ I₂ ______/
```

**I₁:** t = x² + 2x + 3, dt = (2x + 2)dx प्रतिस्थापित कीजिए:

```
      I₁ = ½ ∫ dt/√t = ½ · 2√t = √(x² + 2x + 3)
```

**I₂:** पूर्ण वर्ग बनाइए: x² + 2x + 3 = (x + 1)² + 2 = (x + 1)² + (√2)²

```
      I₂ = ∫ dx/√((x + 1)² + (√2)²) = log | (x + 1) + √(x² + 2x + 3) |
```

*(यहाँ ∫dt/√(t² + a²) = log|t + √(t² + a²)| का प्रयोग किया गया है।)*

```
∫ (x + 2)/√(x² + 2x + 3) dx = √(x² + 2x + 3) + log | (x + 1) + √(x² + 2x + 3) | + C
```

### Q6 — ∫ x² log x dx

एक बीजीय और एक लघुगणकीय फलन का गुणनफल → **खंडशः समाकलन**। ILATE के अनुसार "L" पहले आता है और "A" बाद में,
अतः **u = log x** तथा v = x² लीजिए।

```
      ∫ x² log x dx = log x · ∫x² dx  −  ∫ (1/x) (∫x² dx) dx

                    = log x · (x³/3)  −  ∫ (1/x)(x³/3) dx

                    = (x³/3) log x  −  (1/3) ∫ x² dx

                    = (x³/3) log x  −  (1/3)(x³/3)
```

```
∫ x² log x dx = (x³/3) log x − x³/9 + C
```

*(अवकलन करके जाँचिए: (3x²/3)log x + (x³/3)(1/x) − 3x²/9 = x² log x + x²/3 − x²/3 = x² log x ✓)*

### Q7 — ∫ eˣ (sin x + cos x) dx

इसे ∫eˣ[f(x) + f′(x)]dx के रूप में पहचानिए, जहाँ **f(x) = sin x** है, क्योंकि f′(x) = cos x।

```
∫ eˣ (sin x + cos x) dx = eˣ sin x + C
```

*(यदि यह रूप न दिखे तो दो बार खंडशः समाकलन से भी उत्तर मिलेगा — पर उसमें एक पंक्ति की जगह चार लगेंगी।)*

### Q8 — ∫[0, π/2] √(tan x) / [√(tan x) + √(cot x)] dx

मान लीजिए

```
      I = ∫[0, π/2] √(tan x) / [√(tan x) + √(cot x)] dx          …(i)
```

**गुणधर्म P4 लगाइए**, जिसमें a = π/2, अर्थात् x के स्थान पर (π/2 − x) रखिए। चूँकि tan(π/2 − x) = cot x
तथा cot(π/2 − x) = tan x,

```
      I = ∫[0, π/2] √(cot x) / [√(cot x) + √(tan x)] dx          …(ii)
```

**(i) और (ii) को जोड़िए —**

```
      2I = ∫[0, π/2] [ √(tan x) + √(cot x) ] / [ √(tan x) + √(cot x) ] dx

         = ∫[0, π/2] 1 dx

         = [x]₀^(π/2) = π/2
```

```
I = π/4
```

> यह "दो बार लिखिए और जोड़िए" वाला प्रसिद्ध प्रश्न है। रूप पहचान लेने पर यह तीन पंक्तियों का काम है।
> जिस भी प्रश्न में समाकल्य [0, a] पर A/(A + B) के रूप में हो और x → a − x से A तथा B आपस में बदल जाएँ,
> वह यही प्रश्न है।

### Q9 — ∫[1, 4] |x − 2| dx

निरपेक्ष मान का चिह्न x = 2 पर बदलता है, जो [1, 4] के भीतर है। अतः **अंतराल को 2 पर बाँटिए —**

```
      |x − 2| = 2 − x   जब x < 2          (क्योंकि x − 2 < 0)
              = x − 2   जब x ≥ 2
```

```
      I = ∫[1,2] (2 − x) dx  +  ∫[2,4] (x − 2) dx
```

**पहला भाग —**

```
      ∫[1,2] (2 − x) dx = [ 2x − x²/2 ]₁²
                        = (4 − 2) − (2 − ½)
                        = 2 − 3/2 = 1/2
```

**दूसरा भाग —**

```
      ∫[2,4] (x − 2) dx = [ x²/2 − 2x ]₂⁴
                        = (8 − 8) − (2 − 4)
                        = 0 − (−2) = 2
```

```
I = 1/2 + 2 = 5/2
```

*(ज्यामिति से जाँच: [1, 4] पर |x − 2| का ग्राफ दो त्रिभुज बनाता है — एक का आधार 1 और ऊँचाई 1 (क्षेत्रफल ½),
दूसरे का आधार 2 और ऊँचाई 2 (क्षेत्रफल 2)। कुल 5/2 ✓)*

### Q10 — ∫[−1, 1] x¹⁷ cos⁴x dx

मान लीजिए f(x) = x¹⁷ cos⁴x। तब

```
      f(−x) = (−x)¹⁷ cos⁴(−x) = −x¹⁷ cos⁴x = −f(x)
```

*(x¹⁷ विषम है क्योंकि 17 विषम है; cos⁴x सम है क्योंकि cos(−x) = cos x।)*

अतः f एक **विषम** फलन है और सीमाएँ 0 के परितः सममित हैं। **गुणधर्म P7** से —

```
∫[−1, 1] x¹⁷ cos⁴x dx = 0
```

### Q11 — ∫[2, 3] dx/(x² − 1)

a = 1 के साथ मानक रूप (1) का प्रयोग कीजिए, अथवा आंशिक भिन्नों से — दोनों एक ही बात हैं:

```
      ∫ dx/(x² − 1) = ½ log |(x − 1)/(x + 1)|
```

2 से 3 तक मान निकालिए —

```
      I = ½ [ log|(x − 1)/(x + 1)| ]₂³

        = ½ [ log(2/4) − log(1/3) ]

        = ½ [ log(1/2) + log 3 ]

        = ½ log(3/2)
```

```
I = ½ log(3/2)
```

### Q12 — ∫ sin³x dx

sin की विषम घात → sin x का एक गुणनखंड अलग कीजिए और शेष को cos में बदलिए:

```
      ∫ sin³x dx = ∫ sin²x · sin x dx = ∫ (1 − cos²x) sin x dx
```

t = cos x, dt = −sin x dx प्रतिस्थापित कीजिए:

```
      = ∫ (1 − t²)(−dt)
      = ∫ (t² − 1) dt
      = t³/3 − t
```

```
∫ sin³x dx = cos³x/3 − cos x + C
```

*(जाँच: d/dx[cos³x/3 − cos x] = cos²x(−sin x) + sin x = sin x(1 − cos²x) = sin³x ✓)*

### Q13 — ∫ √(4 − x²) dx

यह a = 2 के साथ मानक रूप (7) है:

```
      ∫ √(a² − x²) dx = (x/2)√(a² − x²) + (a²/2) sin⁻¹(x/a) + C
```

```
∫ √(4 − x²) dx = (x/2)√(4 − x²) + 2 sin⁻¹(x/2) + C
```

*(क्योंकि a²/2 = 4/2 = 2।)*

### Q14 — ∫[0, π/2] sin²x dx

सम घात → द्विक कोण सर्वसमिका का प्रयोग कीजिए:

```
      sin²x = (1 − cos 2x)/2
```

```
      I = ∫[0, π/2] (1 − cos 2x)/2 dx

        = ½ [ x − (sin 2x)/2 ]₀^(π/2)

        = ½ [ (π/2 − (sin π)/2) − (0 − 0) ]

        = ½ (π/2 − 0)
```

```
I = π/4
```
