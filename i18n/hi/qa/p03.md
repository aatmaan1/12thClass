### Q1 — अपवाह वेग, I = neAv_d, ओम का नियम और प्रतिरोधकता

*आरेख:* लंबाई l तथा क्षेत्रफल A का बेलनाकार चालक, उसके आड़े एक बैटरी, भीतर **E** दिखाता एक तीर, और
**E** के विपरीत अपवाहित होते इलेक्ट्रॉन।

**अपवाह वेग की परिभाषा।** जब किसी चालक के आड़े विभवांतर आरोपित किया जाता है, तो मुक्त इलेक्ट्रॉन अपनी
बेतरतीब तापीय गति के अतिरिक्त, **आरोपित क्षेत्र के विपरीत दिशा में एक छोटा औसत वेग** प्राप्त कर लेते
हैं। इस औसत वेग को **अपवाह वेग** कहते हैं।

```
      v_d = (eE/m) τ
```

जहाँ τ शिथिलन काल है (दो क्रमागत टकरावों के बीच का औसत समय)।

**I = neAv_d की व्युत्पत्ति।**

मान लीजिए चालक का अनुप्रस्थ काट A है और प्रति इकाई आयतन n मुक्त इलेक्ट्रॉन हैं, प्रत्येक का आवेश e, जो
v_d चाल से अपवाहित हो रहे हैं।

सूक्ष्म समय Δt में प्रत्येक इलेक्ट्रॉन v_d Δt दूरी तय करता है। अतः लंबाई v_d Δt तथा अनुप्रस्थ काट A
वाले बेलन में समाए **सभी** इलेक्ट्रॉन उस समय में किसी दिए तल को पार कर जाएँगे।

```
      उस बेलन का आयतन = A v_d Δt
      उसमें इलेक्ट्रॉनों की संख्या = n A v_d Δt
      तल को पार करता आवेश, Δq = (n A v_d Δt) e
```

अतः

```
      I = Δq/Δt = n e A v_d
```

**इससे ओम का नियम।** v_d = eEτ/m रखने पर, और एकसमान चालक के लिए E = V/l:

```
      I = n e A · (eτ/m) · (V/l)
        = ( n e² A τ / m l ) V
```

पुनर्व्यवस्थित करने पर,

```
      V = [ m l / (n e² A τ) ] I
```

कोष्ठक किसी दिए चालक के लिए दिए ताप पर एक नियतांक है। अतः

```
      V ∝ I,     अर्थात्     V = I R          — ओम का नियम
```

जहाँ

```
      R = m l / (n e² A τ)
```

**प्रतिरोधकता।** R = ρ l/A से तुलना करने पर:

```
      ρ l/A = m l/(n e² A τ)
⟹     ρ = m / (n e² τ)
```

∎

*(ध्यान दीजिए यह व्यंजक क्या बताता है: ρ केवल पदार्थ के गुणों n और τ पर, तथा τ और n के माध्यम से ताप पर
निर्भर करता है — चालक के आकार-प्रकार पर नहीं। इसीलिए ρ पदार्थ का नियतांक है और R नहीं।)*

### Q2 — किरखॉफ़ के नियम और व्हीटस्टोन सेतु

**किरखॉफ़ के नियम।**

**1. संधि नियम।** परिपथ की किसी भी संधि पर धाराओं का बीजगणितीय योग शून्य होता है — संधि में प्रवेश करती
कुल धारा उससे निकलती कुल धारा के बराबर होती है।

```
      Σ I = 0
```

यह **विद्युत आवेश के संरक्षण** को व्यक्त करता है (संधि पर आवेश जमा नहीं हो सकता)।

**2. लूप नियम।** परिपथ के किसी बंद लूप के चारों ओर विभव-परिवर्तनों का बीजगणितीय योग शून्य होता है।

```
      Σ ΔV = 0
```

यह **ऊर्जा के संरक्षण** को व्यक्त करता है (आरंभ बिंदु पर लौटने वाले आवेश की स्थितिज ऊर्जा में कोई नेट
परिवर्तन नहीं होना चाहिए)।

**व्हीटस्टोन सेतु — संतुलन शर्त।**

*परिपथ:* चतुर्भुज ABCD खींचिए, AB में P, BC में Q, AD में R, DC में S; B और D के बीच धारामापी G; A और C
के बीच कुंजी सहित सेल।

संतुलन पर **धारामापी से कोई धारा नहीं बहती** (I_g = 0)। अतः A पर P से आती धारा I₁ आगे Q से जाती है, और
R से जाती धारा I₂ आगे S से।

**लूप ABDA** (A → B → D → A पर चलते हुए)। I_g = 0 होने से धारामापी शाखा कुछ योगदान नहीं देती, अतः P के
आड़े विभव-पात R के आड़े विभव-पात के बराबर होना चाहिए:

```
      I₁ P − I₂ R = 0
⟹     I₁ P = I₂ R                    …(i)
```

**लूप BCDB** (B → C → D → B पर चलते हुए):

```
      I₁ Q − I₂ S = 0
⟹     I₁ Q = I₂ S                    …(ii)
```

**(i) को (ii) से भाग देने पर:**

```
      (I₁ P)/(I₁ Q) = (I₂ R)/(I₂ S)
⟹     P/Q = R/S
```

यह **व्हीटस्टोन सेतु की संतुलन शर्त** है। ∎

**यह उपयोगी क्यों है।** इस शर्त में सेल का विद्युत वाहक बल या धारामापी का प्रतिरोध नहीं आता, अतः तीन
ज्ञात प्रतिरोधों से अज्ञात प्रतिरोध यथार्थ रूप से ज्ञात किया जा सकता है। **शून्य विधि** होने के कारण इसकी
यथार्थता केवल शून्य विक्षेप पहचानने पर निर्भर है, मीटर के अंशांकन पर नहीं।

### Q3 — ρ = m/(ne²τ) द्वारा प्रतिरोधकता की ताप-निर्भरता

```
      ρ = m / (n e² τ)
```

अतः ρ ताप पर केवल **n** (मुक्त आवेश वाहकों का संख्या घनत्व) और **τ** (शिथिलन काल) के माध्यम से निर्भर
करता है।

**धातुएँ।** मुक्त इलेक्ट्रॉनों का संख्या घनत्व n वस्तुतः **नियत** है — वह परमाणुओं की संख्या से तय होता
है और ताप के साथ ध्यान देने योग्य रूप से नहीं बदलता। T बढ़ने पर जालक आयन अधिक प्रबलता से कंपन करते हैं,
अतः इलेक्ट्रॉन **अधिक बार** टकराते हैं, और **τ घटता** है। n नियत और τ घटने से ρ = m/(ne²τ) **बढ़ता** है।
अतः धातुओं के लिए α > 0।

**अर्धचालक।** यहाँ कम ताप पर n छोटा है, क्योंकि मुक्त होने के लिए इलेक्ट्रॉनों को ऊर्जा अंतराल पार करने
के लिए तापीय उत्तेजन चाहिए। T बढ़ने पर **n बहुत तेज़ी से बढ़ता** है (लगभग चरघातांकी रूप से)। τ धातु की
तरह अब भी घटता है, पर **n की वृद्धि उस पर कहीं भारी पड़ती है**। अतः ρ = m/(ne²τ) तीव्रता से **घटता** है।
अतः अर्धचालकों के लिए α < 0।

**ग्राफ़:**

```
   ρ │        धातु                       ρ │  अर्धचालक
     │       ╱                             │╲
     │      ╱                              │ ╲
     │     ╱     ρ बढ़ता है,               │  ╲
     │    ╱      लगभग रैखिक रूप से         │   ╲___   ρ तीव्रता से घटता है
     │   ╱                                 │       ‾‾‾───────
   ρ₀●──                                   │
     └────────────────── T                 └────────────────── T
```

*(दोनों अक्षों पर नाम लिखिए, और धातु के ग्राफ़ पर ρ₀ अंकित कीजिए।)*

### Q4 — पार्श्व में दो सेल

*आरेख:* दो सेल (ε₁, r₁) तथा (ε₂, r₂) एक ही दो बिंदुओं A और B के बीच जुड़े, और B से कुल धारा I निकलती।

मान लीजिए दोनों सेल बिंदुओं A और B के बीच जुड़े हैं, उनसे धाराएँ I₁ तथा I₂ बह रही हैं, और A तथा B के बीच
सिरों का विभवांतर V है।

**प्रत्येक सेल के लिए** (दोनों निरावेशित हो रहे हैं, धारा A से B की ओर चला रहे हैं):

```
      V = ε₁ − I₁ r₁          ⟹     I₁ = (ε₁ − V)/r₁
      V = ε₂ − I₂ r₂          ⟹     I₂ = (ε₂ − V)/r₂
```

**संधि नियम से**, कुल धारा

```
      I = I₁ + I₂
        = (ε₁ − V)/r₁ + (ε₂ − V)/r₂
        = (ε₁/r₁ + ε₂/r₂) − V(1/r₁ + 1/r₂)
```

V के लिए पुनर्व्यवस्थित करने पर:

```
      V (1/r₁ + 1/r₂) = (ε₁/r₁ + ε₂/r₂) − I
```

```
      V = (ε₁/r₁ + ε₂/r₂)/(1/r₁ + 1/r₂)  −  I · 1/(1/r₁ + 1/r₂)
```

```
      V = (ε₁r₂ + ε₂r₁)/(r₁ + r₂)  −  I · [ r₁r₂/(r₁ + r₂) ]
```

एकल सेल के मानक रूप V = ε_tulya − I r_tulya से तुलना करने पर:

```
      ε_tulya = (ε₁r₂ + ε₂r₁)/(r₁ + r₂)

      r_tulya = r₁r₂/(r₁ + r₂)          अर्थात्     1/r_tulya = 1/r₁ + 1/r₂
```

∎

*(जाँच: यदि दोनों सेल समरूप हों, ε₁ = ε₂ = ε और r₁ = r₂ = r, तो ε_tulya = ε और r_tulya = r/2 —
विद्युत वाहक बल अपरिवर्तित पर आंतरिक प्रतिरोध आधा, और ठीक इसीलिए सेल पार्श्व में जोड़े जाते हैं।)*

### Q6 — गतिशीलता

**परिभाषा।** आवेश वाहक की **गतिशीलता** प्रति इकाई आरोपित विद्युत क्षेत्र उसके अपवाह वेग का परिमाण है:

```
      μ = v_d / E
```

**SI मात्रक:** m² V⁻¹ s⁻¹।

**शिथिलन काल पर निर्भरता।** चूँकि v_d = eEτ/m,

```
      μ = (eEτ/m)/E = e τ / m
```

अतः **गतिशीलता शिथिलन काल τ के सीधे समानुपाती** है (और वाहक के द्रव्यमान के व्युत्क्रमानुपाती)। टकरावों
के बीच अधिक औसत समय का अर्थ है वाहक अधिक देर तक त्वरित हो सकता है, जिससे उसी क्षेत्र पर अधिक अपवाह वेग
मिलता है।

### Q7 — मीटर सेतु

*परिपथ:* 1 m का एकसमान तार AC, बाईं रिक्ति में अज्ञात R, दाईं रिक्ति में S = 6 Ω, B पर सर्पी और
धारामापी।

```
      R/S = l/(100 − l)
```

l = 40 cm तथा S = 6 Ω के साथ:

```
      R = S · l/(100 − l)
        = 6 × 40/(100 − 40)
        = 6 × 40/60
        = 4 Ω
```

**R = 4 Ω**

**संतुलन बिंदु मध्य के पास क्यों होना चाहिए।** सेतु **सर्वाधिक सुग्राही** तब होता है जब चारों प्रतिरोध
तुलनीय परिमाण के हों, जो तार के मध्य बिंदु के पास संतुलन बिंदु के संगत है। सिरों के पास सर्पी की स्थिति
में छोटा परिवर्तन अनुपात l/(100 − l) में बहुत ही छोटा परिवर्तन करता है, अतः शून्य बिंदु ठीक-ठीक ढूँढ़ना
कठिन हो जाता है और R में त्रुटि बड़ी होती है। मध्य के पास काम करने से तार तथा जोड़ने वाली पट्टियों के
**सिरा प्रतिरोधों** का प्रभाव भी न्यूनतम हो जाता है।

### Q8 — तार को खींचकर दोगुनी लंबाई

*(दिया है: मूल प्रतिरोध R।)*

तार खींचने पर उसका **आयतन अपरिवर्तित** रहता है (पदार्थ संरक्षित है)। मान लीजिए मूल लंबाई और क्षेत्रफल
l तथा A हैं; खींचने के बाद लंबाई 2l है और नया क्षेत्रफल A′।

```
      आयतन नियत:   l A = (2l) A′
⟹     A′ = A/2
```

नया प्रतिरोध:

```
      R′ = ρ (2l)/(A/2) = 4 · (ρ l/A) = 4R
```

**नया प्रतिरोध 4R है।**

**स्पष्टीकरण।** प्रतिरोध **दो** कारणों से एक साथ बढ़ता है: लंबाई दोगुनी होती है (R ∝ l), और अनुप्रस्थ काट
का क्षेत्रफल आधा होता है (R ∝ 1/A)। दोनों प्रभाव गुणित होकर 4 का गुणक देते हैं।

*(व्यापक रूप से, n गुनी लंबाई तक खींचने पर **n²R** मिलता है।)*

### Q9 — V–I ग्राफ़

```
  (i) ओमीय चालक                    (ii) अर्धचालक डायोड
   I │        ╱                     I │              ╱
     │      ╱                         │             │
     │    ╱   मूल बिंदु से            │            ╱   अग्र अभिनति:
     │  ╱     जाती सरल रेखा           │        ___╱    घुटना वोल्टता के बाद
     │╱       प्रवणता = 1/R           │  ─────╯        तीव्र वृद्धि
  ───●────────── V              ──────●────────────── V
     │╱                          उत्क्रम│  (अत्यंत छोटी, लगभग
     │                           अभिनति │   नियत धारा)
```

**एक अंतर:** ओमीय चालक का ग्राफ़ **मूल बिंदु से जाती सरल रेखा** है, अतः अनुपात V/I — प्रतिरोध —
**नियत** है। डायोड का ग्राफ़ **अरैखिक** है और अग्र तथा उत्क्रम अभिनति में भिन्न है, अतः प्रतिरोध
**नियत नहीं** है; साथ ही वह ध्यान देने योग्य चालन केवल एक दिशा में करता है।

### Q10 — गरम करने पर धातु का प्रतिरोध

**उत्तर: (a) बढ़ता है**

धातु के लिए n वस्तुतः नियत है और ताप के साथ τ घटता है, अतः ρ = m/(ne²τ) बढ़ता है, और इसलिए R = ρl/A भी।

### Q11 — प्रकरण अध्ययन: सेल का V–I ग्राफ़

सिरों के विभवांतर और धारा के बीच संबंध है

```
      V = ε − I r
```

जो V तथा I में एक सरल रेखा है।

**(i) V-अक्ष पर अंतःखंड** V का वह मान है जब I = 0, जो **सेल का विद्युत वाहक बल** है।

```
      ε = 1.5 V
```

**(ii) प्रवणता का परिमाण** r है, **सेल का आंतरिक प्रतिरोध**।

```
      r = 0.4 Ω
```

*(प्रवणता ऋणात्मक है, क्योंकि I बढ़ने पर V गिरता है; परिमाण r है।)*

**(iii) रेखा का समीकरण:**

```
      V = 1.5 − 0.4 I
```

**(iv) लघुपथन** का अर्थ है बाहरी प्रतिरोध शून्य, अतः V = 0:

```
      0 = 1.5 − 0.4 I
⟹     I = 1.5/0.4 = 3.75 A
```

**लघुपथन धारा 3.75 A है** — जो अपेक्षा के अनुरूप ε/r ही है।

### Q12 — श्रेणी–पार्श्व परिपथ पर किरखॉफ़ के नियम

*परिपथ:* 10 V का सेल (आंतरिक प्रतिरोध उपेक्षणीय), फिर 2 Ω प्रतिरोध, फिर 4 Ω तथा 6 Ω का पार्श्व युग्म,
और वापस सेल तक।

**चरण 1 — पार्श्व संयोजन।**

```
      1/R_p = 1/4 + 1/6 = 3/12 + 2/12 = 5/12
⟹     R_p = 12/5 = 2.4 Ω
```

**चरण 2 — कुल प्रतिरोध और मुख्य धारा।**

```
      R_कुल = 2 + 2.4 = 4.4 Ω
      I = ε/R_कुल = 10/4.4 = 2.27 A
```

**चरण 3 — पार्श्व भाग के आड़े विभवांतर।**

```
      V_p = I R_p = (2.27)(2.4) = 5.45 V
```

*(समकक्ष रूप से, 2 Ω प्रतिरोध के आड़े पात (2.27)(2) = 4.55 V है, और 10 − 4.55 = 5.45 V ✓ — यही
किरखॉफ़ का लूप नियम है।)*

**चरण 4 — शाखा धाराएँ** (प्रत्येक शाखा के आड़े पूरा 5.45 V है, क्योंकि वे पार्श्व में हैं):

```
      I₄ = 5.45/4 = 1.36 A
      I₆ = 5.45/6 = 0.91 A
```

*संधि नियम से जाँच:* I₄ + I₆ = 1.36 + 0.91 = 2.27 A = I ✓

**धाराएँ: 2 Ω से 2.27 A, 4 Ω से 1.36 A, तथा 6 Ω से 0.91 A।**

*(ध्यान दें कि छोटा प्रतिरोध बड़ी धारा ले जाता है — पार्श्व में I ∝ 1/R।)*
