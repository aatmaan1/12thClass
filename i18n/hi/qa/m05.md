### Q1 — x = 2 पर सांतत्य के लिए k

x = 2 पर सांतत्य के लिए हमें LHL = RHL = f(2) चाहिए।

```
f(2) = k(2)² = 4k          [x ≤ 2 वाली शाखा से]

LHL = lim  f(2 − h) = lim  k(2 − h)² = 4k
      h→0⁺              h→0⁺

RHL = lim  f(2 + h) = lim  3 = 3
      h→0⁺              h→0⁺
```

LHL = RHL रखने पर:

```
      4k = 3
⟹     k = 3/4
```

**k = 3/4** (और तब f(2) = 4(3/4) = 3, अतः तीनों मेल खाते हैं ✓)।

### Q2 — x = π/2 पर सांतत्य के लिए k

```
f(π/2) = 3
```

सीमा के लिए **x = π/2 + h** रखिए, जिससे x → π/2 पर h → 0:

```
cos x = cos(π/2 + h) = −sin h
π − 2x = π − 2(π/2 + h) = π − π − 2h = −2h
```

अतः

```
lim f(x) = lim  [ k(−sin h) ] / (−2h)
x→π/2      h→0

         = lim  (k/2) · (sin h / h)
           h→0

         = (k/2) · 1                 [क्योंकि lim (sin h)/h = 1]
         = k/2
```

सांतत्य के लिए यह सीमा f(π/2) = 3 के बराबर होनी चाहिए:

```
      k/2 = 3
⟹     k = 6
```

**k = 6**

> x = π/2 + h का प्रतिस्थापन ही पूरी युक्ति है। सीमा सीधे निकालने पर 0/0 मिलता है और बात आगे नहीं बढ़ती।

### Q3 — y = xˣ का अवकलन

न घात नियम लागू होता है न चरघातांकी नियम, क्योंकि चर आधार और घातांक दोनों में है।
**लघुगणकीय अवकलन** का उपयोग कीजिए।

```
      y = xˣ
⟹     log y = x log x
```

दोनों पक्षों का x के सापेक्ष अवकलन:

```
      (1/y) (dy/dx) = (1)(log x) + x(1/x)          [दाईं ओर गुणनफल नियम]
⟹     (1/y) (dy/dx) = log x + 1
⟹     dy/dx = y (1 + log x)
```

**dy/dx = xˣ (1 + log x)**

### Q4 — यदि xʸ = yˣ, तो dy/dx

दोनों पक्षों का लघुगणक लीजिए:

```
      y log x = x log y
```

दोनों पक्षों का x के सापेक्ष अवकलन (प्रत्येक पक्ष पर गुणनफल नियम, log y पर शृंखला नियम):

```
      (dy/dx) log x + y·(1/x)  =  (1) log y + x·(1/y)(dy/dx)
```

dy/dx वाले पद बाईं ओर इकट्ठे कीजिए:

```
      (dy/dx) log x − (x/y)(dy/dx)  =  log y − y/x
⟹     (dy/dx) [ log x − x/y ]  =  log y − y/x
```

प्रत्येक कोष्ठक को समान हर पर लाइए:

```
      log x − x/y = (y log x − x)/y
      log y − y/x = (x log y − y)/x
```

अतः

```
      dy/dx = [ (x log y − y)/x ] × [ y/(y log x − x) ]
```

```
dy/dx = y (x log y − y) / [ x (y log x − x) ]
```

### Q5 — y = (sin⁻¹x)² ⟹ (1 − x²)y″ − xy′ − 2 = 0

**एक बार अवकलन:**

```
      y = (sin⁻¹x)²
⟹     dy/dx = 2 sin⁻¹x · 1/√(1 − x²)
```

**मूल हटाइए:**

```
      √(1 − x²) · dy/dx = 2 sin⁻¹x
```

**दोनों पक्षों का वर्ग कीजिए** (यही मुख्य चाल है — इससे sin⁻¹x हटकर y आ जाता है):

```
      (1 − x²) (dy/dx)² = 4 (sin⁻¹x)² = 4y
```

**फिर से अवकलन** x के सापेक्ष, बाईं ओर गुणनफल नियम से:

```
      (1 − x²) · 2 (dy/dx)(d²y/dx²)  +  (dy/dx)² · (−2x)  =  4 (dy/dx)
```

**पूरे को 2(dy/dx) से भाग दीजिए** (वैध है क्योंकि साधारणतः dy/dx ≠ 0):

```
      (1 − x²) (d²y/dx²) − x (dy/dx) = 2
⟹     (1 − x²) (d²y/dx²) − x (dy/dx) − 2 = 0
```

**अतः सिद्ध हुआ।** ∎

### Q6 — y = e^(a cos⁻¹x) ⟹ (1 − x²)y″ − xy′ − a²y = 0

**एक बार अवकलन:**

```
      dy/dx = e^(a cos⁻¹x) · a · ( −1/√(1 − x²) )
            = −a y / √(1 − x²)                       [क्योंकि e^(a cos⁻¹x) = y]
```

**मूल हटाइए:**

```
      √(1 − x²) · dy/dx = −a y
```

**दोनों पक्षों का वर्ग:**

```
      (1 − x²) (dy/dx)² = a² y²
```

**फिर से अवकलन:**

```
      (1 − x²) · 2 (dy/dx)(d²y/dx²)  +  (dy/dx)² (−2x)  =  a² · 2y (dy/dx)
```

**पूरे को 2(dy/dx) से भाग:**

```
      (1 − x²)(d²y/dx²) − x (dy/dx) = a² y
⟹     (1 − x²)(d²y/dx²) − x (dy/dx) − a² y = 0
```

**अतः सिद्ध हुआ।** ∎

> Q5 और Q6 *वही* प्रश्न हैं, केवल बाहरी फलन भिन्न है। ढाँचा पहचानिए — भीतर प्रतिलोम त्रिकोणमितीय, फिर
> अवकलन/मूल हटाना/वर्ग/अवकलन/भाग — और यह पूरा परिवार एक ही विधि बन जाता है। अन्य सदस्य: y = (tan⁻¹x)²,
> y = e^(m sin⁻¹x), y = (log(x + √(1+x²)))²।

### Q7 — प्राचलिक: x = a(θ − sin θ), y = a(1 − cos θ)

```
dx/dθ = a(1 − cos θ)
dy/dθ = a(0 + sin θ) = a sin θ
```

```
dy/dx = (dy/dθ) / (dx/dθ) = a sin θ / [ a(1 − cos θ) ] = sin θ / (1 − cos θ)
```

अर्ध-कोण सर्वसमिकाओं sin θ = 2 sin(θ/2) cos(θ/2) तथा 1 − cos θ = 2 sin²(θ/2) से सरल कीजिए:

```
dy/dx = [ 2 sin(θ/2) cos(θ/2) ] / [ 2 sin²(θ/2) ] = cos(θ/2)/sin(θ/2)
```

**dy/dx = cot(θ/2)**

### Q8 — sin y = x sin(a + y) ⟹ dy/dx = sin²(a + y)/sin a

दिए संबंध से पहले x को अलग कीजिए:

```
      x = sin y / sin(a + y)
```

**x का y के सापेक्ष** अवकलन कीजिए (यहाँ यह उलटे की तुलना में आसान है), भागफल नियम से:

```
dx/dy = [ cos y · sin(a + y)  −  sin y · cos(a + y) ] / sin²(a + y)
```

अंश ज्या-अंतर सूत्र sin(A − B) = sin A cos B − cos A sin B है, जिसमें A = a + y तथा B = y:

```
      cos y sin(a + y) − sin y cos(a + y) = sin((a + y) − y) = sin a
```

अतः

```
      dx/dy = sin a / sin²(a + y)
```

इसलिए

```
      dy/dx = 1 / (dx/dy) = sin²(a + y) / sin a
```

**अतः सिद्ध हुआ।** ∎

> x का y के सापेक्ष अवकलन करके व्युत्क्रम लेना अस्पष्ट अवकलन से पूरी तरह बचा देता है। जब भी कोई संबंध x को
> y के पदों में साफ़ रूप में दे, यही तेज़ रास्ता है।

### Q9 — tan⁻¹((1 − x)/(1 + x)) का अवकलन

मान लीजिए u = (1 − x)/(1 + x), अतः y = tan⁻¹u।

**चरण 1 — du/dx**, भागफल नियम से:

```
du/dx = [ (−1)(1 + x) − (1 − x)(1) ] / (1 + x)²
      = [ −1 − x − 1 + x ] / (1 + x)²
      = −2 / (1 + x)²
```

**चरण 2 — 1 + u² सरल कीजिए:**

```
1 + u² = 1 + (1 − x)²/(1 + x)²
       = [ (1 + x)² + (1 − x)² ] / (1 + x)²
       = [ (1 + 2x + x²) + (1 − 2x + x²) ] / (1 + x)²
       = (2 + 2x²) / (1 + x)²
       = 2(1 + x²) / (1 + x)²
```

**चरण 3 — शृंखला नियम:**

```
dy/dx = (1/(1 + u²)) · du/dx
      = [ (1 + x)² / (2(1 + x²)) ] · [ −2/(1 + x)² ]
      = −1/(1 + x²)
```

**dy/dx = −1/(1 + x²)**

### Q10 — x = 1 पर f(x) = |x − 1|

f को खंडशः लिखिए:

```
f(x) = { 1 − x,   x < 1
       { x − 1,   x ≥ 1
```

**x = 1 पर सांतत्य:**

```
f(1) = 0
LHL = lim (1 − (1 − h)) = lim h = 0
      h→0⁺                 h→0⁺
RHL = lim ((1 + h) − 1) = lim h = 0
      h→0⁺                 h→0⁺
```

तीनों 0 के बराबर हैं, अतः f, **x = 1 पर संतत** है। ✓

**x = 1 पर अवकलनीयता:**

```
LHD = lim  [ f(1 − h) − f(1) ] / (−h) = lim  [ h − 0 ] / (−h) = −1
      h→0⁺                                h→0⁺

RHD = lim  [ f(1 + h) − f(1) ] / h    = lim  [ h − 0 ] / h    = +1
      h→0⁺                                h→0⁺
```

चूँकि LHD = −1 ≠ +1 = RHD, अतः f, **x = 1 पर अवकलनीय नहीं** है।

**अतः f, x = 1 पर संतत है पर अवकलनीय नहीं** — जो दिखाता है कि सांतत्य से अवकलनीयता सिद्ध नहीं होती।

### Q11 — y = x³ log x, d²y/dx² ज्ञात करना

**प्रथम अवकलज** (गुणनफल नियम):

```
dy/dx = 3x² log x + x³ · (1/x) = 3x² log x + x²
```

**द्वितीय अवकलज** (पहले पद पर गुणनफल नियम):

```
d²y/dx² = [ 6x log x + 3x² · (1/x) ] + 2x
        = 6x log x + 3x + 2x
```

**d²y/dx² = 6x log x + 5x = x(6 log x + 5)**

### Q12 — x = 3 पर (x² − 9)/(x − 3) का सांतत्य

```
f(3) = 6                     [दिया गया]

lim  f(x) = lim  (x² − 9)/(x − 3)
x→3          x→3

          = lim  (x − 3)(x + 3)/(x − 3)
            x→3

          = lim  (x + 3)               [काटना वैध है, क्योंकि सीमा में x ≠ 3]
            x→3

          = 6
```

चूँकि lim f(x) = 6 = f(3), अतः **f, x = 3 पर संतत है**।

### Q13 — अभिकथन–कारण

**A:** "f(x) = |x|, x = 0 पर अवकलनीय है।" **असत्य** — LHD = −1, RHD = +1।

**R:** "प्रत्येक संतत फलन अवकलनीय होता है।" **असत्य** — निष्पत्ति उलटी दिशा में चलती है; 0 पर |x| ही
प्रति-उदाहरण है।

**उत्तर: A असत्य है और R असत्य है।**

*(सत्य कथन उसका विलोम है: प्रत्येक अवकलनीय फलन संतत होता है।)*

### Q14 — y = sin(cos(x²))

तीन परतें हैं, अतः शृंखला नियम दो बार। बाहर से भीतर की ओर चलिए:

```
dy/dx = cos(cos(x²)) · d/dx[cos(x²)]
      = cos(cos(x²)) · (−sin(x²)) · d/dx[x²]
      = cos(cos(x²)) · (−sin(x²)) · 2x
```

**dy/dx = −2x sin(x²) cos(cos(x²))**
