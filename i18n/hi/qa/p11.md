### Q1 — आइंस्टाइन का समीकरण और दो नियम

**आइंस्टाइन का प्रकाश-विद्युत समीकरण।** विकिरण फ़ोटॉनों से बना है, प्रत्येक की ऊर्जा hν। प्रकाश-उत्सर्जन
में **एक फ़ोटॉन एक इलेक्ट्रॉन द्वारा अवशोषित** होता है। फ़ोटॉन की ऊर्जा का एक भाग, जो कार्य फलन φ₀ के
बराबर है, इलेक्ट्रॉन को धातु के पृष्ठ से मुक्त करने में लगता है, और शेष इलेक्ट्रॉन की गतिज ऊर्जा के रूप
में प्रकट होता है:

```
      h ν = φ₀ + K_max                      या          K_max = h ν − φ₀
```

चूँकि K_max = eV₀, इसे eV₀ = hν − φ₀ भी लिखा जा सकता है।

**(i) देहली आवृत्ति का अस्तित्व।**

गतिज ऊर्जा ऋणात्मक नहीं हो सकती, अतः उत्सर्जन तभी संभव है जब

```
      h ν − φ₀ ≥ 0
⟹     ν ≥ φ₀/h
```

ν₀ = φ₀/h परिभाषित करने पर, उत्सर्जन **केवल तब होता है जब ν ≥ ν₀**। यदि ν < ν₀ हो, तो एक अकेला फ़ोटॉन
इलेक्ट्रॉन मुक्त करने के लिए पर्याप्त ऊर्जा ही नहीं रखता — और चूँकि प्रक्रिया एक फ़ोटॉन प्रति इलेक्ट्रॉन
है, **तीव्रता** बढ़ाने से केवल ऐसे **अधिक** अपर्याप्त फ़ोटॉन मिलते हैं, कोई अधिक ऊर्जावान फ़ोटॉन नहीं। अतः
**ν₀ से नीचे कोई उत्सर्जन नहीं होता, प्रकाश चाहे कितना ही तीव्र हो**। यही देहली आवृत्ति है।

**(ii) K_max तीव्रता से स्वतंत्र क्यों है।**

```
      K_max = h ν − φ₀
```

दाएँ पक्ष में **केवल आवृत्ति ν और पदार्थ का नियतांक φ₀** हैं — तीव्रता आती ही नहीं।

भौतिक रूप से: **तीव्रता प्रति सेकंड आने वाले फ़ोटॉनों की संख्या तय करती है**, प्रत्येक फ़ोटॉन की ऊर्जा
नहीं। प्रत्येक इलेक्ट्रॉन ठीक **एक** फ़ोटॉन अवशोषित करता है, जिसकी ऊर्जा hν है। अतः तीव्रता बढ़ाने से
प्रकाश-इलेक्ट्रॉनों की **संख्या** (और अतः प्रकाश-धारा) बढ़ती है, पर प्रत्येक को उपलब्ध ऊर्जा — और अतः
K_max — अपरिवर्तित रहती है।

### Q2 — निरोधी विभव बनाम आवृत्ति ग्राफ़

आइंस्टाइन के समीकरण eV₀ = hν − φ₀ से,

```
      V₀ = (h/e) ν − φ₀/e
```

जो V₀ तथा ν में एक **सरल रेखा** है।

**ग्राफ़** (दो धातुओं A तथा B के लिए, जहाँ φ₀A < φ₀B):

```
   V₀ │                     ╱ A         ╱ B
      │                   ╱           ╱
      │                 ╱           ╱        (दोनों रेखाएँ समांतर हैं)
      │               ╱           ╱
   ───┼─────────────●───────────●──────────────→ ν
      │           ν₀A         ν₀B
      │         ╱
 −φ₀/e│       ╱
```

**प्रवणता किसे दर्शाती है।** y = mx + c से तुलना करने पर प्रवणता

```
      प्रवणता = h/e
```

अर्थात् **प्लांक नियतांक और इलेक्ट्रॉनिक आवेश** का अनुपात। महत्वपूर्ण बात यह है कि यह दो **सार्वत्रिक
नियतांकों** का संयोजन है, अतः प्रवणता **हर धातु के लिए समान** होती है — दोनों रेखाएँ समांतर हैं।
(इसी से मिलिकन ने पहली बार h का यथार्थ मान नापा था।)

**कार्य फलन कैसे प्राप्त होता है।**

दो समकक्ष तरीके:
1. **V₀-अक्ष पर अंतःखंड** से, जो **−φ₀/e** के बराबर है। अतः φ₀ = e × (y-अंतःखंड का परिमाण)।
2. **ν-अक्ष पर अंतःखंड** से, जो देहली आवृत्ति ν₀ है, क्योंकि वहाँ V₀ = 0। तब φ₀ = **h ν₀**।

**बड़े कार्य फलन** वाली धातु की **देहली आवृत्ति बड़ी** होती है, अतः उसकी रेखा **दाईं** ओर खिसकी होती है
— इस ग्राफ़ पर दोनों धातुओं में यही एकमात्र अंतर है।

### Q3 — प्रकाश-धारा बनाम संग्राहक विभव ग्राफ़

**(i) नियत आवृत्ति पर भिन्न तीव्रताएँ:**

```
     I │                 ─────────── I₃
       │               ╱
       │           ─────────────── I₂
       │         ╱   ╱
       │     ──────────────── I₁
       │   ╱   ╱   ╱
   ────┴───────────────────────────→  V
     −V₀      0
       ↑
   तीनों के लिए वही निरोधी विभव
```

**(ii) नियत तीव्रता पर भिन्न आवृत्तियाँ:**

```
     I │            ──────────────── (सभी वही संतृप्ति धारा तक पहुँचते हैं)
       │        ╱  ╱  ╱
       │      ╱  ╱  ╱
       │    ╱  ╱  ╱
   ────┴───┴──┴──┴────────────────→  V
    −V₀₃ −V₀₂ −V₀₁  0
                       ν₃ > ν₂ > ν₁
```

**मूल अंतर।**

| | भिन्न **तीव्रताएँ**, वही ν | भिन्न **आवृत्तियाँ**, वही तीव्रता |
| --- | --- | --- |
| संतृप्ति धारा | **भिन्न** — अधिक तीव्रता पर अधिक | सभी के लिए **समान** |
| निरोधी विभव | सभी के लिए **समान** | **भिन्न** — अधिक आवृत्ति पर अधिक |

**क्यों:** **संतृप्ति धारा** प्रति सेकंड प्रकाश-इलेक्ट्रॉनों की *संख्या* नापती है, जो प्रति सेकंड
**फ़ोटॉनों की संख्या**, अर्थात् **तीव्रता** से तय होती है। **निरोधी विभव** K_max = hν − φ₀ नापता है, जो
केवल **आवृत्ति** से तय होता है।

अतः पहला ग्राफ़ फ़ोटॉनों की संख्या बदलता है (धारा बदलती है, उनकी ऊर्जा नहीं), और दूसरा प्रति फ़ोटॉन ऊर्जा
बदलता है (अधिकतम गतिज ऊर्जा बदलती है, संख्या नहीं)।

### Q5 — कार्य फलन और देहली आवृत्ति

**कार्य फलन (φ₀)।** किसी धातु के पृष्ठ से इलेक्ट्रॉन को ठीक मुक्त करने के लिए, अर्थात् उसे शून्य गतिज
ऊर्जा के साथ पृष्ठ तक लाने के लिए आवश्यक **न्यूनतम ऊर्जा**। यह **धातु का अभिलक्षण** है और आमतौर पर
इलेक्ट्रॉन-वोल्ट में व्यक्त किया जाता है।

**देहली आवृत्ति (ν₀)।** आपाती विकिरण की वह **न्यूनतम आवृत्ति** जिससे नीचे किसी दी गई धातु से
प्रकाश-विद्युत उत्सर्जन **नहीं** होता, विकिरण की तीव्रता चाहे कितनी ही अधिक हो।

**उनके बीच संबंध:**

```
      φ₀ = h ν₀                     (और समकक्ष रूप से φ₀ = h c/λ₀)
```

### Q6 — प्रकाश-विद्युत संख्यात्मक

```
      φ₀ = 2.14 eV          λ = 500 nm
```

**(i) देहली तरंगदैर्ध्य।** hc = 1240 eV nm लेकर:

```
      λ₀ = h c/φ₀ = 1240/2.14 = 579 nm
```

**λ₀ ≈ 579 nm**

*(चूँकि आपाती λ = 500 nm, λ₀ = 579 nm से **कम** है, आपाती आवृत्ति देहली से अधिक है, अतः उत्सर्जन होता है
✓ — यह लिखना चाहिए।)*

**(ii) अधिकतम गतिज ऊर्जा।**

आपाती फ़ोटॉन की ऊर्जा:

```
      E = h c/λ = 1240/500 = 2.48 eV
```

```
      K_max = E − φ₀ = 2.48 − 2.14 = 0.34 eV
```

**K_max = 0.34 eV** (= 0.34 × 1.6 × 10⁻¹⁹ = 5.44 × 10⁻²⁰ J)

**(iii) निरोधी विभव।**

```
      e V₀ = K_max
⟹     V₀ = K_max/e = 0.34 eV/e = 0.34 V
```

**V₀ = 0.34 V**

> ध्यान दीजिए कि **hc = 1240 eV nm** का शॉर्टकट पूरे प्रश्न को दस की घातों के बिना तीन पंक्तियों की
> गणित बना देता है। और ध्यान दें कि जब K_max **eV** में व्यक्त हो, तो निरोधी विभव **वोल्ट** में संख्या
> के रूप में वही होता है — क्योंकि eV₀ = K_max।

### Q7 — त्वरित इलेक्ट्रॉन की दे ब्रॉग्ली तरंगदैर्ध्य

```
      V = 100 V
```

कार्यसाधक सूत्र का उपयोग करने पर:

```
      λ = 12.27/√V  Å
        = 12.27/√100
        = 12.27/10
        = 1.227 Å
```

**λ = 1.227 Å = 1.227 × 10⁻¹⁰ m ≈ 0.123 nm**

*(पूरी विधि, यदि सूत्र न लिखा जाए:
p = √(2meV) = √(2 × 9.1 × 10⁻³¹ × 1.6 × 10⁻¹⁹ × 100) = √(2.912 × 10⁻⁴⁷) = 5.4 × 10⁻²⁴ kg m s⁻¹,
अतः λ = h/p = (6.63 × 10⁻³⁴)/(5.4 × 10⁻²⁴) = 1.23 × 10⁻¹⁰ m ✓)*

### Q8 — समान गतिज ऊर्जा वाले इलेक्ट्रॉन और प्रोटॉन

द्रव्यमान m तथा गतिज ऊर्जा K वाले कण के लिए,

```
      p = √(2 m K)                  ⟹      λ = h/p = h/√(2 m K)
```

अतः **समान गतिज ऊर्जा K** पर,

```
      λ ∝ 1/√m
```

इलेक्ट्रॉन का द्रव्यमान प्रोटॉन से कहीं कम है (m_p ≈ 1836 m_e), अतः

```
      λ_इलेक्ट्रॉन/λ_प्रोटॉन = √(m_p/m_e) = √1836 ≈ 43
```

**इलेक्ट्रॉन की दे ब्रॉग्ली तरंगदैर्ध्य अधिक है** — लगभग 43 गुना — क्योंकि समान गतिज ऊर्जा पर हलके कण का
संवेग कम होता है, और λ संवेग के व्युत्क्रमानुपाती है।

### Q11 — प्रकरण अध्ययन: V₀–ν ग्राफ़

```
      प्रवणता = 4.14 × 10⁻¹⁵ V s          ν-अंतःखंड = 5 × 10¹⁴ Hz
```

**(i) प्रवणता क्या देती है।** V₀ = (h/e)ν − φ₀/e से प्रवणता **h/e** है — प्लांक नियतांक और इलेक्ट्रॉनिक
आवेश का अनुपात।

**(ii) प्लांक नियतांक:**

```
      h/e = 4.14 × 10⁻¹⁵
⟹     h = (4.14 × 10⁻¹⁵)(1.6 × 10⁻¹⁹)
        = 6.62 × 10⁻³⁴ J s
```

**h ≈ 6.6 × 10⁻³⁴ J s** — स्वीकृत मान से अच्छा मेल।

**(iii) कार्य फलन।** ν-अंतःखंड देहली आवृत्ति ν₀ = 5 × 10¹⁴ Hz है, अतः

```
      φ₀ = h ν₀ = (6.62 × 10⁻³⁴)(5 × 10¹⁴) = 3.31 × 10⁻¹⁹ J
```

इलेक्ट्रॉन-वोल्ट में:

```
      φ₀ = (3.31 × 10⁻¹⁹)/(1.6 × 10⁻¹⁹) = 2.07 eV
```

**φ₀ ≈ 2.07 eV**

*(तेज़ रास्ता: φ₀/e = (h/e) × ν₀ = (4.14 × 10⁻¹⁵)(5 × 10¹⁴) = 2.07 V, अतः सीधे φ₀ = 2.07 eV।)*

**(iv) दूसरी धातु के लिए प्रवणता बदलेगी?**

**नहीं।** प्रवणता **h/e** है, जो दो **सार्वत्रिक नियतांकों** का संयोजन है, और उसमें धातु से जुड़ा कुछ भी
नहीं है। अतः किसी अन्य धातु का ग्राफ़ एक **समांतर** सरल रेखा होगा।

जो *बदलता* है वह **अंतःखंड** है: भिन्न धातु का कार्य फलन भिन्न होता है, अतः देहली आवृत्ति
ν₀ = φ₀/h भिन्न होगी, इसलिए उसकी रेखा क्षैतिज रूप से खिसक जाएगी। बड़े कार्य फलन वाली धातु की रेखा और
दाईं ओर खिसकी होगी।

### Q12 — फ़ोटॉन क्षेत्रों से क्यों विचलित नहीं होते

विद्युत तथा चुंबकीय क्षेत्रों में किसी कण पर बल

```
      F = q(E + v × B)
```

जो **आवेश q के समानुपाती** है।

फ़ोटॉन **विद्युत रूप से उदासीन** है — उस पर **शून्य आवेश** है। अतः किसी भी विद्युत या चुंबकीय क्षेत्र से
उस पर लगने वाला बल **शून्य** है, और वह ऐसे क्षेत्रों से बिना विचलित हुए गुज़र जाता है।

*(गामा किरणों को बीटा और अल्फ़ा विकिरण से अलग पहचानने का यह मानक तरीका है: चुंबकीय क्षेत्र से बिना विचलित
हुए केवल गामा किरणें गुज़रती हैं, क्योंकि वे फ़ोटॉन हैं।)*

### Q13 — अभिकथन–कारण

**A:** "देहली आवृत्ति से नीचे कोई प्रकाश-इलेक्ट्रॉन उत्सर्जित नहीं होते, प्रकाश चाहे कितना ही तीव्र हो।"
**सत्य** — यह चार प्रायोगिक नियमों में से एक है।

**R:** "प्रकाश-उत्सर्जन एक-फ़ोटॉन–एक-इलेक्ट्रॉन प्रक्रिया है, और कार्य फलन से कम ऊर्जा वाला एक अकेला
फ़ोटॉन इलेक्ट्रॉन मुक्त नहीं कर सकता।" **सत्य।**

**क्या R, A को समझाता है?** **हाँ** — और ठीक-ठीक। चूँकि प्रत्येक इलेक्ट्रॉन ठीक एक फ़ोटॉन अवशोषित करता
है, तीव्रता बढ़ाने से केवल फ़ोटॉनों की **संख्या** बढ़ती है, उनमें से किसी एक की ऊर्जा नहीं। यदि hν < φ₀
हो, तो किसी एक फ़ोटॉन में पर्याप्त ऊर्जा नहीं है, और उनकी कोई भी संख्या काम नहीं करेगी।

**उत्तर: (a) A और R दोनों सत्य हैं, और R, A का सही स्पष्टीकरण है।**
