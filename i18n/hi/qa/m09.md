### Q1 — कोटि तथा घात

**सर्वोच्च कोटि** का अवकलज d²y/dx² है, अतः **कोटि 2** है।

उसकी घात 1 है (वह d²y/dx² के रूप में आता है, वर्ग या घन नहीं), अतः **घात 1** है।

*((dy/dx)³ पद की घात 3 है, पर वह निम्न कोटि का अवकलज है और घात के लिए अप्रासंगिक है। इसी प्रकार 6y⁵ का
इससे कोई संबंध नहीं।)*

**उत्तर: (b) 2, 1**

### Q2 — sin(dy/dx) वाले समीकरण की घात

समीकरण में **sin(dy/dx)** है, अतः वह अवकलजों में बहुपदीय नहीं है।

**घात परिभाषित नहीं है।**

*(कोटि 2 है।)*

### Q3 — dy/dx = (1 + y²)/(1 + x²)

**पृथक्करणीय।**

```
      dy/(1 + y²) = dx/(1 + x²)
```

दोनों पक्षों का समाकलन:

```
      ∫ dy/(1 + y²) = ∫ dx/(1 + x²)
⟹     tan⁻¹y = tan⁻¹x + C
```

```
व्यापक हल:  tan⁻¹y − tan⁻¹x = C
```

### Q4 — dy/dx = y tan x का विशिष्ट हल, y(0) = 1 के साथ

**पृथक्करणीय।**

```
      dy/y = tan x dx
```

समाकलन:

```
      log|y| = log|sec x| + log C          [सुविधा के लिए अचर को log C लिखा]
⟹     log|y| = log|C sec x|
⟹     y = C sec x
```

**आरंभिक शर्त लगाइए** x = 0 पर y = 1। चूँकि sec 0 = 1:

```
      1 = C(1)   ⟹   C = 1
```

```
विशिष्ट हल:  y = sec x
```

> जब दोनों पक्ष लघुगणक हों, तब स्वेच्छ अचर को C के बजाय **log C** लिखने से एक अतिरिक्त घातांकी चरण बच
> जाता है। यह मानक है और अपेक्षित भी।

### Q5 — sec²x tan y dx + sec²y tan x dy = 0

**पृथक्करणीय।** पूरे को (tan x)(tan y) से भाग दीजिए:

```
      (sec²x / tan x) dx  +  (sec²y / tan y) dy = 0
```

प्रत्येक पद का समाकलन (पहले में t = tan x, दूसरे में t = tan y रखकर, जिससे क्रमशः dt = sec²x dx तथा
sec²y dy):

```
      log|tan x| + log|tan y| = log C
⟹     log|tan x · tan y| = log C
```

```
व्यापक हल:  tan x · tan y = C
```

### Q6 — x dy/dx − y = x²

**चरण 1 — मानक रूप।** पूरे को x से भाग दीजिए:

```
      dy/dx − y/x = x
```

अतः यह **रैखिक** है, जिसमें

```
      P = −1/x          Q = x
```

**चरण 2 — समाकलन गुणक।**

```
      I.F. = e^(∫P dx) = e^(∫ −dx/x) = e^(−log x) = e^(log(1/x)) = 1/x
```

**चरण 3 — हल का ढाँचा।**

```
      y · (I.F.) = ∫ Q · (I.F.) dx + C
⟹     y · (1/x) = ∫ x · (1/x) dx + C
⟹     y/x = ∫ 1 dx + C
⟹     y/x = x + C
```

**चरण 4 — y के लिए हल।**

```
व्यापक हल:  y = x² + Cx
```

*(जाँच: y′ = 2x + C, अतः x y′ − y = 2x² + Cx − x² − Cx = x² ✓)*

### Q7 — x dy/dx + 2y = x² log x

**चरण 1 — मानक रूप।** x से भाग:

```
      dy/dx + (2/x) y = x log x
```

```
      P = 2/x          Q = x log x
```

**चरण 2 — समाकलन गुणक।**

```
      I.F. = e^(∫ 2dx/x) = e^(2 log x) = e^(log x²) = x²
```

**चरण 3 — हल का ढाँचा।**

```
      y · x² = ∫ (x log x)(x²) dx + C = ∫ x³ log x dx + C
```

**∫x³ log x dx को खंडशः निकालिए** (ILATE: u = log x लीजिए):

```
      ∫ x³ log x dx = log x · (x⁴/4) − ∫ (1/x)(x⁴/4) dx
                    = (x⁴/4) log x − (1/4) ∫ x³ dx
                    = (x⁴/4) log x − x⁴/16
```

अतः

```
      y x² = (x⁴/4) log x − x⁴/16 + C
```

**चरण 4 — y के लिए हल** (x² से भाग):

```
व्यापक हल:  y = (x²/4) log x − x²/16 + C/x²
```

### Q8 — dy/dx + y cot x = 2 cos x

पहले से मानक रूप में है, जिसमें

```
      P = cot x          Q = 2 cos x
```

**समाकलन गुणक:**

```
      I.F. = e^(∫cot x dx) = e^(log|sin x|) = sin x
```

**हल का ढाँचा:**

```
      y sin x = ∫ (2 cos x)(sin x) dx + C
```

2 sin x cos x = sin 2x का उपयोग कीजिए:

```
      y sin x = ∫ sin 2x dx + C
              = −(cos 2x)/2 + C
```

```
व्यापक हल:  y sin x = −(cos 2x)/2 + C          अर्थात्  y = [C − ½cos 2x] / sin x
```

### Q9 — x² dy/dx = x² + xy + y²

**समघातीय पहचानिए।** पूरे को x² से भाग दीजिए:

```
      dy/dx = 1 + y/x + (y/x)²
```

दायाँ पक्ष केवल y/x पर निर्भर है, अतः समीकरण समघातीय है।

**y = vx रखिए**, अतः dy/dx = v + x(dv/dx):

```
      v + x dv/dx = 1 + v + v²
⟹     x dv/dx = 1 + v²
```

**पृथक कीजिए:**

```
      dv/(1 + v²) = dx/x
```

**समाकलन:**

```
      tan⁻¹v = log|x| + C
```

**v = y/x वापस रखिए:**

```
व्यापक हल:  tan⁻¹(y/x) = log|x| + C
```

### Q10 — (x − y) dy/dx = x + 2y

इसे इस रूप में लिखिए

```
      dy/dx = (x + 2y)/(x − y)
```

**समघातीयता जाँचिए:** अंश और हर को x से भाग देने पर,

```
      dy/dx = (1 + 2y/x)/(1 − y/x)
```

जो केवल y/x पर निर्भर है। **समघातीय।**

**y = vx, dy/dx = v + x dv/dx रखिए:**

```
      v + x dv/dx = (1 + 2v)/(1 − v)
```

```
      x dv/dx = (1 + 2v)/(1 − v) − v
              = [ (1 + 2v) − v(1 − v) ] / (1 − v)
              = [ 1 + 2v − v + v² ] / (1 − v)
              = (1 + v + v²)/(1 − v)
```

**पृथक कीजिए:**

```
      (1 − v)/(1 + v + v²) dv = dx/x
```

**बाएँ पक्ष का समाकलन।** ध्यान दें d/dv(1 + v + v²) = 1 + 2v, अतः लिखिए

```
      1 − v = −½(1 + 2v) + 3/2
```

*(जाँच: −½ − v + 3/2 = 1 − v ✓)*

```
      ∫ (1 − v)/(1 + v + v²) dv = −½ ∫ (1 + 2v)/(1 + v + v²) dv  +  (3/2) ∫ dv/(1 + v + v²)
```

**पहला भाग** (t = 1 + v + v² रखकर):

```
      = −½ log|1 + v + v²|
```

**दूसरा भाग:** वर्ग पूरा कीजिए, 1 + v + v² = (v + ½)² + 3/4 = (v + ½)² + (√3/2)²

```
      = (3/2) · (1/(√3/2)) tan⁻¹( (v + ½)/(√3/2) )
      = (3/2)(2/√3) tan⁻¹( (2v + 1)/√3 )
      = √3 tan⁻¹( (2v + 1)/√3 )
```

अतः

```
      −½ log|1 + v + v²| + √3 tan⁻¹( (2v + 1)/√3 ) = log|x| + C
```

**v = y/x वापस रखिए।** चूँकि 1 + y/x + y²/x² = (x² + xy + y²)/x²:

```
      −½ log| (x² + xy + y²)/x² |  +  √3 tan⁻¹( (2y + x)/(√3 x) )  =  log|x| + C
```

लघुगणक खोलने पर: −½log|x² + xy + y²| + log|x| = log|x| + C पुनर्व्यवस्थित होकर

```
व्यापक हल:  √3 tan⁻¹( (x + 2y)/(√3 x) )  −  ½ log|x² + xy + y²|  =  C
```

*(भिन्न पाठ्यपुस्तकें अचर को भिन्न ढंग से समाहित करके इसे प्रस्तुत करती हैं; कोई भी तुल्य रूप स्वीकार्य
है, बशर्ते कार्य दिखाया गया हो।)*

> यह CBSE जो पूछता है उसके कठिन सिरे पर है। सीखने योग्य तकनीक अंश का विभाजन है — (1 − v) को हर के अवकलज
> के गुणज तथा एक अचर के रूप में लिखना। यह [अध्याय 7](07-integrals.md) की "अंश तोड़िए" वाली वही युक्ति है।

### Q11 — (1 + x²)dy/dx + 2xy = 4x² का समाकलन गुणक

**मानक रूप:** (1 + x²) से भाग दीजिए:

```
      dy/dx + [2x/(1 + x²)] y = 4x²/(1 + x²)
```

```
      P = 2x/(1 + x²)
```

```
      I.F. = e^(∫ 2x dx/(1 + x²)) = e^(log(1 + x²)) = 1 + x²
```

**I.F. = 1 + x²**

> शॉर्टकट पर ध्यान दीजिए: जब भी समीकरण पहले से (गुणांक)·dy/dx + (उस गुणांक का अवकलज)·y = … के रूप में लिखा
> हो, तो गुणांक स्वयं **ही** समाकलन गुणक होता है। यहाँ d/dx(1 + x²) = 2x, जो ठीक y का गुणांक है।

### Q12 — प्रकरण अध्ययन: जीवाणु वृद्धि

**(i) अवकल समीकरण।**

"वृद्धि दर उपस्थित जनसंख्या के समानुपाती है" सीधे अनूदित होता है:

```
      dN/dt = kN                    जहाँ k > 0 समानुपात नियतांक है
```

**(ii) उसे हल कीजिए।**

पृथक्करणीय:

```
      dN/N = k dt
⟹     log N = kt + C₁
⟹     N = e^(kt + C₁) = A e^(kt)          जहाँ A = e^(C₁)
```

**t = 0 पर N = 1000 लगाइए:**

```
      1000 = A e⁰ = A     ⟹   A = 1000
⟹     N = 1000 e^(kt)
```

**t = 2 पर N = 2000 लगाइए:**

```
      2000 = 1000 e^(2k)
⟹     e^(2k) = 2
⟹     2k = log 2
⟹     k = (log 2)/2
```

```
      N(t) = 1000 e^( (t log 2)/2 )  =  1000 · 2^(t/2)
```

**(iii) 6 घंटे बाद जनसंख्या।**

```
      N(6) = 1000 · 2^(6/2) = 1000 · 2³ = 8000
```

**6 घंटे बाद जनसंख्या 8000 जीवाणु है।**

*(दोगुना होने का समय 2 घंटे है, अतः 6 घंटे में जनसंख्या तीन बार दोगुनी होती है: 1000 → 2000 → 4000 →
8000 ✓ — उपयोगी संगति जाँच।)*
