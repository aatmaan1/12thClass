### Q1 — आंशिक परावैद्युत पट्टी वाला समांतर पट्टिका संधारित्र

*आरेख:* d दूरी पर दो समांतर प्लेटें खींचिए, और उनके बीच परावैद्युतांक K तथा मोटाई t (t < d) की एक पट्टी,
जिससे कुल (d − t) मोटाई की वायु-रिक्तियाँ बचें।

मान लीजिए प्लेटों पर पृष्ठ आवेश घनत्व σ = Q/A है।

**वायु-रिक्तियों में क्षेत्र।** प्लेटों के बीच जहाँ परावैद्युत नहीं है:

```
      E₀ = σ/ε₀
```

**परावैद्युत के भीतर क्षेत्र।** ध्रुवित परावैद्युत एक विरोधी क्षेत्र उत्पन्न करता है, जिससे नेट क्षेत्र
K गुना घट जाता है:

```
      E = E₀/K = σ/(Kε₀)
```

**प्लेटों के आड़े विभवांतर** वायु-रिक्तियों और पट्टी के विभव-पातों का योग है। कुल वायु-पथ की मोटाई
(d − t) है और पट्टी की मोटाई t:

```
      V = E₀ (d − t)  +  E t
        = (σ/ε₀)(d − t)  +  (σ/Kε₀) t
        = (σ/ε₀) [ (d − t) + t/K ]
```

**σ = Q/A रखने पर:**

```
      V = (Q/Aε₀) [ (d − t) + t/K ]
```

**धारिता:**

```
      C = Q/V = Q / { (Q/Aε₀)[(d − t) + t/K] }
```

```
      C = ε₀A / [ d − t + t/K ]
```

**सीमांत स्थितियों की जाँच** (लिखने योग्य — यह समझ दर्शाती है):

- t = 0 (पट्टी नहीं): C = ε₀A/d ✓ — साधारण वायु संधारित्र।
- t = d (पट्टी पूरा अंतराल भरती है): C = ε₀A/(d/K) = **Kε₀A/d** ✓ — पूर्णतः परावैद्युत-भरा संधारित्र।

चूँकि K > 1, अतः t/K < t, इसलिए हर d से छोटा है — अतः **परावैद्युत डालने से धारिता सदैव बढ़ती है**। ∎

### Q2 — संधारित्र में संचित ऊर्जा, और ऊर्जा घनत्व

**व्युत्पत्ति।** संधारित्र को आवेशित करने का अर्थ है, बनते जा रहे विभवांतर के विरुद्ध एक प्लेट से दूसरी
पर आवेश स्थानांतरित करना। मान लीजिए किसी क्षण आवेश q है, अतः विभवांतर

```
      V′ = q/C
```

और dq अतिरिक्त सूक्ष्म आवेश को ले जाने में आवश्यक कार्य

```
      dW = V′ dq = (q/C) dq
```

संधारित्र को 0 से Q तक आवेशित करने का कुल कार्य:

```
      W = ∫[0,Q] (q/C) dq = (1/C) [ q²/2 ]₀^Q = Q²/(2C)
```

यह कार्य स्थिर-वैद्युत स्थितिज ऊर्जा के रूप में संचित होता है:

```
      U = Q²/(2C)  =  ½ CV²  =  ½ QV                (Q = CV लेकर)
```

**ऊर्जा घनत्व।** समांतर पट्टिका संधारित्र के लिए C = ε₀A/d तथा V = Ed। U = ½CV² में रखने पर:

```
      U = ½ (ε₀A/d)(Ed)² = ½ ε₀ A d E²
```

प्लेटों के बीच का आयतन (A d) है, अतः प्रति इकाई आयतन ऊर्जा

```
      u = U/(Ad) = ½ ε₀ E²
```

```
      ऊर्जा घनत्व  u = ½ ε₀ E²
```

यह परिणाम व्यापक है — यह कहीं भी स्थिर-वैद्युत क्षेत्र के लिए लागू होता है, केवल संधारित्र में नहीं। ∎

### Q3 — समविभव पृष्ठ

**परिभाषा।** समविभव पृष्ठ वह पृष्ठ है जिसके **प्रत्येक बिंदु पर विद्युत विभव का मान समान** होता है।

**गुणधर्म (कोई तीन):**

1. समविभव पृष्ठ के **अनुदिश** एक बिंदु से दूसरे तक आवेश ले जाने में **कोई कार्य नहीं** होता।
2. **विद्युत क्षेत्र प्रत्येक बिंदु पर समविभव पृष्ठ के सदैव लंबवत** होता है।
3. दो समविभव पृष्ठ **कभी एक-दूसरे को नहीं काट सकते**, क्योंकि किसी बिंदु के दो भिन्न विभव नहीं हो सकते।
4. जहाँ क्षेत्र प्रबल है वहाँ समविभव पृष्ठ **पास-पास** होते हैं और जहाँ क्षीण है वहाँ दूर-दूर।
5. एकाकी बिंदु आवेश के लिए वे **संकेंद्रीय गोले** हैं; एकसमान क्षेत्र के लिए क्षेत्र के लंबवत
   **समांतर समतल**।

**समविभव पृष्ठ के अनुदिश कार्य क्यों नहीं होता।**

विभवांतर ΔV में आवेश q ले जाने में किया गया कार्य

```
      W = q ΔV
```

समविभव पृष्ठ के अनुदिश सभी बिंदुओं का विभव समान है, अतः ΔV = 0, और इसलिए **W = 0**।

समकक्ष रूप से: चूँकि **E** पृष्ठ के लंबवत है, और विस्थापन d**s** पृष्ठ *में* ही है, अतः बल q**E**
विस्थापन के लंबवत है, इसलिए

```
      dW = qE · ds = qE ds cos 90° = 0
```

### Q4 — द्विध्रुव के कारण विभव, और निरक्षीय स्थिति

*आरेख:* A पर −q और B पर +q खींचिए, बीच की दूरी 2a, केंद्र O। बिंदु P को O से r दूरी पर अंकित कीजिए, जहाँ
OP द्विध्रुव अक्ष OB से θ कोण बनाता है। A और B से OP पर लंब डालिए।

मान लीजिए द्विध्रुव में A पर −q और B पर +q है, AB = 2a और केंद्र O। P, O से r दूरी पर है, और
∠POB = θ।

**दूरियाँ।** r >> a के लिए, A और B से रेखा OP पर लंब डालने से, अच्छे सन्निकटन में,

```
      BP ≈ r − a cos θ                AP ≈ r + a cos θ
```

**P पर विभव** — दोनों योगदानों का बीजगणितीय योग (विभव एक अदिश है):

```
      V = k [ q/BP  +  (−q)/AP ]
        = kq [ 1/(r − a cos θ)  −  1/(r + a cos θ) ]

        = kq [ ( (r + a cos θ) − (r − a cos θ) ) / ( r² − a² cos²θ ) ]

        = kq [ 2a cos θ / (r² − a² cos²θ) ]
```

r >> a के लिए हम a²cos²θ को r² की तुलना में उपेक्षित कर सकते हैं:

```
      V = kq (2a cos θ)/r²
```

चूँकि p = q(2a),

```
      V = (1/4πε₀) · p cos θ / r²
```

**निरक्षीय रेखा पर θ = 90°**, अतः cos θ = 0:

```
      V_निरक्षीय = 0
```

**अतः द्विध्रुव की निरक्षीय रेखा के प्रत्येक बिंदु पर विभव शून्य होता है।** ∎

*(भौतिक कारण: कोई भी निरक्षीय बिंदु +q और −q से **समान दूरी** पर है, अतः उनके विभव — परिमाण में समान,
चिह्न में विपरीत — ठीक-ठीक कट जाते हैं। ध्यान दें कि वहाँ *क्षेत्र* शून्य **नहीं** होता, क्योंकि क्षेत्र
सदिश हैं और दोनों योगदान नहीं कटते।)*

### Q5 — श्रेणी में दो संधारित्र

```
      C₁ = 2 μF          C₂ = 3 μF          V = 6 V
```

**(i) तुल्य धारिता (श्रेणी):**

```
      1/C = 1/C₁ + 1/C₂ = 1/2 + 1/3 = 5/6
⟹     C = 6/5 = 1.2 μF
```

```
      Q = C V = (1.2 × 10⁻⁶)(6) = 7.2 × 10⁻⁶ C = 7.2 μC
```

```
      V₁ = Q/C₁ = 7.2/2 = 3.6 V
      V₂ = Q/C₂ = 7.2/3 = 2.4 V
```

*जाँच:* V₁ + V₂ = 3.6 + 2.4 = 6 V ✓ — आपूर्ति के बराबर, जैसा श्रेणी में होना ही चाहिए।

### Q6 — परावैद्युत डालना, बैटरी हटाकर और जुड़ी रहने पर

**स्थिति B: डालने से पहले बैटरी हटा दी गई — अतः Q नियत।**

**(i) धारिता:** C′ = KC। K गुना **बढ़ती** है, क्योंकि ध्रुवित परावैद्युत उसी आवेश पर क्षेत्र घटा देता है,
अतः प्रति वोल्ट अधिक आवेश रखा जा सकता है।

**(ii) आवेश:** **अपरिवर्तित**, Q′ = Q। संधारित्र वियुक्त है — आवेश के आने या जाने का कोई रास्ता नहीं।

**(iii) विभवांतर:** V′ = Q/C′ = Q/(KC) = **V/K**। K गुना **घटता** है।

**(iv) विद्युत क्षेत्र:** E′ = V′/d = **E/K**। K गुना **घटता** है, क्योंकि प्रेरित ध्रुवण क्षेत्र
आरोपित क्षेत्र का विरोध करता है।

**(v) संचित ऊर्जा:** Q नियत वाले रूप का उपयोग करने पर,

```
      U′ = Q²/(2C′) = Q²/(2KC) = U/K
```

K गुना **घटती** है। खोई ऊर्जा का हिसाब उस कार्य से मिलता है जो संधारित्र परावैद्युत पट्टी को अंतराल में
**खींचने** में करता है।

**यदि बैटरी जुड़ी रहती — अतः V नियत:**

| राशि | बैटरी हटी हुई (Q नियत) | बैटरी जुड़ी (V नियत) |
| --- | --- | --- |
| C | बढ़कर KC | बढ़कर KC |
| Q | अपरिवर्तित | **बढ़कर KQ** |
| V | घटकर V/K | **अपरिवर्तित** |
| E | घटकर E/K | **अपरिवर्तित** (E = V/d) |
| U | घटकर U/K | **बढ़कर KU** (U = ½CV²) |

बैटरी जुड़ी रहने पर अतिरिक्त आवेश KQ − Q बैटरी देती है, जो कार्य करती है; अतः संचित ऊर्जा घटने के बजाय
बढ़ जाती है।

> ध्यान दीजिए कि *वही* भौतिक क्रिया, बैटरी जुड़ी है या नहीं, इसके अनुसार U में विपरीत परिवर्तन करती है।
> यही विरोधाभास इस प्रश्न का पूरा उद्देश्य है।

### Q7 — दो आवेशित संधारित्र आपस में जुड़े

```
      C₁ = 4 μF, V₁ = 100 V पर          C₂ = 6 μF, V₂ = 50 V पर
```

**सामान्य विभव:**

```
      V = (C₁V₁ + C₂V₂)/(C₁ + C₂)
        = (4 × 100 + 6 × 50)/(4 + 6)              [μF तथा वोल्ट में]
        = (400 + 300)/10
        = 700/10
        = 70 V
```

**ऊर्जा की हानि:**

```
      ΔU = C₁C₂ (V₁ − V₂)² / [ 2(C₁ + C₂) ]
         = (4 × 10⁻⁶)(6 × 10⁻⁶)(100 − 50)² / [ 2(10 × 10⁻⁶) ]
         = (24 × 10⁻¹²)(2500) / (20 × 10⁻⁶)
         = (6 × 10⁻⁸)/(2 × 10⁻⁵)
         = 3 × 10⁻³ J
```

**सामान्य विभव = 70 V; खोई ऊर्जा = 3 × 10⁻³ J = 3 mJ।**

*(सीधी गणना से जाँच: आरंभिक ऊर्जा = ½(4μ)(100)² + ½(6μ)(50)² = 20 mJ + 7.5 mJ = 27.5 mJ। अंतिम ऊर्जा
= ½(10μ)(70)² = 24.5 mJ। हानि = 3 mJ ✓)*

यह ऊर्जा **जोड़ने वाले तारों में ऊष्मा** के रूप में क्षय हो जाती है (और थोड़ी विद्युत चुंबकीय विकिरण के
रूप में)।

### Q8 — एकसमान क्षेत्र में द्विध्रुव की स्थितिज ऊर्जा

द्विध्रुव की स्थितिज ऊर्जा उस कार्य के बराबर है जो उसे किसी संदर्भ दिशा से θ कोण तक घुमाने में लगता है।

[अध्याय 1](01-electric-charges-and-fields.md) से, द्विध्रुव को θ कोण पर रोके रखने के लिए आवश्यक
बल-आघूर्ण τ = pE sin θ है। क्षेत्र के विरुद्ध dθ घुमाने में किया गया सूक्ष्म कार्य

```
      dW = τ dθ = pE sin θ dθ
```

संदर्भ स्थिति θ = 90° लेकर (जहाँ परिपाटी से U शून्य है), 90° से θ तक घुमाने में किया गया कार्य

```
      W = ∫[90°, θ] pE sin θ′ dθ′
        = pE [ −cos θ′ ]₉₀°^θ
        = pE ( −cos θ + cos 90° )
        = −pE cos θ
```

अतः

```
      U = −pE cos θ  =  −p · E
```

**U न्यूनतम** है जब cos θ = 1, अर्थात् **θ = 0°** — द्विध्रुव क्षेत्र के **समांतर** पंक्तिबद्ध। तब

```
      U_न्यूनतम = −pE
```

यह **स्थायी संतुलन** की स्थिति है। (θ = 180° पर U = +pE अधिकतम है — अस्थायी संतुलन।) ∎

### Q9 — तीन आवेशों की स्थितिज ऊर्जा

*आरेख:* भुजा 10 cm वाला समबाहु त्रिभुज, शीर्षों पर q₁ = +2 μC, q₂ = −3 μC, q₃ = +4 μC।

तीनों युग्म-दूरियाँ बराबर हैं: r = 10 cm = 0.1 m।

```
      U = k [ q₁q₂/r + q₂q₃/r + q₁q₃/r ]
        = (k/r) [ q₁q₂ + q₂q₃ + q₁q₃ ]
```

```
      q₁q₂ = (2 × 10⁻⁶)(−3 × 10⁻⁶) = −6 × 10⁻¹²
      q₂q₃ = (−3 × 10⁻⁶)(4 × 10⁻⁶) = −12 × 10⁻¹²
      q₁q₃ = (2 × 10⁻⁶)(4 × 10⁻⁶)  = +8 × 10⁻¹²
                                     ─────────────
      योग                          = −10 × 10⁻¹² = −1 × 10⁻¹¹
```

```
      U = (9 × 10⁹/0.1)(−1 × 10⁻¹¹)
        = (9 × 10¹⁰)(−1 × 10⁻¹¹)
        = −0.9 J
```

**U = −0.9 J**

ऋण चिह्न का अर्थ है कि निकाय **बद्ध** है — तीनों आवेशों को अनंत तक अलग करने के लिए 0.9 J बाहरी कार्य
आवश्यक होगा।

### Q10 — C कब दोगुनी होती है?

C = ε₀A/d केवल ज्यामिति और माध्यम पर निर्भर करता है।

- d दोगुना करने पर C **आधी** हो जाती है — अतः (a) नहीं।
- A दोगुना करने पर C **दोगुनी** हो जाती है ✓
- C, Q या V पर निर्भर ही नहीं करता — अतः (c) या (d) नहीं।

**उत्तर: (b) प्लेट का क्षेत्रफल दोगुना कर दिया जाए**

### Q11 — प्रकरण अध्ययन: समांतर पट्टिका संधारित्र

```
      A = 100 cm² = 100 × 10⁻⁴ m² = 1 × 10⁻² m²
      d = 1 mm = 1 × 10⁻³ m
      V = 100 V
```

**(i) धारिता:**

```
      C = ε₀A/d = (8.854 × 10⁻¹²)(1 × 10⁻²)/(1 × 10⁻³)
        = (8.854 × 10⁻¹⁴)/(10⁻³)
        = 8.854 × 10⁻¹¹ F
```

**C ≈ 8.85 × 10⁻¹¹ F = 88.5 pF**

**(ii) संचित आवेश:**

```
      Q = CV = (8.854 × 10⁻¹¹)(100) = 8.854 × 10⁻⁹ C
```

**Q ≈ 8.85 × 10⁻⁹ C = 8.85 nC**

**(iii) संचित ऊर्जा:**

```
      U = ½ CV² = ½ (8.854 × 10⁻¹¹)(100)²
        = ½ (8.854 × 10⁻¹¹)(10⁴)
        = ½ (8.854 × 10⁻⁷)
        = 4.43 × 10⁻⁷ J
```

**U ≈ 4.43 × 10⁻⁷ J**

**(iv) K = 5 के साथ, आपूर्ति अब भी जुड़ी।** V नियत है, अतः C बढ़कर KC हो जाती है और

```
      U′ = ½ (KC) V² = K × U = 5 × 4.43 × 10⁻⁷
```

**U′ ≈ 2.21 × 10⁻⁶ J** — मूल ऊर्जा का पाँच गुना, और अतिरिक्त ऊर्जा बैटरी देती है।

### Q12 — अभिकथन–कारण

**A:** "भिन्न विभवों पर आवेशित दो संधारित्रों को जोड़ने पर ऊर्जा की हानि सदैव होती है।" **सत्य** — हानि
ΔU = C₁C₂(V₁ − V₂)²/[2(C₁ + C₂)] है, जो V₁ ≠ V₂ होने पर सदैव धनात्मक है।

**R:** "संधारित्रों को आपस में जोड़ने पर आवेश संरक्षित रहता है।" **सत्य** — पुनर्वितरण से पहले और बाद
कुल आवेश समान रहता है।

**क्या R, A को समझाता है?** **नहीं।** आवेश संरक्षण से आप सामान्य विभव *निकाल* पाते हैं, पर वह ऊर्जा की
हानि का कारण नहीं है। ऊर्जा इसलिए खोती है कि आवेश जोड़ने वाले तार के प्रतिरोध से बहता है और ऊष्मा के रूप
में क्षय हो जाता है। आवेश का संरक्षण, अपने आप में, किसी ऊर्जा-हानि का संकेत नहीं देता।

**उत्तर: (b) A और R दोनों सत्य हैं, पर R, A का सही स्पष्टीकरण नहीं है।**

> यह अभिकथन–कारण के चिरपरिचित जाल का अच्छा उदाहरण है: दो सत्य कथन, जिनमें दूसरा प्रासंगिक लगता है पर
> कुछ और समझाता है।
