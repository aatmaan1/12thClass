### Q1 — 2x³ − 3x² − 36x + 7 के एकदिष्टता अंतराल

```
f(x)  = 2x³ − 3x² − 36x + 7
f′(x) = 6x² − 6x − 36
      = 6(x² − x − 6)
      = 6(x − 3)(x + 2)
```

क्रांतिक बिंदु: f′(x) = 0 पर **x = −2 तथा x = 3**। ये **R** को तीन अंतरालों में बाँटते हैं।

**चिह्न सारणी:**

| अंतराल | परीक्षण बिंदु | (x − 3) | (x + 2) | f′(x) | f है |
| --- | --- | --- | --- | --- | --- |
| (−∞, −2) | x = −3 | − | − | **+** | वर्धमान |
| (−2, 3) | x = 0 | − | + | **−** | ह्रासमान |
| (3, ∞) | x = 4 | + | + | **+** | वर्धमान |

**(a) (−∞, −2) ∪ (3, ∞) पर निरंतर वर्धमान**
**(b) (−2, 3) पर निरंतर ह्रासमान**

### Q2 — [0, 2π] पर sin x + cos x के अंतराल

```
f′(x) = cos x − sin x
```

f′(x) = 0 रखिए:

```
      cos x = sin x
⟹     tan x = 1
⟹     x = π/4  या  x = 5π/4        ([0, 2π] के भीतर)
```

[0, 2π] पर **चिह्न सारणी**:

| अंतराल | परीक्षण बिंदु | f′(x) = cos x − sin x | f है |
| --- | --- | --- | --- |
| (0, π/4) | x = 0 | 1 − 0 = **+** | वर्धमान |
| (π/4, 5π/4) | x = π/2 | 0 − 1 = **−** | ह्रासमान |
| (5π/4, 2π) | x = 3π/2 | 0 − (−1) = **+** | वर्धमान |

**[0, π/4) ∪ (5π/4, 2π] पर वर्धमान; (π/4, 5π/4) पर ह्रासमान।**

### Q3 — त्रिज्या R के गोले में अधिकतम आयतन का बेलन

**व्यवस्था।** मान लीजिए बेलन की आधार त्रिज्या r और ऊँचाई h है। गोले के अंतर्गत होने से अक्षीय काट का
विकर्ण एक व्यास है, अतः r, h/2 तथा R से बने समकोण त्रिभुज पर पाइथागोरस से:

```
      r² + (h/2)² = R²
⟹     r² = R² − h²/4                    …(प्रतिबंध)
```

**अभीष्ट राशि।**

```
      V = π r² h
```

**प्रतिबंध से r हटाइए:**

```
      V(h) = π (R² − h²/4) h = π R² h − (π/4) h³
```

जहाँ 0 < h < 2R।

**अवकलन:**

```
      dV/dh = π R² − (3π/4) h²
```

dV/dh = 0 रखिए:

```
      π R² = (3π/4) h²
⟹     h² = 4R²/3
⟹     h = 2R/√3                          (धनात्मक मूल, क्योंकि h > 0)
```

**द्वितीय अवकलज परीक्षण:**

```
      d²V/dh² = −(3π/2) h
```

h = 2R/√3 > 0 पर d²V/dh² = −(3π/2)(2R/√3) < 0।

अतः h = 2R/√3 पर V **अधिकतम** है।

**इसलिए त्रिज्या R के गोले के अंतर्गत अधिकतम आयतन के बेलन की ऊँचाई h = 2R/√3 है।** ∎

*(रोचक जानकारी: तब r² = R² − R²/3 = 2R²/3, और V_अधिकतम = π(2R²/3)(2R/√3) = 4πR³/(3√3)।)*

### Q4 — 18 cm वर्गाकार चादर से खुला बक्सा

**व्यवस्था।** मान लीजिए कोनों से काटे गए प्रत्येक वर्ग की भुजा x cm है। मोड़ने के बाद बक्से का

```
आधार = (18 − 2x) × (18 − 2x)          ऊँचाई = x
```

जहाँ 0 < x < 9 (जिससे आधार की भुजा धनात्मक रहे)।

**अभीष्ट राशि।**

```
      V(x) = x (18 − 2x)²
           = x (324 − 72x + 4x²)
           = 324x − 72x² + 4x³
```

**अवकलन:**

```
      V′(x) = 324 − 144x + 12x²
            = 12(x² − 12x + 27)
            = 12(x − 3)(x − 9)
```

V′(x) = 0 रखिए: x = 3 या x = 9। पर x = 9 प्रांत से बाहर है (उससे आधार शून्य हो जाता है), अतः

```
      x = 3
```

**द्वितीय अवकलज परीक्षण:**

```
      V″(x) = −144 + 24x
      V″(3) = −144 + 72 = −72 < 0
```

अतः x = 3 पर V **अधिकतम** है।

**अधिकतम आयतन:**

```
      V(3) = 3(18 − 6)² = 3(12)² = 3(144) = 432 cm³
```

**काटे जाने वाले वर्ग की भुजा 3 cm है, और अधिकतम आयतन 432 cm³ है।**

### Q5 — 2x³ − 24x + 107 के निरपेक्ष चरम मान

```
f′(x) = 6x² − 24 = 6(x² − 4) = 6(x − 2)(x + 2)
```

क्रांतिक बिंदु: x = 2 तथा x = −2।

**[1, 3] पर:** क्रांतिक बिंदु x = 2 भीतर है; x = −2 नहीं। x = 1, 2, 3 पर f निकालिए:

```
f(1) = 2 − 24 + 107 = 85
f(2) = 16 − 48 + 107 = 75
f(3) = 54 − 72 + 107 = 89
```

**निरपेक्ष उच्चतम = 89, x = 3 पर; निरपेक्ष निम्नतम = 75, x = 2 पर।**

**[−3, −1] पर:** क्रांतिक बिंदु x = −2 भीतर है। x = −3, −2, −1 पर f निकालिए:

```
f(−3) = 2(−27) − 24(−3) + 107 = −54 + 72 + 107 = 125
f(−2) = 2(−8) − 24(−2) + 107 = −16 + 48 + 107 = 139
f(−1) = 2(−1) − 24(−1) + 107 = −2 + 24 + 107 = 129
```

**निरपेक्ष उच्चतम = 139, x = −2 पर; निरपेक्ष निम्नतम = 125, x = −3 पर।**

> ध्यान दीजिए कि [1, 3] पर उच्चतम **सिरे** पर आया और निम्नतम क्रांतिक बिंदु पर, जबकि [−3, −1] पर उच्चतम
> क्रांतिक बिंदु पर था और निम्नतम सिरे पर। ठीक इसीलिए सिरों पर भी मान निकालना अनिवार्य है।

### Q6 — 28 m तार को वर्ग और वृत्त में काटना

**व्यवस्था।** मान लीजिए **वृत्त** के लिए x मीटर उपयोग होता है; तब (28 − x) मीटर वर्ग को जाता है, जहाँ
0 < x < 28।

**वृत्त:** परिधि 2πr = x ⟹ r = x/(2π), अतः

```
वृत्त का क्षेत्रफल = πr² = π · x²/(4π²) = x²/(4π)
```

**वर्ग:** परिमाप 4a = 28 − x ⟹ a = (28 − x)/4, अतः

```
वर्ग का क्षेत्रफल = a² = (28 − x)²/16
```

**अभीष्ट राशि — कुल क्षेत्रफल:**

```
      A(x) = x²/(4π) + (28 − x)²/16
```

**अवकलन:**

```
      A′(x) = 2x/(4π) + 2(28 − x)(−1)/16
            = x/(2π) − (28 − x)/8
```

A′(x) = 0 रखिए:

```
      x/(2π) = (28 − x)/8
⟹     8x = 2π(28 − x)
⟹     8x = 56π − 2πx
⟹     x(8 + 2π) = 56π
⟹     x = 56π/(8 + 2π) = 28π/(4 + π)
```

**द्वितीय अवकलज परीक्षण:**

```
      A″(x) = 1/(2π) + 1/8 > 0
```

जो सभी x के लिए धनात्मक है, अतः इस मान पर A **न्यूनतम** है।

**लंबाइयाँ:**

```
वृत्त वाला टुकड़ा  = 28π/(π + 4) m
वर्ग वाला टुकड़ा  = 28 − 28π/(π + 4) = 28[(π + 4) − π]/(π + 4) = 112/(π + 4) m
```

**तार को 28π/(π + 4) m (वृत्त के लिए) तथा 112/(π + 4) m (वर्ग के लिए) के टुकड़ों में काटना चाहिए।**

*(संख्यात्मक रूप से लगभग 12.32 m तथा 15.68 m।)*

### Q7 — वृत्त के क्षेत्रफल की परिवर्तन दर

```
A = πr²        ⟹     dA/dt = 2πr · dr/dt
```

दिया है dr/dt = 3 cm/s तथा r = 10 cm:

```
      dA/dt = 2π(10)(3) = 60π cm²/s
```

**क्षेत्रफल 60π cm²/s की दर से बढ़ रहा है** (≈ 188.5 cm²/s)।

### Q8 — दिखाइए कि x³ − 3x² + 3x − 100, R पर वर्धमान है

```
f′(x) = 3x² − 6x + 3
      = 3(x² − 2x + 1)
      = 3(x − 1)²
```

चूँकि सभी वास्तविक x के लिए (x − 1)² ≥ 0, अतः **सभी x ∈ R के लिए f′(x) ≥ 0**, और समता केवल एक अकेले बिंदु
x = 1 पर।

अतः f, **R पर वर्धमान** है। ∎

> जिस फलन का अवकलज कुछ पृथक बिंदुओं पर शून्य हो पर शेष जगह धनात्मक हो, वह पूरे अंतराल पर अब भी वर्धमान
> होता है। यदि प्रश्न "निरंतर वर्धमान" कहे, तो लिखिए कि सभी x ≠ 1 के लिए f′(x) > 0 और f′ = 0 केवल एक
> बिंदु पर, जो निरंतर वृद्धि के लिए पर्याप्त है।

### Q9 — खिड़की: आयत + अर्धवृत्त, परिमाप 10 m

**(i) A को r के पदों में व्यक्त कीजिए।**

आयत की चौड़ाई अर्धवृत्त के व्यास के बराबर है, अतः चौड़ाई = 2r। उसकी ऊँचाई h मान लीजिए।

**परिमाप** (ध्यान दें: आयत का ऊपरी भाग सीमा का *अंग नहीं* है — वह अर्धवृत्त का व्यास है, जो भीतरी है):

```
      परिमाप = 2h + 2r + πr = 10
⟹     h = (10 − 2r − πr)/2                …(प्रतिबंध)
```

**क्षेत्रफल:**

```
      A = (आयत) + (अर्धवृत्त)
        = 2rh + ½πr²
```

h रखने पर:

```
      A = 2r · (10 − 2r − πr)/2 + ½πr²
        = r(10 − 2r − πr) + ½πr²
        = 10r − 2r² − πr² + ½πr²
```

```
A(r) = 10r − 2r² − (π/2) r²
```

**(ii) अधिकतमीकरण।**

```
      dA/dr = 10 − 4r − πr = 10 − r(4 + π)
```

dA/dr = 0 रखिए:

```
      r = 10/(4 + π)
```

द्वितीय अवकलज परीक्षण:

```
      d²A/dr² = −4 − π < 0
```

अतः क्षेत्रफल **r = 10/(4 + π) m** पर **अधिकतम** है (≈ 1.40 m)।

*(ध्यान देने योग्य: वापस रखने पर h = 20/(4 + π) ÷ 2 = 10/(4 + π) = r। अर्थात् अधिकतम-क्षेत्रफल वाली
खिड़की में आयत की ऊँचाई अर्धवृत्त की त्रिज्या के बराबर होती है।)*

**(iii) अधिकतम क्षेत्रफल।**

```
      A = 10r − r²(2 + π/2)      जहाँ r = 10/(4 + π)

ध्यान दें 2 + π/2 = (4 + π)/2, अतः

      A = 10 · 10/(4 + π)  −  [100/(4 + π)²] · (4 + π)/2
        = 100/(4 + π) − 50/(4 + π)
        = 50/(4 + π)
```

**अधिकतम क्षेत्रफल = 50/(4 + π) m²** (≈ 7.00 m²)।

### Q10 — दो धनात्मक संख्याएँ, योग 16, घनों का योग न्यूनतम

मान लीजिए संख्याएँ x तथा 16 − x हैं, जहाँ 0 < x < 16।

```
      S(x) = x³ + (16 − x)³
```

```
      S′(x) = 3x² − 3(16 − x)²
            = 3[ x² − (16 − x)² ]
            = 3[ x − (16 − x) ][ x + (16 − x) ]        [वर्गों का अंतर]
            = 3(2x − 16)(16)
            = 48(2x − 16)
```

S′(x) = 0 रखिए: 2x − 16 = 0 ⟹ **x = 8**।

**द्वितीय अवकलज परीक्षण:**

```
      S″(x) = 6x + 6(16 − x) = 96 > 0
```

धनात्मक, अतः x = 8 पर S **न्यूनतम** है।

**दोनों संख्याएँ 8 तथा 8 हैं**, जिससे घनों का न्यूनतम योग 8³ + 8³ = 1024 मिलता है।

### Q12 — वृत्त के अंतर्गत अधिकतम क्षेत्रफल का आयत वर्ग होता है

मान लीजिए वृत्त की नियत त्रिज्या a है। उसके अंतर्गत बने आयत का विकर्ण एक व्यास होता है, अतः यदि भुजाएँ
x तथा y हों:

```
      x² + y² = (2a)² = 4a²
⟹     y = √(4a² − x²)
```

**अभीष्ट राशि:**

```
      A = xy = x√(4a² − x²)
```

A² का अधिकतमीकरण आसान है (A > 0 होने से A² का अधिकतम उसी x पर आता है):

```
      A² = x²(4a² − x²) = 4a²x² − x⁴
```

मान लीजिए S = A²। तब

```
      dS/dx = 8a²x − 4x³ = 4x(2a² − x²)
```

dS/dx = 0 रखिए (जहाँ x > 0):

```
      x² = 2a²   ⟹   x = a√2
```

**द्वितीय अवकलज परीक्षण:**

```
      d²S/dx² = 8a² − 12x²
      x² = 2a² पर :  8a² − 24a² = −16a² < 0
```

अतः S, और इसलिए A, x = a√2 पर **अधिकतम** है।

तब

```
      y = √(4a² − 2a²) = √(2a²) = a√2 = x
```

चूँकि x = y, अतः अधिकतम क्षेत्रफल वाला आयत एक **वर्ग** है। ∎

> A के बजाय A² का अधिकतमीकरण करने की युक्ति वर्गमूल के अवकलन से बचा देती है, और पूर्णतः स्वीकार्य है।
> कारण लिखिए ("चूँकि A > 0, अतः A² अधिकतम होने पर A भी अधिकतम होता है") — वह वाक्य एक अंक है।
