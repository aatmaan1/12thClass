### Q1 — बायो-सावर्ट नियम और वृत्तीय पाश के अक्ष पर क्षेत्र

**बायो-सावर्ट नियम का कथन।** किसी सूक्ष्म धारा अवयव I d**l** द्वारा बिंदु P पर उत्पन्न चुंबकीय क्षेत्र
d**B** का परिमाण

- धारा I तथा अवयव की लंबाई dl के सीधे समानुपाती है,
- sin θ के सीधे समानुपाती है, जहाँ θ, d**l** तथा अवयव को P से जोड़ने वाली रेखा के बीच का कोण है,
- P की अवयव से दूरी r के वर्ग के व्युत्क्रमानुपाती है।

```
      dB = (μ₀/4π) · I dl sin θ / r²                 सदिश रूप:  dB = (μ₀/4π) I (dl × r̂)/r²
```

d**B** की दिशा d**l** तथा **r** वाले तल के लंबवत होती है।

**वृत्तीय पाश के लिए व्युत्पत्ति।**

*आरेख:* त्रिज्या R का वृत्तीय पाश पृष्ठ के तल में किनारे से दिखाया गया, जिसमें धारा I बह रही है।
P अक्ष पर केंद्र O से x दूरी पर है। ऊपर और नीचे व्यासतः विपरीत दो अवयव d**l** लीजिए। प्रत्येक से d**B**
सदिश खींचिए, और उन्हें अक्ष के अनुदिश तथा अक्ष के लंबवत घटकों में वियोजित कीजिए।

पाश पर किसी धारा अवयव I d**l** पर विचार कीजिए। उसकी P से दूरी

```
      r = √(R² + x²)
```

पाश के प्रत्येक अवयव के लिए d**l**, **r** के लंबवत है (अवयव स्पर्शीय है, **r** अक्ष वाले तल में है),
अतः θ = 90° और sin θ = 1। अतः

```
      dB = (μ₀/4π) · I dl / (R² + x²)
```

**d**B** का वियोजन।** d**B**, d**l** तथा **r** वाले तल के लंबवत है, अतः उसके घटक हैं:

- **अक्ष के अनुदिश** एक घटक: dB cos α
- **अक्ष के लंबवत** एक घटक: dB sin α

जहाँ α, d**B** तथा अक्ष के बीच का कोण है, और ज्यामिति से

```
      cos α = R/√(R² + x²)
```

**अब सममिति का उपयोग।** व्यासतः विपरीत अवयव के लिए लंबवत घटक विपरीत दिशा में होता है। पूरे पाश पर योग
करने से **सभी लंबवत घटक युग्मों में कट जाते हैं**, और केवल अक्षीय घटक बचकर जुड़ते हैं।

```
      B = ∮ dB cos α
        = ∮ (μ₀/4π) · I dl/(R² + x²) · R/√(R² + x²)

        = (μ₀ I R)/(4π (R² + x²)^(3/2)) ∮ dl
```

पाश के चारों ओर समाकल ∮dl उसकी परिधि 2πR है:

```
      B = (μ₀ I R)/(4π (R² + x²)^(3/2)) × 2πR
```

```
      B = μ₀ I R² / [ 2 (R² + x²)^(3/2) ]
```

**N फेरों** वाली कुंडली के लिए N से गुणा कीजिए:

```
      B = μ₀ N I R² / [ 2 (R² + x²)^(3/2) ]
```

**केंद्र पर**, x = 0 रखने पर:

```
      B = μ₀ N I R²/(2R³)  =  μ₀ N I/(2R)
```

दिशा अक्ष के अनुदिश होती है, जो **दक्षिण-हस्त नियम** से मिलती है (अँगुलियाँ धारा की दिशा में मोड़िए;
अँगूठा **B** देता है)। ∎

### Q2 — ऐम्पियर का परिपथीय नियम और लंबा सीधा तार

**कथन।** किसी भी बंद पथ के चारों ओर चुंबकीय क्षेत्र **B** का रेखा समाकल उस पथ से घिरे क्षेत्रफल से
गुज़रती कुल धारा का μ₀ गुना होता है:

```
      ∮ B · dl = μ₀ I_घिरा
```

**लंबे सीधे तार के लिए व्युत्पत्ति।**

*आरेख:* ऊपर की ओर धारा I ले जाता एक लंबा सीधा ऊर्ध्वाधर तार, उसके चारों ओर क्षैतिज तल में त्रिज्या r का
एक वृत्त, और वृत्त के स्पर्शीय दिखाया गया **B**।

**ऐम्पियरी लूप का चयन, औचित्य के साथ।** तार पर केंद्रित त्रिज्या r का एक वृत्त लीजिए, जो तार के लंबवत
तल में हो। समस्या की बेलनाकार सममिति से:

- इस वृत्त के प्रत्येक बिंदु पर **B** का परिमाण समान है;
- **B** प्रत्येक बिंदु पर वृत्त के **स्पर्शीय** है, अतः **B**, d**l** के समांतर है और
  **B**·d**l** = B dl।

अतः

```
      ∮ B · dl = B ∮ dl = B (2πr)
```

लूप से घिरी धारा I है। ऐम्पियर का नियम लगाने पर:

```
      B (2πr) = μ₀ I
⟹     B = μ₀ I / (2π r)
```

अतः **B ∝ 1/r**। क्षेत्र रेखाएँ तार के चारों ओर **संकेंद्रीय वृत्त** हैं, और उनकी दिशा दक्षिण-हस्त
अँगूठा नियम से मिलती है। ∎

### Q3 — धारामापी

*आरेख (इन सबको नामांकित कीजिए):* मृदु लोहे के क्रोड पर लिपटी N फेरों की आयताकार कुंडली PQRS; स्थायी
चुंबक के अवतल ध्रुव-खंड N तथा S जो त्रिज्य क्षेत्र उत्पन्न करते हैं; ऊपर दर्पण या सूचक ले जाती
फ़ॉस्फ़र-ब्रॉन्ज़ पट्टी का निलंबन; नीचे एक स्प्रिंग; पैमाना।

**सिद्धांत।** चुंबकीय क्षेत्र में रखी धारावाही कुंडली पर **बल-आघूर्ण** लगता है।

**कार्यविधि।** मान लीजिए कुंडली में N फेरे, क्षेत्रफल A है, और वह परिमाण B के त्रिज्य क्षेत्र में धारा I
ले जा रही है।

कुंडली पर **विक्षेपक बल-आघूर्ण**

```
      τ_विक्षेपक = N I A B sin θ
```

चूँकि अवतल ध्रुव-खंडों से बना क्षेत्र **त्रिज्य** है, कुंडली का तल विक्षेप चाहे जो हो सदैव **B के
समांतर** रहता है, अतः पूरे समय θ = 90° और sin θ = 1। अतः

```
      τ_विक्षेपक = N I A B
```

निलंबन विक्षेप φ के समानुपाती **प्रत्यानयन बल-आघूर्ण** देता है:

```
      τ_प्रत्यानयन = k φ
```

जहाँ k निलंबन का ऐंठन नियतांक है।

संतुलन पर दोनों बल-आघूर्ण बराबर हो जाते हैं:

```
      N I A B = k φ
```

```
      φ = (N A B / k) I                    अर्थात्     φ ∝ I
```

**विक्षेप धारा के सीधे समानुपाती है**, इसीलिए धारामापी का पैमाना **एकसमान (रैखिक)** होता है।

**त्रिज्य चुंबकीय क्षेत्र क्यों?** जिससे कुंडली का तल प्रत्येक विक्षेप पर **B** के समांतर रहे। इससे
sin θ = 1 बना रहता है, जो विक्षेपक बल-आघूर्ण को विक्षेप से स्वतंत्र कर देता है, और अतः φ ठीक-ठीक I के
समानुपाती हो जाता है — जिससे **रैखिक पैमाना** मिलता है। त्रिज्य क्षेत्र के बिना पैमाना असमान होता।

**मृदु लोहे का क्रोड क्यों?** वह कुंडली से गुज़रने वाले चुंबकीय फ्लक्स को संकेंद्रित करके B और अतः
सुग्राहिता बढ़ाता है, और क्षेत्र को त्रिज्य बनाने में भी सहायक होता है। ∎

### Q4 — समांतर धाराओं के बीच बल, और ऐम्पियर

*आरेख:* d दूरी पर दो लंबे समांतर ऊर्ध्वाधर तार, जिनमें एक ही दिशा में धाराएँ I₁ तथा I₂ बह रही हैं; तार 2
पर तार 1 का क्षेत्र पृष्ठ के भीतर की ओर और तार 2 पर परिणामी बल तार 1 की ओर दिखाया गया।

मान लीजिए d दूरी पर रखे दो लंबे समांतर सीधे चालकों में धाराएँ I₁ तथा I₂ बह रही हैं।

**तार 2 के स्थान पर तार 1 का क्षेत्र** (लंबे सीधे तार का परिणाम लेकर):

```
      B₁ = μ₀ I₁/(2π d)
```

जो तार 2 के लंबवत है।

**तार 2 की लंबाई l पर बल**, जो B₁ के लंबवत धारा I₂ ले जाता है:

```
      F = B₁ I₂ l sin 90° = B₁ I₂ l
        = [μ₀ I₁/(2π d)] I₂ l
```

**प्रति इकाई लंबाई बल:**

```
      F/l = μ₀ I₁ I₂ / (2π d)
```

न्यूटन के तीसरे नियम से तार 1 पर समान और विपरीत बल लगता है।

**दिशा।** फ़्लेमिंग के वाम-हस्त नियम से: धाराएँ **एक ही** दिशा में बहने पर तार एक-दूसरे को **आकर्षित**
करते हैं, और **विपरीत** दिशाओं में बहने पर **प्रतिकर्षित**।

**ऐम्पियर की परिभाषा।** I₁ = I₂ = 1 A तथा d = 1 m रखने पर:

```
      F/l = (4π × 10⁻⁷)(1)(1)/(2π × 1) = 2 × 10⁻⁷ N m⁻¹
```

**एक ऐम्पियर वह स्थिर धारा है, जो निर्वात में 1 मीटर की दूरी पर रखे अनंत लंबे, सीधे, उपेक्षणीय वृत्तीय
अनुप्रस्थ काट वाले दो समांतर चालकों में से प्रत्येक में बहने पर प्रत्येक चालक की प्रति मीटर लंबाई पर
2 × 10⁻⁷ न्यूटन का बल उत्पन्न करती है।** ∎

### Q5 — धारावाही पाश पर बल-आघूर्ण

*आरेख:* एकसमान क्षेत्र **B** में भुजाओं l तथा b वाला आयताकार पाश PQRS, जिसके तल का अभिलंब **B** से θ कोण
पर है। लंबाई l की दोनों भुजाओं पर BIl बल दिखाइए, जो तल से बाहर और भीतर विपरीत दिशाओं में लगते हैं।

भुजाओं l तथा b वाले आयताकार पाश PQRS पर विचार कीजिए, जिसमें धारा I बह रही है, और जो एकसमान क्षेत्र
**B** में रखा है, उसके तल का अभिलंब **B** से θ कोण पर है।

**लंबाई l की भुजाओं पर बल** (PQ तथा RS): ये भुजाएँ **B** के लंबवत हैं, अतः प्रत्येक पर बल

```
      F = B I l
```

ये दोनों बल **परिमाण में समान और दिशा में विपरीत** हैं, पर वे **भिन्न रेखाओं** पर लगते हैं, अतः वे एक
**युग्म** बनाते हैं।

**लंबाई b की भुजाओं पर बल:** ये समान, विपरीत, और **एक ही रेखा** पर लगते हैं, अतः पूरी तरह कट जाते हैं और
कोई बल-आघूर्ण नहीं देते।

**युग्म का बल-आघूर्ण** = (बल) × (क्रिया-रेखाओं के बीच लंब दूरी)। ज्यामिति से वह लंब दूरी b sin θ है:

```
      τ = (B I l)(b sin θ)
        = B I (l b) sin θ
        = B I A sin θ                        जहाँ A = lb पाश का क्षेत्रफल है
```

**N फेरों के लिए:**

```
      τ = N I A B sin θ
```

**चुंबकीय द्विध्रुव आघूर्ण m = N I A** परिभाषित करने पर (जो पाश के अभिलंब के अनुदिश है):

```
      τ = m × B
```

**अधिकतम बल-आघूर्ण:** जब sin θ = 1, अर्थात् θ = 90° — अभिलंब **B** के लंबवत, जिसका अर्थ है
**कुंडली का तल B के समांतर**। तब τ_अधिकतम = NIAB।

**शून्य बल-आघूर्ण:** जब θ = 0°, अर्थात् अभिलंब **B** के समांतर, अतः **कुंडली का तल B के लंबवत**। यह
स्थायी संतुलन की स्थिति है।

**ध्यान दें:** एकसमान क्षेत्र में पाश पर **नेट बल शून्य** है — उस पर शुद्ध युग्म लगता है और अतः वह
स्थानांतरित हुए बिना घूमता है। ∎

### Q6 — वृत्तीय पथ और चाल-निरपेक्ष आवर्तकाल

द्रव्यमान m का आवेश q एकसमान क्षेत्र **B** में वेग **v** से, **B** के लंबवत प्रवेश करता है।

**बल।** F = qvB sin 90° = qvB, और **F** = q(**v** × **B**) से वह **v के लंबवत** है।

चूँकि बल सदैव वेग के लंबवत है, वह **v** की **दिशा बदलता है पर परिमाण कभी नहीं**। वेग के सदैव लंबवत,
नियत परिमाण का बल ठीक **अभिकेंद्र** बल है, अतः कण नियत चाल से **वृत्त** में चलता है।

**त्रिज्या।** चुंबकीय बल को आवश्यक अभिकेंद्र बल के बराबर रखने पर:

```
      q v B = m v²/r
⟹     r = m v/(q B)
```

**आवर्तकाल।**

```
      T = 2πr/v = 2π [m v/(qB)]/v
⟹     T = 2π m/(q B)
```

**चाल v कट गई।** अतः आवर्तकाल (और अतः आवृत्ति f = qB/2πm) केवल आवेश-द्रव्यमान अनुपात और क्षेत्र पर
निर्भर है — **चाल पर नहीं**, और त्रिज्या पर भी नहीं। अधिक तेज़ कण उसी समय में समानुपाती रूप से बड़ा
वृत्त तय करता है। ∎

### Q7 — धारामापी का रूपांतरण

*आरेख:* (i) धारामापी G के आड़े पार्श्व में जुड़ा एक कम प्रतिरोध (शंट) S, और यह युग्म परिपथ में श्रेणी में;
(ii) धारामापी G के साथ श्रेणी में एक प्रतिरोध R, और यह युग्म घटक के आड़े पार्श्व में।

**(i) ऐमीटर में — पार्श्व में कम प्रतिरोध (शंट) जोड़िए।**

मान लीजिए धारामापी का प्रतिरोध G है और वह धारा I_g पर पूर्ण पैमाना विक्षेप देता है। उसे धारा I तक पढ़ने
योग्य बनाने के लिए पार्श्व में शंट S जोड़िए, जिससे G से केवल I_g गुज़रे और शेष (I − I_g) S से गुज़रे।

चूँकि G तथा S पार्श्व में हैं, उनके आड़े विभवांतर समान है:

```
      I_g G = (I − I_g) S
```

```
      S = I_g G / (I − I_g)
```

व्यवहार में I >> I_g होने से **S बहुत छोटा** होता है। इस प्रकार बने ऐमीटर का प्रतिरोध पार्श्व संयोजन
GS/(G + S) है, जो S से भी छोटा है — अतः बहुत छोटा, जैसा आवश्यक है।

**(ii) वोल्टमीटर में — श्रेणी में उच्च प्रतिरोध जोड़िए।**

धारामापी को विभवांतर V तक पढ़ने योग्य बनाने के लिए श्रेणी में प्रतिरोध R जोड़िए, जिससे संयोजन के आड़े V
लगाने पर धारामापी से धारा ठीक I_g हो:

```
      V = I_g (G + R)
```

```
      R = V/I_g − G
```

चूँकि I_g बहुत छोटा है, **R बहुत बड़ा** होता है। इस प्रकार बने वोल्टमीटर का प्रतिरोध (G + R) है, जो बहुत
बड़ा है, जैसा आवश्यक है।

### Q8 — चुंबकीय बल कोई कार्य क्यों नहीं करता

गतिमान आवेश पर चुंबकीय बल

```
      F = q (v × B)
```

सदिश गुणनफल की परिभाषा से **F** **सदैव v के लंबवत** है।

विस्थापन d**s** = **v** dt पर किसी बल द्वारा किया गया कार्य

```
      dW = F · ds = F · v dt
```

चूँकि **F** ⊥ **v**, अदिश गुणनफल **F**·**v** = 0, अतः

```
      dW = 0
```

अतः चुंबकीय बल आवेश पर **कोई कार्य नहीं** करता। परिणामतः **कण की गतिज ऊर्जा और चाल अपरिवर्तित रहती
हैं** — चुंबकीय क्षेत्र केवल गति की **दिशा** बदल सकता है।

### Q12 — प्रकरण अध्ययन: धारामापी का रूपांतरण

```
      G = 60 Ω          I_g = 1 mA = 10⁻³ A
```

**(i) I = 1 A तक पढ़ने वाला ऐमीटर** — पार्श्व में शंट S जोड़िए:

```
      S = I_g G/(I − I_g)
        = (10⁻³)(60)/(1 − 10⁻³)
        = 0.06/0.999
        = 0.06006 Ω
```

**S ≈ 0.06 Ω, धारामापी के साथ पार्श्व में जुड़ा।**

**(ii) V = 5 V तक पढ़ने वाला वोल्टमीटर** — श्रेणी में प्रतिरोध R जोड़िए:

```
      R = V/I_g − G
        = 5/(10⁻³) − 60
        = 5000 − 60
        = 4940 Ω
```

**R = 4940 Ω, धारामापी के साथ श्रेणी में जुड़ा।**

**(iii) ऐमीटर का प्रतिरोध** = G तथा S का पार्श्व संयोजन:

```
      R_A = GS/(G + S) = (60)(0.06006)/(60.06006) = 3.6036/60.06 ≈ 0.06 Ω
```

**R_A ≈ 0.06 Ω** — वस्तुतः शंट के बराबर, क्योंकि S << G।

**(iv) ऐमीटर का प्रतिरोध कम क्यों होना चाहिए।** ऐमीटर उस परिपथ में **श्रेणी** में जोड़ा जाता है जिसकी
धारा नापी जा रही है। यदि उसका प्रतिरोध ध्यान देने योग्य होता, तो वह **परिपथ का कुल प्रतिरोध बढ़ाकर धारा
घटा देता** — अर्थात् जिस राशि को नापना है उसे ही बदल देता। कम प्रतिरोध यह सुनिश्चित करता है कि ऐमीटर
परिपथ को न्यूनतम विक्षोभित करे। (आदर्श ऐमीटर का प्रतिरोध शून्य होता है।)

### Q13 — धारा सुग्राहिता बनाम वोल्टता सुग्राहिता

```
      धारा सुग्राहिता     I_s = φ/I = N A B/k
      वोल्टता सुग्राहिता  V_s = φ/V = N A B/(k G)  =  I_s/G
```

धारा सुग्राहिता फेरों की संख्या N बढ़ाकर बढ़ाई जा सकती है। पर N बढ़ाने से कुंडली में **तार की लंबाई** भी
बढ़ती है, और अतः **धारामापी का प्रतिरोध G**।

चूँकि V_s = I_s/G, यदि G, I_s के **उसी अनुपात** में बढ़ जाए, तो वोल्टता सुग्राहिता **अपरिवर्तित** रहती
है। अतः धारा सुग्राहिता बढ़ाने से वोल्टता सुग्राहिता आवश्यक रूप से **नहीं** बढ़ती।

*(विशेष रूप से V_s बढ़ाने के लिए N, A या B बढ़ाना होगा, या k घटाना होगा — पर **G में समानुपाती वृद्धि के
बिना**।)*
