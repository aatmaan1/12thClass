**Q13.** *(1 अंक, अभिकथन–कारण)*
**अभिकथन (A):** sin⁻¹(sin(2π/3)) = 2π/3।
**कारण (R):** सभी x ∈ **R** के लिए sin⁻¹(sin x) = x।

### Q1 — sin⁻¹(−1/2)

मान लीजिए sin⁻¹(−1/2) = θ, अतः sin θ = −1/2 जहाँ θ ∈ [−π/2, π/2]।

चूँकि sin(π/6) = 1/2, अतः sin(−π/6) = −1/2, और −π/6 ∈ [−π/2, π/2]। ✓

**sin⁻¹(−1/2) = −π/6**

### Q2 — cos⁻¹(−1/2)

cos⁻¹ का परिसर [0, π] है, अतः उत्तर [0, π] में होना चाहिए — वह ऋणात्मक नहीं हो सकता।

cos⁻¹(−x) = π − cos⁻¹x का उपयोग करने पर:

```
cos⁻¹(−1/2) = π − cos⁻¹(1/2) = π − π/3 = 2π/3
```

जाँच: 2π/3 ∈ [0, π] ✓ तथा cos(2π/3) = −1/2 ✓।

**cos⁻¹(−1/2) = 2π/3**

> यहाँ सबसे आम ग़लत उत्तर −π/3 है। cos⁻¹ **कभी ऋणात्मक नहीं** होता।

### Q3 — tan⁻¹(√3) − cot⁻¹(−√3)

```
tan⁻¹(√3) = π/3            क्योंकि tan(π/3) = √3 और π/3 ∈ (−π/2, π/2)

cot⁻¹(−√3) = π − cot⁻¹(√3)  [परिवार B का नियम]
           = π − π/6
           = 5π/6           और 5π/6 ∈ (0, π) ✓
```

अतः

```
tan⁻¹(√3) − cot⁻¹(−√3) = π/3 − 5π/6 = 2π/6 − 5π/6 = −3π/6 = −π/2
```

**उत्तर: −π/2**

### Q4 — sin⁻¹(sin(3π/4))

**चरण 1.** क्या 3π/4, [−π/2, π/2] में है? 3π/4 = 135°, और π/2 = 90°। **नहीं।** अतः उत्तर 3π/4 नहीं है।

**चरण 2.** भीतर का मान निकालिए:

```
sin(3π/4) = sin(π − π/4) = sin(π/4) = 1/√2
```

**चरण 3.** प्रतिलोम लीजिए:

```
sin⁻¹(1/√2) = π/4        और π/4 ∈ [−π/2, π/2] ✓
```

**उत्तर: π/4**

### Q5 — cos⁻¹(cos(7π/6))

**चरण 1.** क्या 7π/6, [0, π] में है? 7π/6 = 210° > 180°। **नहीं।**

**चरण 2.**

```
cos(7π/6) = cos(π + π/6) = −cos(π/6) = −√3/2
```

**चरण 3.**

```
cos⁻¹(−√3/2) = π − cos⁻¹(√3/2) = π − π/6 = 5π/6      और 5π/6 ∈ [0, π] ✓
```

**उत्तर: 5π/6**

*(शॉर्टकट जाँच: θ ∈ [π, 2π] के लिए cos⁻¹(cos θ) = 2π − θ = 2π − 7π/6 = 5π/6 ✓)*

### Q6 — tan⁻¹(tan(3π/4))

**चरण 1.** क्या 3π/4, (−π/2, π/2) में है? नहीं।

**चरण 2.** tan(3π/4) = tan(π − π/4) = −tan(π/4) = −1।

**चरण 3.** tan⁻¹(−1) = −π/4, और −π/4 ∈ (−π/2, π/2) ✓

**उत्तर: −π/4**

### Q7 — sin(cos⁻¹(3/5))

मान लीजिए θ = cos⁻¹(3/5)। तब cos θ = 3/5 और **θ ∈ [0, π]**।

```
sin²θ = 1 − cos²θ = 1 − 9/25 = 16/25
⟹ sin θ = ± 4/5
```

चूँकि θ ∈ [0, π], अतः sin θ ≥ 0। इसलिए हम **धनात्मक** मूल लेते हैं।

**sin(cos⁻¹(3/5)) = 4/5**

> पंक्ति "θ ∈ [0, π], अतः sin θ ≥ 0" ही अंक है। उसके बिना आपने चिह्न का औचित्य नहीं दिया।

### Q8 — sin⁻¹(2x − 1) का प्रांत

sin⁻¹ के लिए उसका प्रतिपाद्य [−1, 1] में होना चाहिए:

```
      −1 ≤ 2x − 1 ≤ 1
⟹     0 ≤ 2x ≤ 2
⟹     0 ≤ x ≤ 1
```

**प्रांत = [0, 1]**

### Q9 — sec⁻¹ की मुख्य मान शाखा

**उत्तर: (b) [0, π] − {π/2}**

π/2 को छोड़ा जाता है क्योंकि sec(π/2) अपरिभाषित है।

### Q10 — cos⁻¹(cos(13π/6))

13π/6 > 2π? 2π = 12π/6, अतः 13π/6 = 2π + π/6। पहले 2π घटाइए:

```
cos(13π/6) = cos(2π + π/6) = cos(π/6) = √3/2
```

तब

```
cos⁻¹(√3/2) = π/6        और π/6 ∈ [0, π] ✓
```

**उत्तर: π/6**

### Q11 — sec⁻¹(−2)

|−2| ≥ 1, अतः यह परिभाषित है। परिसर [0, π] − {π/2} है, अतः उत्तर अऋणात्मक होगा।

```
sec⁻¹(−2) = π − sec⁻¹(2) = π − π/3 = 2π/3
```

**उत्तर: (c) 2π/3**

*(विकल्प (a) −π/3 जाल है: sec⁻¹ कभी ऋणात्मक नहीं होता।)*

### Q12 — sin⁻¹(1/2) + cos⁻¹(1/2) + tan⁻¹(1)

```
sin⁻¹(1/2) = π/6
cos⁻¹(1/2) = π/3
tan⁻¹(1)   = π/4
```

योग = π/6 + π/3 + π/4 = 2π/12 + 4π/12 + 3π/12 = **9π/12 = 3π/4**

*(या सीधे ध्यान दीजिए कि sin⁻¹(1/2) + cos⁻¹(1/2) = π/2, फिर + π/4 = 3π/4।)*

### Q13 — अभिकथन–कारण

**अभिकथन:** sin⁻¹(sin(2π/3))। क्या 2π/3 ∈ [−π/2, π/2]? 2π/3 = 120° > 90°, अतः **नहीं**।
sin(2π/3) = sin(π/3) = √3/2, और sin⁻¹(√3/2) = π/3, **2π/3 नहीं**।
अतः **A असत्य है**।

**कारण:** "सभी x ∈ **R** के लिए sin⁻¹(sin x) = x" **असत्य** है — वह केवल x ∈ [−π/2, π/2] के लिए सत्य है।
अतः **R असत्य है**।

दोनों असत्य। मानक चार विकल्पों (a)–(d) में न (c) "A सत्य, R असत्य" बैठता है न (d) "A असत्य, R सत्य";
सही उत्तर यह है कि **A तथा R दोनों असत्य हैं**, जो पाँचवाँ विकल्प देने वाले प्रश्नपत्रों में (e) होता है,
और केवल चार विकल्प वाले प्रश्नपत्रों में इसका अर्थ है कि प्रश्न आपसे A के असत्य होने पर ध्यान देने की
अपेक्षा करता है — अपने प्रश्नपत्र की विकल्प-सूची देख लीजिए।

**उत्तर: A असत्य है और R असत्य है।**
