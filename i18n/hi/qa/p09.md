### Q1 — खगोलीय दूरदर्शी

*किरण आरेख (यह सब खींचिए और नामांकित कीजिए):* बाईं ओर फोकस दूरी f_o वाला अभिदृश्यक लेंस O, जिस पर दूर की
वस्तु से आता समांतर पुंज अक्ष से छोटे कोण α पर पड़ता है। वह अपने द्वितीय फोकस बिंदु पर वास्तविक, उलटा,
छोटा प्रतिबिंब A′B′ बनाता है। फोकस दूरी f_e वाली नेत्रिका E इस प्रकार रखी है कि उसका प्रथम फोकस बिंदु
A′B′ पर पड़े (सामान्य समंजन)। किरणें नेत्रिका से **समांतर** निकलती हैं, अक्ष से बड़े कोण β पर, अतः अंतिम
प्रतिबिंब अनंत पर बनता है। f_o, f_e, α, β, और नली की लंबाई L = f_o + f_e अंकित कीजिए।

**सिद्धांत।** अभिदृश्यक दूर की वस्तु का वास्तविक, उलटा, छोटा प्रतिबिंब अपने फोकस पर बनाता है; फिर नेत्रिका
उस मध्यवर्ती प्रतिबिंब पर साधारण आवर्धक की तरह कार्य करती है।

**आवर्धन क्षमता की व्युत्पत्ति।**

दूरदर्शी की **आवर्धन क्षमता** अंतिम प्रतिबिंब द्वारा नेत्र पर बनाए कोण β और वस्तु द्वारा स्वयं नेत्र (या
अभिदृश्यक) पर बनाए कोण α का अनुपात है:

```
      m = β/α
```

मान लीजिए मध्यवर्ती प्रतिबिंब A′B′ की ऊँचाई h है।

अभिदृश्यक पर बने त्रिभुज से, वस्तु द्वारा अभिदृश्यक पर बनाया कोण मध्यवर्ती प्रतिबिंब द्वारा अभिदृश्यक के
केंद्र पर बनाए कोण के बराबर है:

```
      tan α = h/f_o                 ⟹     α ≈ h/f_o          (कोण छोटे हैं)
```

नेत्रिका पर बने त्रिभुज से, चूँकि A′B′ नेत्रिका के फोकस पर है:

```
      tan β = h/f_e                 ⟹     β ≈ h/f_e
```

अतः

```
      m = β/α = (h/f_e)/(h/f_o)
```

```
      m = f_o/f_e
```

*(चिह्न परिपाटी के साथ इसे m = −f_o/f_e लिखा जाता है, और ऋण चिह्न बताता है कि अंतिम प्रतिबिंब उलटा है।)*

**सामान्य समंजन में दूरदर्शी की लंबाई:**

```
      L = f_o + f_e
```

**अपवर्ती की तुलना में परावर्ती दूरदर्शी के दो लाभ:**

1. **वर्ण विपथन नहीं होता।** अवतल दर्पण सभी तरंगदैर्ध्यों को एक ही कोण से परावर्तित करता है, जबकि लेंस
   भिन्न रंगों को भिन्न मात्रा में अपवर्तित करके रंगीन किनारे बनाता है।

2. **अधिक चमक और विभेदन क्षमता, तथा यांत्रिक स्थिरता।** बड़े द्वारक वाले दर्पण बड़े लेंसों से बनाना कहीं
   सरल और सस्ता है, और दर्पण अपनी पूरी पीठ से सहारा पाता है इसलिए अपने ही भार से झुकता नहीं — बड़े लेंस को
   केवल किनारे से सहारा मिल सकता है।

*(यह भी स्वीकार्य: गोलीय विपथन बहुत कम, क्योंकि परवलयिक दर्पण प्रयोग किया जा सकता है।)*

### Q2 — संयुक्त सूक्ष्मदर्शी

*किरण आरेख (यह सब खींचिए और नामांकित कीजिए):* बाईं ओर फोकस दूरी f_o वाला अभिदृश्यक लेंस O और दाईं ओर
फोकस दूरी f_e वाली नेत्रिका E, जिनके बीच नली की लंबाई L है। एक छोटी वस्तु AB, F_o से ठीक **बाहर** रखी है।
अभिदृश्यक नेत्रिका और उसके फोकस F_e के बीच **वास्तविक, उलटा, आवर्धित** प्रतिबिंब A′B′ बनाता है। फिर
नेत्रिका निकट बिंदु पर, नेत्र से D = 25 cm दूरी पर, **आभासी, आवर्धित, उलटा** अंतिम प्रतिबिंब A″B″ बनाती
है। प्रत्येक लेंस से कम-से-कम दो किरणें, तीर-निशान सहित, दिखाइए, और f_o, f_e, v_o, u_o, D अंकित कीजिए।

**सिद्धांत।** अभिदृश्यक बहुत निकट की वस्तु का वास्तविक, आवर्धित प्रतिबिंब बनाता है; फिर नेत्रिका उस
प्रतिबिंब पर साधारण आवर्धक की तरह कार्य करती है। दोनों आवर्धन गुणित हो जाते हैं।

**व्युत्पत्ति।**

कुल आवर्धन क्षमता दोनों का गुणनफल है:

```
      m = m_o × m_e
```

**अभिदृश्यक।** उसका रैखिक आवर्धन

```
      m_o = v_o/u_o
```

जहाँ u_o अभिदृश्यक के लिए वस्तु दूरी और v_o प्रतिबिंब दूरी है।

**नेत्रिका।** वह साधारण सूक्ष्मदर्शी की तरह कार्य करती है। निकट बिंदु D पर अंतिम प्रतिबिंब वाले साधारण
आवर्धक के लिए कोणीय आवर्धन

```
      m_e = 1 + D/f_e
```

अतः

```
      m = (v_o/u_o) ( 1 + D/f_e )
```

**यदि अंतिम प्रतिबिंब अनंत पर हो** (शिथिल नेत्र), तो नेत्रिका का आवर्धन D/f_e हो जाता है, अतः

```
      m = (v_o/u_o) ( D/f_e )
```

**सन्निकट रूप।** लंबी नली के लिए अभिदृश्यक की प्रतिबिंब दूरी v_o लगभग नली की लंबाई L होती है, और वस्तु
F_o से ठीक बाहर रखी होने से u_o ≈ f_o। तब

```
      m ≈ (L/f_o)(D/f_e)
```

**दोनों फोकस दूरियाँ कम क्यों होनी चाहिए।**

m ≈ (L/f_o)(D/f_e) से, आवर्धन क्षमता **f_o तथा f_e दोनों के व्युत्क्रमानुपाती** है। अतः बड़ा आवर्धन पाने
के लिए अभिदृश्यक और नेत्रिका **दोनों** की **फोकस दूरी कम** होनी चाहिए — और चूँकि वस्तु अभिदृश्यक के फोकस
से ठीक बाहर रखनी है और वहीं उसका प्रबल आवर्धन होना है, f_o दोनों में **छोटी** रखी जाती है। ∎

### Q3 — प्रिज़्म से अपवर्तन

*आरेख:* त्रिभुजाकार प्रिज़्म ABC जिसका अपवर्तक कोण A शीर्ष पर है। किरण PQ फलक AB पर आपतन कोण i से पड़कर
प्रिज़्म में कोण r₁ पर अपवर्तित होती है, फलक AC तक जाकर उस पर कोण r₂ से पड़ती है, और RS के रूप में निर्गम
कोण e पर निकलती है। PQ तथा RS को पीछे/आगे बढ़ाकर मिलाइए, और उनके बीच विचलन कोण δ अंकित कीजिए। Q तथा R पर
अभिलंब खींचिए।

**r₁ + r₂ = A की व्युत्पत्ति।**

चतुर्भुज AQNR में (जहाँ N दोनों अभिलंबों का प्रतिच्छेद है), Q तथा R पर कोण प्रत्येक 90° हैं (अभिलंब फलकों
के लंबवत हैं)। चतुर्भुज के कोणों का योग 360° होता है:

```
      A + 90° + ∠QNR + 90° = 360°
⟹     A + ∠QNR = 180°                    …(i)
```

त्रिभुज QNR में कोणों का योग 180° होता है:

```
      r₁ + r₂ + ∠QNR = 180°               …(ii)
```

(i) तथा (ii) की तुलना करने पर:

```
      r₁ + r₂ = A
```

**i + e = A + δ की व्युत्पत्ति।**

किरण प्रत्येक फलक पर विचलित होती है। पहले फलक पर विचलन (i − r₁) है; दूसरे फलक पर (e − r₂)। कुल विचलन δ
इनका योग है:

```
      δ = (i − r₁) + (e − r₂)
        = (i + e) − (r₁ + r₂)
        = (i + e) − A
```

अतः

```
      i + e = A + δ
```

**i–δ ग्राफ़:**

```
   δ │╲                        ╱
     │ ╲                     ╱
     │  ╲                  ╱
     │   ╲               ╱
     │    ╲__          ╱
  δm │       ‾‾╲____╱‾            ← एक ही न्यूनतम, जो i = e पर होता है
     └──────────┴────────────── i
                i₁
```

δ_m से बड़े प्रत्येक δ के लिए आपतन कोण के **दो** मान होते हैं (एक में किरण-पथ दूसरे का उलटा होता है), पर
न्यूनतम पर दोनों संपाती हो जाते हैं — अर्थात् **न्यूनतम विचलन पर i = e**।

**प्रिज़्म सूत्र की व्युत्पत्ति।**

न्यूनतम विचलन पर i = e, और अतः दोनों फलकों पर स्नेल का नियम लगाने से r₁ = r₂ = r। तब:

```
      r₁ + r₂ = A       ⟹     2r = A       ⟹     r = A/2
```

और

```
      i + e = A + δ_m   ⟹     2i = A + δ_m ⟹     i = (A + δ_m)/2
```

पहले फलक पर **स्नेल का नियम** लगाने पर:

```
      n = sin i/sin r
```

मान रखने पर:

```
      n = sin[ (A + δ_m)/2 ] / sin( A/2 )
```

∎

### Q4 — लेंस निर्माता सूत्र

*आरेख:* अपवर्तनांक n₁ वाले माध्यम में रखा अपवर्तनांक n₂ का पतला उभयोत्तल लेंस, जिसकी दो सतहों की
त्रिज्याएँ R₁ तथा R₂ हैं। अक्ष पर वस्तु O; पहली सतह मध्यवर्ती प्रतिबिंब I₁ बनाती है; दूसरी सतह अंतिम
प्रतिबिंब I बनाती है।

अपवर्तनांक n₁ के माध्यम में रखे अपवर्तनांक n₂ के पतले लेंस पर विचार कीजिए, जिसकी सतहों की वक्रता
त्रिज्याएँ R₁ तथा R₂ हैं। मान लीजिए वस्तु लेंस से u दूरी पर है।

**पहली सतह पर अपवर्तन।** एक गोलीय सतह पर अपवर्तन के सूत्र का उपयोग करते हुए, वस्तु u पर और प्रतिबिंब v₁
पर बनने पर:

```
      n₂/v₁ − n₁/u = (n₂ − n₁)/R₁                    …(i)
```

**दूसरी सतह पर अपवर्तन।** पहली सतह से बना प्रतिबिंब I₁ दूसरी सतह के लिए **वस्तु** का कार्य करता है।
प्रकाश अब माध्यम n₂ से माध्यम n₁ में जाता है:

```
      n₁/v − n₂/v₁ = (n₁ − n₂)/R₂                    …(ii)
```

**(i) तथा (ii) जोड़ने पर** — v₁ वाले पद कट जाते हैं:

```
      n₁/v − n₁/u = (n₂ − n₁)/R₁ + (n₁ − n₂)/R₂
                  = (n₂ − n₁)( 1/R₁ − 1/R₂ )
```

n₁ से भाग देने पर:

```
      1/v − 1/u = ( n₂/n₁ − 1 )( 1/R₁ − 1/R₂ )
```

**अब f पहचानिए।** परिभाषा से, जब वस्तु अनंत पर हो (u = ∞), प्रतिबिंब फोकस पर बनता है (v = f)। u = ∞
रखने पर:

```
      1/f = ( n₂/n₁ − 1 )( 1/R₁ − 1/R₂ )
```

**वायु में** लेंस के लिए n₁ = 1 तथा n₂ = n, जिससे **लेंस निर्माता सूत्र** मिलता है:

```
      1/f = ( n − 1 )( 1/R₁ − 1/R₂ )
```

और पिछली पंक्ति से तुलना करने पर **पतले लेंस का सूत्र**:

```
      1/v − 1/u = 1/f
```

∎

### Q5 — दर्पण सूत्र

*आरेख:* अवतल दर्पण जिसका ध्रुव P, वक्रता केंद्र C, और मुख्य फोकस F है। ऊँचाई h की वस्तु AB अक्ष पर u
दूरी पर खड़ी है। दो किरणें खींचिए: एक अक्ष के समांतर, जो F से होकर परावर्तित होती है; एक C से होकर, जो
अपने ही रास्ते वापस परावर्तित होती है। वे A′ पर मिलती हैं, और v दूरी पर ऊँचाई h′ का वास्तविक उलटा
प्रतिबिंब A′B′ बनाती हैं। आपतन बिंदु M से अक्ष पर लंब MN खींचिए।

अवतल दर्पण पर विचार कीजिए जिसका ध्रुव P, फोकस F और वक्रता केंद्र C है। मान लीजिए AB ऊँचाई h की वस्तु u
दूरी पर है, जो v दूरी पर ऊँचाई h′ का वास्तविक उलटा प्रतिबिंब A′B′ बनाती है।

**समरूप त्रिभुज, युग्म 1।** त्रिभुज A′B′P तथा ABP समरूप हैं (दोनों B तथा B′ पर समकोण हैं, और परावर्तन के
नियम से P पर कोण बराबर हैं):

```
      A′B′/AB = B′P/BP
⟹     h′/h = v/u                        (परिमाणों में)         …(i)
```

**समरूप त्रिभुज, युग्म 2।** त्रिभुज A′B′F तथा MPF समरूप हैं (जहाँ MP = AB = h, क्योंकि M वह बिंदु है जहाँ
अक्ष के समांतर किरण दर्पण से टकराती है):

```
      A′B′/MP = B′F/FP
⟹     h′/h = B′F/FP                                             …(ii)
```

**(i) तथा (ii) बराबर रखने पर:**

```
      v/u = B′F/FP
```

अब दूरियों को u, v, f के पदों में लिखिए। चूँकि B′F = PB′ − PF तथा FP = f (सब परिमाणों में):

```
      v/u = (v − f)/f
```

**तिर्यक गुणा करने पर:**

```
      v f = u(v − f) = uv − uf
⟹     v f + u f = u v
```

पूरे को uvf से भाग देने पर:

```
      1/u + 1/v = 1/f
```

**चिह्न परिपाटी लगाने पर** (अवतल दर्पण के सामने वास्तविक वस्तु के लिए u, v तथा f सब ऋणात्मक), संबंध का रूप
वही रहता है:

```
      1/v + 1/u = 1/f
```

∎

*(और ज्यामिति से PC = R = 2f, अर्थात् **f = R/2**।)*

### Q6 — पूर्ण आंतरिक परावर्तन और प्रकाशिक तंतु

**परिभाषा।** जब प्रकाश की किरण **प्रकाशिक रूप से घने माध्यम से विरल माध्यम** की ओर चलते हुए अंतरापृष्ठ पर
**क्रांतिक कोण से बड़े** आपतन कोण से पड़ती है, तो वह **पूर्णतः घने माध्यम में ही परावर्तित** हो जाती है,
और कोई अपवर्तित किरण बनती ही नहीं। यही **पूर्ण आंतरिक परावर्तन** है।

**शर्तें (दोनों आवश्यक हैं):**
1. प्रकाश को **घने** से **विरल** माध्यम की ओर चलना चाहिए।
2. आपतन कोण उस माध्यम-युग्म के **क्रांतिक कोण C से बड़ा** होना चाहिए, जहाँ

```
      sin C = n_विरल/n_घना  =  1/n           (वायु से लगे अपवर्तनांक n के घने माध्यम के लिए)
```

**प्रकाशिक तंतु में उपयोग।**

*आरेख:* एक लंबा तंतु जिसमें उच्च अपवर्तनांक का क्रोड और उसके चारों ओर कम अपवर्तनांक का आच्छादन है; एक
किरण एक सिरे से घुसकर चलते-चलते क्रोड–आच्छादन सीमा से बार-बार टकराती हुई।

प्रकाशिक तंतु में **उच्च** अपवर्तनांक वाले काँच या प्लास्टिक का एक पतला **क्रोड** होता है, जिसके चारों ओर
**कम** अपवर्तनांक का **आच्छादन** होता है।

तंतु के एक सिरे से घुसा प्रकाश क्रोड–आच्छादन सीमा पर उस माध्यम-युग्म के **क्रांतिक कोण से बड़े** कोण पर
पड़ता है। अतः उसका **पूर्ण आंतरिक परावर्तन** होता है, और वह क्रोड में ही लौट आता है। यह तंतु की लंबाई में
हज़ारों बार दोहराया जाता है, अतः प्रकाश तंतु के साथ-साथ — **मोड़ों के आसपास भी** — तीव्रता की लगभग कोई
हानि किए बिना निर्देशित होता जाता है, क्योंकि पूर्ण आंतरिक परावर्तन में कोई अवशोषण नहीं होता (चाँदी चढ़े
दर्पण से परावर्तन के विपरीत)।

**अनुप्रयोग:** प्रकाशिक तंतु दूरभाष और इंटरनेट संकेतों को लंबी दूरी तक ले जाते हैं, और शरीर के भीतर देखने
के लिए **एंडोस्कोपी** में प्रयोग होते हैं।

### Q7 — अवतल दर्पण संख्यात्मक

```
      u = −20 cm          f = −15 cm          (अवतल दर्पण: f ऋणात्मक)
```

**दर्पण सूत्र:**

```
      1/v + 1/u = 1/f
⟹     1/v = 1/f − 1/u
          = 1/(−15) − 1/(−20)
          = −1/15 + 1/20
          = (−4 + 3)/60
          = −1/60
⟹     v = −60 cm
```

**आवर्धन:**

```
      m = −v/u = −(−60)/(−20) = −60/20 = −3
```

**निष्कर्ष।** प्रतिबिंब दर्पण के **सामने 60 cm** पर बनता है (वस्तु की ही ओर, क्योंकि v ऋणात्मक है)। वह
**वास्तविक** है (दर्पण के लिए v ऋणात्मक का अर्थ वास्तविक), **उलटा** (m ऋणात्मक) और **तीन गुना आवर्धित**।

*(संगति जाँच: f = 15, अतः C, 30 cm पर है। 20 cm पर रखी वस्तु F और C के बीच है, और §2 की सारणी कहती है कि
तब प्रतिबिंब वास्तविक, उलटा और आवर्धित, C से परे होना चाहिए — और 60 cm वास्तव में 30 cm से परे है ✓)*

### Q8 — उत्तल लेंस संख्यात्मक

```
      u = −30 cm          f = +20 cm          (उत्तल लेंस: f धनात्मक)
```

```
      1/v − 1/u = 1/f
⟹     1/v = 1/f + 1/u
          = 1/20 + 1/(−30)
          = (3 − 2)/60
          = 1/60
⟹     v = +60 cm
```

**आवर्धन:**

```
      m = v/u = 60/(−30) = −2
```

**निष्कर्ष।** प्रतिबिंब लेंस से वस्तु की **दूसरी ओर 60 cm** पर बनता है। वह **वास्तविक** है (लेंस के लिए
v धनात्मक), **उलटा** (m ऋणात्मक) और **दो गुना आवर्धित**।

### Q11 — न्यूनतम विचलन पर प्रिज़्म का अपवर्तनांक

```
      A = 60°          δ_m = 30°
```

**न्यूनतम विचलन पर आपतन कोण:**

```
      i = (A + δ_m)/2 = (60 + 30)/2 = 45°
```

**अपवर्तनांक:**

```
      n = sin[(A + δ_m)/2] / sin(A/2)
        = sin 45°/sin 30°
        = (0.7071)/(0.5)
        = 1.414
```

**n = √2 ≈ 1.41 तथा i = 45°।**

*(न्यूनतम विचलन पर r₁ = r₂ = A/2 = 30°, अतः प्रिज़्म के भीतर किरण आधार के समांतर चलती है — उपयोगी जाँच,
और अक्सर एक स्पष्ट उप-प्रश्न।)*

### Q12 — समान अपवर्तनांक वाले द्रव में डुबोया उत्तल लेंस

अपवर्तनांक n_m के माध्यम में अपवर्तनांक n के लेंस के लिए लेंस निर्माता सूत्र से:

```
      1/f = ( n/n_m − 1 )( 1/R₁ − 1/R₂ )
```

यहाँ n = 1.5 तथा n_m = 1.5, अतः n/n_m = 1 और

```
      1/f = (1 − 1)( 1/R₁ − 1/R₂ ) = 0
⟹     f = ∞
```

**फोकस दूरी अनंत हो जाती है, और लेंस की क्षमता शून्य** — वह लेंस की तरह व्यवहार करना ही बंद कर देता है।

**स्पष्टीकरण।** लेंस अपनी सतहों पर प्रकाश के **अपवर्तन** से कार्य करता है, और अपवर्तन तभी होता है जब सतह के
आर-पार **अपवर्तनांक बदलता** हो। यदि आसपास के द्रव का अपवर्तनांक काँच के **बराबर** हो, तो किसी भी सतह पर
अपवर्तनांक नहीं बदलता, अतः प्रकाश बिना विचलित हुए सीधे निकल जाता है। लेंस प्रकाशिक रूप से **अदृश्य** हो
जाता है।

*(संबंधित, और अक्सर अनुवर्ती प्रश्न: यदि द्रव का अपवर्तनांक काँच से **अधिक** होता, तो n/n_m एक से कम होता,
जिससे 1/f ऋणात्मक हो जाता — अतः **उत्तल लेंस अपसारी लेंस की तरह** व्यवहार करता।)*

### Q13 — प्रकरण अध्ययन: खगोलीय दूरदर्शी

```
      f_o = 150 cm          f_e = 5 cm          D = 25 cm
```

**(i) सामान्य समंजन में आवर्धन क्षमता:**

```
      m = f_o/f_e = 150/5 = 30
```

**m = 30** (प्रतिबिंब उलटा है, अतः चिह्नों के साथ m = −30)।

**(ii) सामान्य समंजन में नली की लंबाई:**

```
      L = f_o + f_e = 150 + 5 = 155 cm
```

**L = 155 cm**

**(iii) निकट बिंदु पर अंतिम प्रतिबिंब होने पर आवर्धन क्षमता:**

```
      m = (f_o/f_e)( 1 + f_e/D )
        = (150/5)( 1 + 5/25 )
        = (30)( 1 + 0.2 )
        = 30 × 1.2
        = 36
```

**m = 36**

*(ध्यान दें कि निकट-बिंदु समंजन सामान्य समंजन से **अधिक** आवर्धन देता है, पर नेत्र पर तनाव की कीमत पर —
इसीलिए सामान्य समंजन, जिसमें प्रतिबिंब अनंत पर और नेत्र शिथिल रहता है, आमतौर पर चुना जाता है।)*

**(iv) अभिदृश्यक का द्वारक बड़ा क्यों होना चाहिए।**

दो कारण:
- **प्रकाश-संग्रहण क्षमता।** बड़ा द्वारक दूर की वस्तु से अधिक प्रकाश एकत्र करता है, अतः धुँधली वस्तुएँ
  (दूर के तारे और आकाशगंगाएँ) देखने योग्य चमकीली हो जाती हैं।
- **विभेदन क्षमता।** बड़ा द्वारक अभिदृश्यक पर विवर्तन घटाता है और अतः दो निकट स्थित वस्तुओं को अलग-अलग
  पहचानने देता है — दूरदर्शी सूक्ष्म विवरण विभेदित कर पाता है।

### Q14 — अवतल लेंस की क्षमता

**अवतल** लेंस के लिए f **ऋणात्मक** होता है: f = −25 cm।

```
      P = 100/f (cm में) = 100/(−25) = −4 D
```

**उत्तर: (b) −4 D**
