हर वर्ग आव्यूह से आप एक संख्या निकाल सकते हैं जो कुछ आवश्यक बात बताती है, और वह संख्या है **सारणिक
(determinant)**। इसका वास्तविक अर्थ यह है — और यह जान लेने पर पूरा अध्याय एक सूत्र में बँध जाता है।

2 × 2 आव्यूह एकांक वर्ग को एक समांतर चतुर्भुज में बदल देता है। सारणिक उस समांतर चतुर्भुज का **क्षेत्रफल**
है। 3 × 3 आव्यूह एकांक घन को एक तिरछे बक्से में बदलता है, और सारणिक उसका **आयतन** है। अतः सारणिक नापता है
कि आव्यूह जगह को कितना खींचता है।

इससे तुरंत वह एक तथ्य समझ आता है जिस पर बाकी सब टिका है: **det A = 0 का अर्थ है कि आव्यूह ने जगह को चपटा
कर दिया।** समांतर चतुर्भुज एक रेखा में सिमट गया, बक्सा एक समतल में। और जो एक बार चपटा हो गया उसे आप
अन-चपटा नहीं कर सकते — सूचना सदा के लिए चली गई। इसीलिए शून्य सारणिक वाले आव्यूह का व्युत्क्रम नहीं होता, और
इसीलिए जिस समीकरण-निकाय का सारणिक शून्य है उसका अद्वितीय हल नहीं होता। यह रटने का नियम नहीं: चपटा होने का
परिणाम है।

व्यावहारिक रूप से आप 3 × 3 सारणिक को किसी पंक्ति या स्तंभ के अनुदिश **सहखंडों (cofactors)** से प्रसारित
करते हैं — प्रत्येक अवयव गुणा वह छोटा 2 × 2 सारणिक जो उसकी पंक्ति और स्तंभ हटाने पर बचता है, और चिह्न
+ − + के शतरंज-प्रतिरूप में बदलते हुए। दो सलाह तुरंत फल देती हैं: उस पंक्ति या स्तंभ के अनुदिश प्रसार
कीजिए जिसमें सबसे अधिक शून्य हों, क्योंकि हर शून्य एक पूरा पद मार देता है; और याद रखिए कि आप किसी पंक्ति का
गुणज दूसरी पंक्ति में जोड़ सकते हैं और मान नहीं बदलेगा — इससे आप आरंभ करने से पहले वे शून्य बना सकते हैं।
जो विद्यार्थी हर बार आँख मूँदकर पहली पंक्ति से प्रसार करते हैं, वे तीन गुना गणित करते हैं और तीन गुना चूक
करते हैं।

**सहखंडज (adjoint)** सहखंडों का आव्यूह है, परिवर्तित; और उसका प्रयोजन यह सर्वसमिका है
A · adj A = |A| I। भाग दीजिए और व्युत्क्रम मिल जाता है: **A⁻¹ = adj A / |A|**, इसीलिए व्युत्क्रम ठीक तब
होता है जब |A| ≠ 0। परिवर्त वाले चरण में इस अध्याय की सबसे आम त्रुटि छिपी है — सहखंड आव्यूह निकालकर उसे
पलटना भूल जाना।

सारणिक तीन शीर्षों से **त्रिभुज का क्षेत्रफल** भी देता है, उनके निर्देशांकों की 3 × 3 सरणी के सारणिक के आधे
के रूप में। और चूँकि शून्य क्षेत्रफल वाला त्रिभुज एक सरल रेखा पर तीन बिंदु है, वही सारणिक शून्य रखकर
**संरेखता (collinearity)** की जाँच बन जाती है। यह बार-बार आने वाला एक-अंकीय प्रश्न है और यहाँ भी क्षेत्रफल
वाली व्याख्या ही काम कर रही है।

अध्याय का प्रतिफल है युगपत् समीकरण हल करना। **क्रेमर नियम** प्रत्येक अज्ञात को सारणिकों के अनुपात के रूप
में देता है, और **आव्यूह विधि** निकाय को AX = B लिखकर X = A⁻¹B के रूप में हल करती है। बोर्ड आव्यूह विधि
को प्रबलता से पसंद करता है — उसका 5-अंकीय प्रश्न आमतौर पर "आव्यूह विधि से ये तीन समीकरण हल कीजिए" होता है,
और वह देखना चाहता है कि |A| निकाला गया, फिर adj A, फिर A⁻¹, फिर गुणन। चारों चरण दिखाइए; अंक उनमें बँटे होते
हैं, इसलिए सही अंतिम उत्तर के साथ छोड़ा गया कार्य कम अंक पाता है।

संगति (consistency) का विश्लेषण एक निर्णय-वृक्ष के रूप में स्पष्ट कर लेना उपयोगी है, क्योंकि यह छोटा है
और अक्सर पूछा जाता है। यदि |A| ≠ 0 तो ठीक एक हल है। यदि |A| = 0, तो (adj A)B देखिए: यदि वह शून्य आव्यूह
नहीं है तो निकाय **असंगत** है — कोई हल नहीं, समतल एक-दूसरे से चूक जाते हैं। यदि वह शून्य है, तो निकाय संगत
है और **अनंत** हल हैं — समतल एक रेखा में मिलते हैं। दो वाक्य, तीन स्थितियाँ, और पूरे अंक।

**5-अंकीय आव्यूह-विधि वाले प्रश्न पर**

1. **पाँचों चरण क्रम में, प्रत्येक को नाम देकर कीजिए।** अंकन योजना मूलतः वही पाँच चरण हैं। जिस
   विद्यार्थी से चरण 3 में गणना की चूक हो जाए, वह भी 5 में से 3 पा लेता है यदि चरण 1, 2, 4 और 5 दिखाई
   दें और सही ढाँचे में हों।

2. **लिखिए "|A| ≠ 0, अतः A⁻¹ का अस्तित्व है और निकाय का अद्वितीय हल है।"** वह वाक्य एक अंक है। उसे
   स्वतःसिद्ध मानकर मत छोड़िए।

3. **नौ सहखंड नामांकित सूची के रूप में लिखिए**, A₁₁ से A₃₃ तक, चिह्न सहित। उन्हें मन ही मन निकालकर
   सीधे आव्यूह में मत डालिए — जिस गणना को परीक्षक देख नहीं सकते उसके आंशिक अंक वे नहीं दे सकते, और आप
   स्वयं भी अपना काम जाँच नहीं पाएँगे।

4. **परिवर्त एक अलग, दृश्य चरण है।** पहले सहखंड आव्यूह लिखिए, फिर "adj A = " लिखकर उसका परिवर्त। हर
   वर्ष विद्यार्थियों का एक बड़ा अंश सहखंड आव्यूह लिखकर उसी को adj A कह देता है। वह भूल आगे फैलती है और
   पूरा प्रश्न ले डूबती है।

5. **सदा सत्यापन कीजिए** — x, y, z को मूल समीकरणों में रखकर — और "सत्यापित" लिखिए या प्रतिस्थापन
   दिखाइए। इसमें 20 सेकंड लगते हैं, अधिकांश चूकें पकड़ी जाती हैं, और उत्तर अच्छा पढ़ा जाता है।

6. **शब्द-प्रश्नों में किसी भी आव्यूह से पहले तीनों समीकरण स्पष्ट नामांकित निकाय के रूप में लिखिए।**
   शब्दों का अनुवाद प्रायः 5 में से 1 अंक है और आव्यूह के काम से अलग अंकित होता है। "पहली और तीसरी
   संख्या जोड़ने पर दूसरी का दुगुना मिलता है" → x + z = 2y → x − 2y + z = 0: वह पुनर्व्यवस्था दिखाइए।

**सारणिकों पर सामान्यतः**

7. **जिस पंक्ति या स्तंभ में सबसे अधिक शून्य हों उसी के सापेक्ष प्रसार कीजिए।** आपने कौन-सा चुना, यह
   लिखिए ("R₂ के सापेक्ष प्रसार")। यदि किसी पंक्ति में दो शून्य हों, तो यह तीन 2 × 2 सारणिकों को एक में
   बदल देता है।

8. **कोष्ठक से पहले प्रत्येक सहखंड का चिह्न स्पष्ट रूप से** +[…] या −[…] के रूप में लिखिए। एकांतर चिह्न
   इस अध्याय की सबसे आम अकेली भूल है, और उसे पहले लिख देना उसे रोक देता है।

9. **क्षेत्रफल के प्रश्नों में: निरपेक्ष मान, और "वर्ग इकाई"।** दोनों अंक हैं। और यदि क्षेत्रफल शून्य
   आए, तो यह कहिए और निष्कर्ष दीजिए कि बिंदु संरेख हैं, केवल "क्षेत्रफल = 0" मत लिखिए।

10. **संरेखता के प्रश्नों में** प्रसार से *पहले* सारणिक को शून्य के बराबर एक प्रदर्शित समीकरण के रूप में
    रखिए। इससे परीक्षक को दिखता है कि आप जानते हैं कि आप क्यों गणना कर रहे हैं।

**गुणधर्म वाले बहुविकल्पीय पर**

11. **दो घातांक याद कीजिए:** |kA| = kⁿ|A| और |adj A| = |A|^(n−1)। 3 × 3 के लिए वे k³ और |A|² हैं। इस
    अध्याय के अधिकांश 1-अंकीय प्रश्न इन्हीं से बनते हैं।

12. **|adj A| में चिह्न पर ध्यान दीजिए।** चूँकि 3 × 3 के लिए घातांक n − 1 = 2 है, उत्तर सदा ऋणेतर
    होता है — ऋणात्मक विकल्प तुरंत हटाया जा सकता है।

13. **2 × 2 सहखंडज का शॉर्टकट:** adj [[a, b], [c, d]] = [[d, −b], [−c, a]]। विकर्ण प्रविष्टियाँ बदल
    दीजिए, शेष दो के चिह्न उलट दीजिए। इसका प्रयोग कीजिए; 2 × 2 के लिए चार सहखंड मत निकालिए।

        | a  b |

### 3 × 3 का सारणिक — किसी पंक्ति या स्तंभ के सापेक्ष प्रसार

```
        | a₁  b₁  c₁ |
|A| =   | a₂  b₂  c₂ |
        | a₃  b₃  c₃ |

    = a₁ (b₂c₃ − b₃c₂)  −  b₁ (a₂c₃ − a₃c₂)  +  c₁ (a₂b₃ − a₃b₂)
```

प्रत्येक कोष्ठक वह 2 × 2 सारणिक है जो अग्रणी अवयव की पंक्ति और स्तंभ हटाने पर बचता है। **चिह्न इस
प्रतिरूप में एकांतर होते हैं**

```
+  −  +
−  +  −
+  −  +
```

आप **किसी भी पंक्ति या स्तंभ** के सापेक्ष प्रसार कर सकते हैं — उत्तर वही रहता है। **जिसमें सबसे अधिक
शून्य हों उसे चुनिए।** यदि किसी पंक्ति में दो शून्य हों, तो वह प्रसार तीन के स्थान पर एक पद का होता है।
यह एक आदत परीक्षा में इस अध्याय की किसी भी अन्य युक्ति से अधिक समय बचाती है।

### उपसारणिक और सहखंड

- **उपसारणिक** M_ij = पंक्ति i और स्तंभ j हटाने पर बचे 2 × 2 आव्यूह का सारणिक
- **सहखंड** A_ij = (−1)^(i+j) · M_ij

अर्थात् सहखंड वही उपसारणिक है, ऊपर की शतरंज-पट्टी वाले चिह्न के साथ। यह भेद महत्त्वपूर्ण है: प्रश्न
विशेष रूप से एक या दूसरा माँगते हैं।

**सहखंड रूप में प्रसार:** |A| = a₁₁A₁₁ + a₁₂A₁₂ + a₁₃A₁₃ (पंक्ति 1 के सापेक्ष), या किसी भी अन्य
पंक्ति/स्तंभ के सापेक्ष।

> **एक परिणाम जो पूछा जाता है:** किसी पंक्ति के अवयवों को **भिन्न** पंक्ति के सहखंडों से गुणा करके
> जोड़ने पर योग **शून्य** होता है। जैसे a₁₁A₂₁ + a₁₂A₂₂ + a₁₃A₂₃ = 0।

### त्रिभुज का क्षेत्रफल

शीर्षों (x₁, y₁), (x₂, y₂), (x₃, y₃) के लिए:

```
                  | x₁  y₁  1 |
क्षेत्रफल = ½ | ·  | x₂  y₂  1 | |         (बाहरी रेखाएँ निरपेक्ष मान हैं)
                  | x₃  y₃  1 |
```

**संरेखता:** तीन बिंदु संरेख हैं ⟺ क्षेत्रफल शून्य है ⟺ वह सारणिक 0 है। "k ज्ञात कीजिए ताकि बिंदु
संरेख हों" इसी तरह पूछा जाता है।

> सदा **निरपेक्ष मान** लीजिए — क्षेत्रफल ऋणात्मक नहीं हो सकता। और इकाई "वर्ग इकाई" लिखिए।

### व्युत्क्रमणीय और अव्युत्क्रमणीय

- **अव्युत्क्रमणीय (singular) आव्यूह:** |A| = 0। इसका व्युत्क्रम **नहीं** होता।
- **व्युत्क्रमणीय (non-singular) आव्यूह:** |A| ≠ 0। इसका व्युत्क्रम होता है।

### सहखंडज

A का **सहखंडज** सहखंडों के आव्यूह का **परिवर्त** है:

```
adj A = [A_ij]ᵀ      अर्थात्      adj A = [ A₁₁  A₂₁  A₃₁ ]
                                          [ A₁₂  A₂₂  A₃₂ ]
                                          [ A₁₃  A₂₃  A₃₃ ]
```

**इस अध्याय में सर्वाधिक अंक परिवर्त वाले चरण पर ही खोए जाते हैं।** नौ सहखंड निकालिए, उन्हें उनके
स्वाभाविक स्थानों पर लिखिए, *फिर परिवर्त लीजिए*।

**मुख्य सर्वसमिका:**

```
A (adj A) = (adj A) A = |A| · I
```

### व्युत्क्रम

```
A⁻¹ = (1/|A|) · adj A          जबकि |A| ≠ 0
```

गुणधर्म:

| परिणाम | कोटि n के आव्यूह के लिए |
| --- | --- |
| \|AB\| = \|A\|\|B\| | |
| \|Aᵀ\| = \|A\| | |
| \|kA\| = kⁿ\|A\| | **3 × 3 के लिए n = 3, अतः \|kA\| = k³\|A\|** |
| \|Aⁿ\| = \|A\|ⁿ | |
| \|A⁻¹\| = 1/\|A\| | |
| \|adj A\| = \|A\|^(n−1) | **3 × 3 के लिए = \|A\|²** |
| adj(AB) = (adj B)(adj A) | क्रम उलटता है, परिवर्त की तरह |
| (AB)⁻¹ = B⁻¹A⁻¹ | क्रम उलटता है |
| (A⁻¹)⁻¹ = A | |
| **विषम** कोटि के विषम सममित आव्यूह का सारणिक | = 0 |

इनमें सबसे अधिक पूछे जाने वाले हैं **|kA| = kⁿ|A|** और **|adj A| = |A|^(n−1)**। घातांक याद कीजिए:
3 × 3 के लिए k³ और |A|²।

### रैखिक समीकरण निकाय हल करना — आव्यूह विधि

निकाय

```
a₁x + b₁y + c₁z = d₁
a₂x + b₂y + c₂z = d₂
a₃x + b₃y + c₃z = d₃
```

को **AX = B** के रूप में लिखिए, जहाँ

```
A = [ a₁  b₁  c₁ ]      X = [ x ]      B = [ d₁ ]
    [ a₂  b₂  c₂ ]          [ y ]          [ d₂ ]
    [ a₃  b₃  c₃ ]          [ z ]          [ d₃ ]
```

यदि |A| ≠ 0, तो **X = A⁻¹B**।

**पाँच-चरणीय प्रक्रिया** — हर बार ठीक इसी क्रम में लिखिए:

1. AX = B लिखिए और A, X, B पहचानिए।
2. **|A|** निकालिए। स्पष्ट कहिए कि वह ≠ 0 है, और निष्कर्ष दीजिए कि निकाय का **अद्वितीय हल** है।
3. **नौ सहखंड** निकालिए।
4. **adj A** लिखिए (सहखंड आव्यूह का परिवर्त), फिर **A⁻¹ = (1/|A|) adj A**।
5. **X = A⁻¹B** निकालकर x, y, z पढ़ लीजिए।

### संगतता

| स्थिति | निष्कर्ष |
| --- | --- |
| \|A\| ≠ 0 | **संगत**, और **अद्वितीय** हल: X = A⁻¹B |
| \|A\| = 0 और (adj A)B ≠ O | **असंगत** — कोई हल नहीं |
| \|A\| = 0 और (adj A)B = O | या तो **अनंत** हल या **कोई** हल नहीं — आगे जाँचना होगा |

**समघात** निकाय (B = O) की विशेष स्थिति में: x = y = z = 0 सदा एक हल है, अतः वह सदा संगत होता है।
यदि |A| ≠ 0 हो तो वही तुच्छ हल एकमात्र है; यदि |A| = 0 हो तो अनंत अतुच्छ हल होते हैं।
