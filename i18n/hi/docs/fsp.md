# भौतिकी (042) — सम्पूर्ण सूत्र-पत्र

वर्तमान पाठ्यक्रम में जो कुछ है, अध्याय दर अध्याय। **विलोपित विषय यहाँ नहीं हैं** — यदि कोई आधा-याद
सूत्र यहाँ न मिले, तो उसे ढूँढ़ने से पहले
[`../docs/00-exam-blueprint.md`](../docs/00-exam-blueprint.md) §3 देख लीजिए; वह सम्भवतः पाठ्यक्रम
से बाहर है।

फ़रवरी की प्रतिदिन बीस मिनट वाली पुनरावृत्ति के लिए इसी का प्रयोग कीजिए, और परीक्षा की सुबह एक बार
पूरा पढ़ लीजिए।

## अध्याय 1 — वैद्युत आवेश तथा क्षेत्र

```
q = ne ;  e = 1.6 × 10⁻¹⁹ C

कूलॉम  : F = k q₁q₂/r²           F_माध्यम = F_निर्वात/K
क्षेत्र   : E = F/q₀ = k q/r²       मात्रक N C⁻¹ = V m⁻¹

द्विध्रुव : p = q(2a), दिशा −q से +q की ओर         मात्रक C m
  अक्षीय    : E = 2kpr/(r² − a²)²      → r >> a :  E = 2kp/r³   (p के अनुदिश)
  निरक्षीय  : E = kp/(r² + a²)^(3/2)   → r >> a :  E = kp/r³    (p के विपरीत)
  अक्षीय = 2 × निरक्षीय ;  द्विध्रुव का क्षेत्र ∝ 1/r³
  बल आघूर्ण τ = pE sin θ = p × E ;  एकसमान क्षेत्र में नेट बल = 0
  τ अधिकतम θ = 90° पर ;  θ = 0° पर स्थायी, 180° पर अस्थायी

फ्लक्स : φ = ∮E·dA = EA cos θ      मात्रक N m² C⁻¹ = V m
गाउस   : φ = q_परिबद्ध/ε₀
  पृष्ठ के आकार और माप से स्वतंत्र; बाहरी आवेशों से नेट फ्लक्स शून्य

  अनन्त सीधा तार       : E = λ/(2πε₀ r)        ∝ 1/r
  अनन्त समतल चादर      : E = σ/(2ε₀)           दूरी से स्वतंत्र
  आवेशित गोलीय कोश     : बाहर E = kq/r² ;  भीतर E = 0 ;  पृष्ठ पर σ/ε₀
  घन के केन्द्र पर आवेश : कुल फ्लक्स q/ε₀ ;  एक फलक से q/6ε₀

चालक (स्थिरवैद्युत साम्य में) : भीतर E = 0 ; आवेश बाहरी पृष्ठ पर ;
  पृष्ठ के ठीक बाहर E पृष्ठ के लम्बवत्, परिमाण σ/ε₀ ; पूरा चालक एक ही विभव पर
```

## अध्याय 2 — स्थिरवैद्युत विभव तथा धारिता

```
V = W/q  (वोल्ट = J C⁻¹) ;  V = kq/r  — यह अदिश है, चिह्न सहित ;  V ∝ 1/r
आवेशों का निकाय : V = Σ kqᵢ/rᵢ                (बीजगणितीय योग)
द्विध्रुव : V = kp cos θ/r² ;  अक्षीय ±kp/r² ;  निरक्षीय V = 0 ;  V ∝ 1/r²
E = −dV/dr ;  प्लेटों के बीच एकसमान क्षेत्र E = V/d

समविभव पृष्ठ : उस पर कोई कार्य नहीं ; हर जगह E उसके लम्बवत् ;
  कभी प्रतिच्छेद नहीं करते ; जहाँ E प्रबल है वहाँ पास-पास ;
  बिन्दु आवेश के लिए गोले, एकसमान क्षेत्र के लिए समान्तर समतल

स्थितिज ऊर्जा
  दो आवेश   : U = k q₁q₂/r                  (चिह्न सहित; ऋणात्मक ⟹ बद्ध)
  तीन आवेश  : U = k[q₁q₂/r₁₂ + q₂q₃/r₂₃ + q₁q₃/r₁₃]
  E में द्विध्रुव : U = −pE cos θ = −p·E ;  θ = 0° पर न्यूनतम −pE (स्थायी)
  घुमाने का कार्य : W = pE(cos θ₁ − cos θ₂)

धारिता  C = Q/V   (फैरड = C V⁻¹)
  समान्तर पट्ट        : C = ε₀A/d ;  परावैद्युत के साथ C = Kε₀A/d
  t मोटाई की पट्टिका  : C = ε₀A/(d − t + t/K)
  श्रेणीक्रम : 1/C = Σ 1/Cᵢ      (C सबसे छोटे से भी छोटा)
  समान्तर   : C = Σ Cᵢ          (C सबसे बड़े से भी बड़ा)
  — प्रतिरोधों से ठीक उलटा

  U = ½CV² = ½QV = Q²/2C ;   ऊर्जा घनत्व u = ½ε₀E²
  परावैद्युत में नेट क्षेत्र : E = E₀/K

परावैद्युत डालने पर
  बैटरी जुड़ी हुई     (V नियत): C ↑K ,  Q ↑K ,  E वही ,  U ↑K
  बैटरी हटी हुई       (Q नियत): C ↑K ,  V ↓K ,  E ↓K   ,  U ↓K

दो संधारित्र जोड़ने पर : V = (C₁V₁ + C₂V₂)/(C₁ + C₂)
  ऊर्जा हानि ΔU = C₁C₂(V₁ − V₂)²/[2(C₁ + C₂)]   सदैव ≥ 0
```

## अध्याय 3 — विद्युत धारा

```
I = q/t = dq/dt  (ऐम्पियर) ;  पारम्परिक धारा इलेक्ट्रॉन अपवाह के विपरीत

v_d = eEτ/m  (~10⁻⁴ m s⁻¹) ;   I = n e A v_d
  R = ml/(ne²Aτ) ;   ρ = m/(ne²τ)
J = I/A = n e v_d = σE   (यह सदिश है) ;  μ = v_d/E = eτ/m ;  σ = neμ = 1/ρ

R = ρl/A ;  तार को n गुना खींचने पर → R हो जाता है n²R
ρ_T = ρ₀[1 + α(T − T₀)]
  धातुएँ: α > 0, ρ बढ़ता है (τ घटता है, n नियत)
  अर्धचालक: α < 0, ρ घटता है (n तेज़ी से बढ़ता है)

सेल : ε = I(R + r) ;  V = ε − Ir (निरावेशन) ;  V = ε + Ir (आवेशन) ;  I = 0 पर V = ε
  सेल का V–I ग्राफ़: अन्तःखण्ड = ε , |ढाल| = r ;  लघुपथ धारा I = ε/r
  श्रेणीक्रम : ε_तुल्य = Σεᵢ ,  r_तुल्य = Σrᵢ
  समान्तर   : ε_तुल्य = (ε₁r₂ + ε₂r₁)/(r₁ + r₂) ,  r_तुल्य = r₁r₂/(r₁ + r₂)

किरचॉफ : सन्धि नियम ΣI = 0  → आवेश संरक्षण
          पाश नियम ΣΔV = 0   → ऊर्जा संरक्षण

व्हीटस्टोन (सन्तुलित, I_g = 0) : P/Q = R/S           — एक शून्य विक्षेप विधि
मीटर सेतु : R = S · l/(100 − l)

P = VI = I²R = V²/R ;  बाह्य R को अधिकतम शक्ति तब जब R = r
1 kWh = 3.6 × 10⁶ J
```

## अध्याय 4 — गतिमान आवेश और चुम्बकत्व

```
बायो–सावर्ट : dB = (μ₀/4π) I dl sin θ/r² ;   सदिश रूप (μ₀/4π) I (dl × r̂)/r²
  वृत्ताकार पाश, अक्ष पर : B = μ₀NIR²/[2(R² + x²)^(3/2)]
  केन्द्र पर              : B = μ₀NI/(2R)
  θ (रेडियन) अन्तरित चाप : B = μ₀Iθ/(4πR)

ऐम्पियर : ∮B·dl = μ₀ I_परिबद्ध
  लम्बा सीधा तार : B = μ₀I/(2πr)   ∝ 1/r, संकेन्द्री वृत्ताकार बल रेखाएँ
  लम्बी परिनालिका : भीतर B = μ₀nI ;  सिरे पर μ₀nI/2 ;  बाहर ≈ 0

गतिमान आवेश : F = q(v × B) = qvB sin θ
  F सदैव v के लम्बवत् ⟹ कोई कार्य नहीं ; चाल और गतिज ऊर्जा अपरिवर्तित
  v ⊥ B : r = mv/(qB) ;  T = 2πm/(qB) ;  f = qB/(2πm)   — T, v से स्वतंत्र
  v और B के बीच कोण हो → कुण्डलिनी (हेलिकल) पथ
  लॉरेंज : F = q(E + v × B) ;  वेग वरणकारी v = E/B

चालक : F = I(l × B) = BIl sin θ            (फ्लेमिंग का वाम-हस्त नियम)

समान्तर तार : F/l = μ₀I₁I₂/(2πd)
  एक ही दिशा → आकर्षण ;  विपरीत → प्रतिकर्षण
  ऐम्पियर की परिभाषा: 1 m दूर रखे, 1 A धारा वाले तारों के बीच 2 × 10⁻⁷ N m⁻¹

धारावाही पाश : m = NIA  (A m²) ;  τ = NIAB sin θ = m × B ;  नेट बल = 0
  τ अधिकतम तब जब कुण्डली का तल B के समान्तर हो

धारामापी : NIAB = kφ ⟹ φ ∝ I ;  त्रिज्य क्षेत्र sin θ = 1 रखता है (एकसमान पैमाना)
  धारा सुग्राहिता I_s = NAB/k
  वोल्टता सुग्राहिता V_s = NAB/(kG) = I_s/G
  → अमीटर    : शंट समान्तर में,  S = I_g G/(I − I_g) ;  आदर्श R = 0, श्रेणी में जुड़ता है
  → वोल्टमीटर : प्रतिरोध श्रेणी में, R = V/I_g − G ;      आदर्श R = ∞, समान्तर में जुड़ता है
```

## अध्याय 5 — चुम्बकत्व एवं द्रव्य

```
बल रेखाएँ: सतत बन्द पाश ; बाहर N→S, भीतर S→N ; कभी प्रतिच्छेद नहीं करतीं
∮B·dA = 0  ⟹  चुम्बकीय एकध्रुव नहीं होते      (तुलना कीजिए ∮E·dA = q/ε₀)

छड़ चुम्बक ≡ परिनालिका :  m = NIA (परिनालिका) ;  m = q_m × 2l (छड़ चुम्बक), भीतर S → N
  चुम्बक काटने पर दो पूरे चुम्बक मिलते हैं — अकेला ध्रुव असम्भव है
  लम्बाई के लम्बवत् काटिए: q_m वही, लम्बाई आधी ⟹ m आधा

क्षेत्र में द्विध्रुव : τ = mB sin θ = m × B ;  एकसमान क्षेत्र में नेट बल = 0
  U = −mB cos θ = −m·B ;  θ = 0° पर स्थायी, 180° पर अस्थायी
  W(θ₁ → θ₂) = mB(cos θ₁ − cos θ₂)

पृथ्वी के चुम्बकीय अवयव : दिक्पात, नमन (δ), क्षैतिज घटक B_H
  B_H = B cos δ        B_V = B sin δ        B_V = B_H tan δ
  tan δ = B_V/B_H      B = √(B_H² + B_V²)
  चुम्बकीय विषुवत्: δ = 0°, B = B_H     चुम्बकीय ध्रुव: δ = 90°, B = B_V
  पृथ्वी का चुम्बकीय दक्षिणी ध्रुव भौगोलिक उत्तर के पास है

पदार्थ (केवल गुणात्मक)
  प्रतिचुम्बकीय — दुर्बल प्रतिकर्षण ; कोई नेट परमाणु आघूर्ण नहीं ; जैसे बिस्मथ, ताँबा
  अनुचुम्बकीय  — दुर्बल आकर्षण ; यादृच्छिक स्थायी आघूर्ण ; ताप पर निर्भर ; जैसे ऐलुमिनियम
  लौहचुम्बकीय  — प्रबल आकर्षण ; डोमेन ; क्यूरी ताप से ऊपर समाप्त ; जैसे लोहा

(χ, μ_r, M, H और शैथिल्य पाठ्यक्रम से बाहर हैं — उत्तर में इनका प्रयोग मत कीजिए)
```

## अध्याय 6 — वैद्युतचुम्बकीय प्रेरण

```
फ्लक्स : φ = BA cos θ  (वेबर = T m²) ;  फ्लक्स ग्रन्थिकता = Nφ
फैराडे : ε = −N dφ/dt ;  I = ε/R
  आवेश q = NΔφ/R      — केवल कुल फ्लक्स परिवर्तन पर निर्भर, लगे समय पर नहीं

लेंज़ : प्रेरित धारा फ्लक्स के परिवर्तन का विरोध करती है
  — फैराडे के नियम का ऋण चिह्न यही है
  — यह ऊर्जा संरक्षण का परिणाम है

गति द्वारा वि.वा.बल : ε = Blv
  I = Blv/R ;  F = B²l²v/R ;  P_यांत्रिक = P_वैद्युत = B²l²v²/R
  एक सिरे के परितः घूमती छड़ : ε = ½Bωl²

भँवर धाराएँ : चालक के भीतर ही प्रेरित पाश
  पटलित (लैमिनेटेड) क्रोड से न्यूनतम होती हैं
  उपयोग: वैद्युतचुम्बकीय ब्रेक, प्रेरण भट्ठी, प्रेरण मोटर, ऊर्जा मीटर

स्वप्रेरकत्व : φ = LI ;  ε = −L dI/dt ;  मात्रक हेनरी
  लम्बी परिनालिका : L = μ₀n²Al = μ₀N²A/l   (क्रोड सहित × μ_r)
  संचित ऊर्जा : U = ½LI²
  L ∝ N² ;  धारा से स्वतंत्र

अन्योन्य प्रेरकत्व : φ₂ = MI₁ ;  ε₂ = −M dI₁/dt ;  M₁₂ = M₂₁ (अन्योन्यता)
  दो समाक्ष परिनालिकाएँ : M = μ₀n₁n₂Al = μ₀N₁N₂A/l
  M = k√(L₁L₂) ;  समाक्ष और पास होने पर अधिकतम ;  अक्ष लम्बवत् होने पर शून्य

प्रत्यावर्ती जनित्र : Nφ = NBA cos ωt  ⟹  ε = NBAω sin ωt = ε₀ sin ωt ,  ε₀ = NBAω
  वि.वा.बल अधिकतम तब जब कुण्डली का तल B के समान्तर हो ;  लम्बवत् होने पर शून्य
  सर्पी वलय (दिक्परिवर्तक नहीं) से प्रत्यावर्ती निर्गत मिलता है
```

## अध्याय 7 — प्रत्यावर्ती धारा

```
i = i₀ sin ωt ;  ω = 2πf
पूरे चक्र का माध्य = 0 ;  आधे चक्र का = 2i₀/π = 0.637 i₀
वर्ग माध्य मूल : i_rms = i₀/√2 = 0.707 i₀ ;  v_rms = v₀/√2
  — वह दिष्ट धारा जो उतनी ही ऊष्मा दे ; प्रत्यावर्ती मीटर rms पढ़ते हैं
  220 V मेन्स → शिखर = 220√2 ≈ 311 V

अकेले अवयव
  R : V और I समान कला में
  L : I, V से π/2 पीछे ;  X_L = ωL = 2πfL      ∝ f    (उच्च f रोकता है, दिष्ट धारा जाने देता है)
  C : I, V से π/2 आगे  ;  X_C = 1/ωC = 1/2πfC ∝ 1/f  (उच्च f जाने देता है, दिष्ट धारा रोकता है)
  स्मरण: C में I आगे ;  L में V आगे
  शुद्ध L या शुद्ध C में औसत शक्ति = शून्य

श्रेणी LCR (कला सदिश)
  Z = √(R² + (X_L − X_C)²)      tan φ = (X_L − X_C)/R      cos φ = R/Z
  X_L > X_C → प्रेरणिक, V आगे ;  X_L < X_C → धारितीय, V पीछे

अनुनाद : X_L = X_C
```

```
बंधन ऊर्जा  BE = Δm c² ;   BE(MeV) = Δm(u) × 931.5
BE/A : जितना बड़ा, उतना अधिक स्थायी

BE/A वक्र : A ≈ 20 तक तेज़ी से चढ़कर ~8 MeV ; 30 < A < 170 में लगभग नियत 8 MeV ;
  शिखर ≈ 8.8 MeV, A = 56 पर (Fe — सर्वाधिक स्थायी) ; A = 238 पर घटकर ≈ 7.6 MeV
  निष्कर्ष: (क) नाभिकीय बल अल्प परास का और संतृप्त है
            (ख) भारी नाभिकों के विखण्डन से ऊर्जा मिलती है
            (ग) हल्के नाभिकों के संलयन से ऊर्जा मिलती है
  — दोनों ही स्थितियों में उत्पादों का BE/A अधिक होता है, अर्थात् वे A ≈ 56 के पास आते हैं

विखण्डन : ²³⁵U + n → ¹⁴¹Ba + ⁹²Kr + 3n + ~200 MeV  (~0.9 MeV प्रति न्यूक्लिऑन)
  2–3 न्यूट्रॉन निकलते हैं ⟹ शृंखला अभिक्रिया सम्भव है
संलयन  : ²H + ³H → ⁴He + n + 17.6 MeV ;  4 ¹H → ⁴He + 26.7 MeV (सूर्य)
  कूलॉम अवरोध पार करने के लिए ~10⁷ K चाहिए — इसीलिए "तापनाभिकीय"
  संलयन से प्रति न्यूक्लिऑन अधिक ऊर्जा ; विखण्डन से प्रति अभिक्रिया अधिक

Q = (अभिकारकों का द्रव्यमान − उत्पादों का द्रव्यमान) c² ;   Q > 0 ⟹ ऊर्जा मुक्त
हर नाभिकीय अभिक्रिया में Z और A संरक्षित रहते हैं

(रेडियोऐक्टिवता, क्षय नियम, अर्ध आयु और औसत आयु पाठ्यक्रम से बाहर हैं)
```

## अध्याय 14 — अर्धचालक इलेक्ट्रॉनिकी

```
ऊर्जा बैण्ड  (E_g = संयोजी और चालन बैण्डों के बीच वर्जित अन्तराल)
  चालक     : E_g = 0, बैण्ड अतिव्यापी ;  ताप बढ़ने पर चालकता घटती है
  अर्धचालक : E_g ≈ 1 eV (Si 1.1 , Ge 0.7) ;  ताप बढ़ने पर चालकता बढ़ती है
  विद्युतरोधी : E_g > 3 eV (हीरा ≈ 6 eV)

नैज : शुद्ध ;  n_e = n_h = n_i ;  चालन इलेक्ट्रॉन और होल दोनों से
  युग्म ऊष्मीय रूप से बनते हैं ;  ताप के साथ n_i तेज़ी से बढ़ता है ;  0 K पर पूर्ण विद्युतरोधी

अपद्रव्यी (अपमिश्रण ≈ 10⁶ मूल परमाणुओं पर 1 अशुद्धि परमाणु)
  n-प्रकार : पंचसंयोजी अपमिश्रक (P, As, Sb, Bi) = दाता
             बहुसंख्यक इलेक्ट्रॉन, अल्पसंख्यक होल ;  n_e >> n_h
  p-प्रकार : त्रिसंयोजी अपमिश्रक (B, Al, In, Ga) = ग्राही
             बहुसंख्यक होल, अल्पसंख्यक इलेक्ट्रॉन ;  n_h >> n_e
  दोनों वैद्युत रूप से उदासीन हैं       n_e n_h = n_i²

p-n संधि
  बहुसंख्यक वाहकों का विसरण → अचल आयन खुल जाते हैं → ह्रासी क्षेत्र
    (p-ओर ऋणात्मक ग्राही आयन, n-ओर धनात्मक दाता आयन)
  आन्तरिक क्षेत्र n → p ;  अवरोध विभव V_B ≈ 0.3 V (Ge) , 0.7 V (Si)
  साम्य में: विसरण धारा = अपवाह धारा, नेट धारा शून्य

अग्र अभिनति (p धन से) : अवरोध घटे , ह्रासी चौड़ाई घटे , धारा बड़ी (mA) ,
  बहुसंख्यक वाहक , प्रतिरोध कम ;  घुटना वोल्टता 0.3 V Ge / 0.7 V Si
पश्च अभिनति (p ऋण से) : अवरोध बढ़े , ह्रासी चौड़ाई बढ़े , धारा नगण्य (µA) ,
  अल्पसंख्यक वाहक , प्रतिरोध अधिक
  पश्च संतृप्त धारा वोल्टता से लगभग स्वतंत्र है (ऊष्मीय रूप से बने अल्पसंख्यक वाहकों
  की संख्या से सीमित) पर ताप बढ़ने पर बढ़ती है ;
  बड़ी पश्च वोल्टता पर भंजन

I–V अभिलक्षण : अरैखिक ⟹ डायोड अनओमीय है
  धारा अक्ष पर अग्र के लिए mA और पश्च के लिए µA लिखिए

दिष्टकारी : प्रत्यावर्ती → एकदिश धारा (डायोड केवल एक ही दिशा में चालन करता है)

  पूर्ण तरंग : 2 डायोड + मध्य-निष्कासित ट्रांसफ़ॉर्मर ; दोनों अर्ध चक्र ;
              निर्गत आवृत्ति = 2 × निवेश ; दक्षता ≈ 81.2% ; तरंगिका कम
  लोड के समान्तर लगा संधारित्र फ़िल्टर का काम करता है, तरंगिका को चिकना करता है

(ज़ेनर डायोड, LED, प्रकाश डायोड, सौर सेल, ट्रांज़िस्टर और लॉजिक गेट बाहर हैं)
```

## अन्तिम पृष्ठ की जाँच-सूची, परीक्षा भवन के लिए

उत्तर पुस्तिका जमा करने से पहले :

1. **हर आंकिक उत्तर पर मात्रक।** N, C, V, A, Ω, T, F, H, W, J, eV, m, Hz.
2. **हर ग्राफ़ में दोनों अक्ष नामांकित**, राशि **और** मात्रक सहित — और डायोड के I–V में
   **अग्र के लिए mA, पश्च के लिए µA**।
3. **हर किरण आरेख में तीर के सिरे**, कम से कम दो किरणें, और F, 2F, O (दर्पण में C भी) अंकित।
4. **हर परिपथ आरेख नामांकित** — और पूर्ण तरंग दिष्टकारी का ट्रांसफ़ॉर्मर
   **मध्य-निष्कासित**।
5. **कला सदिश आरेख बनाया हुआ**, किसी भी LCR प्रश्न में, चाहे माँगा गया हो या नहीं।
6. **हर प्रकाशिकी आंकिक में चिह्न परिपाटी जाँची हुई**: u ऋणात्मक, अवतल दर्पण का f ऋणात्मक,
   अवतल लेंस का f ऋणात्मक।
7. **हर प्रत्यावर्ती धारा शक्ति गणना में cos φ शामिल।**
8. **आन्तरिक विकल्प में छोड़े गए प्रयास काटे हुए।**
9. **प्रश्न संख्याएँ प्रश्नपत्र से मेल खाती हुईं।**
10. **"अन्तर बताइए" के उत्तर दो-स्तम्भ सारणी में**, हर पंक्ति में एक ही गुण की तुलना करते हुए।
