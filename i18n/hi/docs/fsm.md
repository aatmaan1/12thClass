## अध्याय 1 — सम्बन्ध एवं फलन

```
स्वतुल्य (Reflexive)   : हर a ∈ A के लिए (a, a) ∈ R
सममित (Symmetric)     : (a, b) ∈ R ⟹ (b, a) ∈ R
संक्रामक (Transitive)  : (a, b), (b, c) ∈ R ⟹ (a, c) ∈ R
तुल्यता (Equivalence)  : तीनों एक साथ

एकैकी (one-one)  : f(x₁) = f(x₂) ⟹ x₁ = x₂    [या f′ का चिह्न पूरे अन्तराल में एक ही]
आच्छादक (onto)   : परिसर = सहप्रान्त
एकैकी-आच्छादी    : दोनों

तुल्यता वर्ग  [a] = { x ∈ A : (a, x) ∈ R };  ये वर्ग A का विभाजन करते हैं

|A| = m, |B| = n :
  A→B सम्बन्ध      = 2^(mn)          A पर सम्बन्ध (|A| = n) = 2^(n²)
  A पर स्वतुल्य     = 2^(n² − n)      A पर सममित             = 2^(n(n+1)/2)
  A→B फलन         = n^m             A→B एकैकी (m ≤ n)      = n!/(n − m)!
  A→A एकैकी-आच्छादी = n!
```

## अध्याय 3 — आव्यूह

```
कोटि m × n → mn अवयव ;  a_ij = पंक्ति i, स्तम्भ j

AB तभी परिभाषित जब स्तम्भ(A) = पंक्ति(B) ;  A(m×n) B(n×p) = AB(m×p)

(A′)′ = A      (kA)′ = kA′      (A + B)′ = A′ + B′      (AB)′ = B′A′

सममित        : A′ = A
विषम सममित   : A′ = −A  ⟹  सभी विकर्ण अवयव = 0  ⟹  ट्रेस = 0
A = ½(A + A′) + ½(A − A′)                [सममित + विषम सममित]

A + A′, AA′, A′A सममित हैं ;  A − A′ विषम सममित है
A, B सममित ⟹ AB + BA सममित, AB − BA विषम सममित

सामान्यतः AB ≠ BA ;  AB = O से यह नहीं निकलता कि A = O या B = O
(A + B)² = A² + AB + BA + B²             [A² + 2AB + B² नहीं]

2 × 2 के लिए :  A² − (ट्रेस A)·A + (det A)·I = O
```

## अध्याय 7 — समाकलन

```
मानक समाकल
  ∫ xⁿ dx = x^(n+1)/(n+1) + C   (n ≠ −1)      ∫ dx/x = log|x| + C
  ∫ eˣ dx = eˣ + C                            ∫ aˣ dx = aˣ/log a + C

  ∫ sin x dx = −cos x + C                     ∫ cos x dx = sin x + C
  ∫ sec²x dx = tan x + C                      ∫ cosec²x dx = −cot x + C
  ∫ sec x tan x dx = sec x + C                ∫ cosec x cot x dx = −cosec x + C
  ∫ tan x dx = log|sec x| + C                 ∫ cot x dx = log|sin x| + C
  ∫ sec x dx = log|sec x + tan x| + C         ∫ cosec x dx = log|cosec x − cot x| + C
  ∫ dx/√(1 − x²) = sin⁻¹x + C                 ∫ dx/(1 + x²) = tan⁻¹x + C

नौ विशेष रूप
  ∫ dx/(x² − a²)  = (1/2a) log|(x − a)/(x + a)| + C
  ∫ dx/(a² − x²)  = (1/2a) log|(a + x)/(a − x)| + C
  ∫ dx/(x² + a²)  = (1/a) tan⁻¹(x/a) + C

  ∫ dx/√(x² − a²) = log|x + √(x² − a²)| + C
  ∫ dx/√(x² + a²) = log|x + √(x² + a²)| + C
  ∫ dx/√(a² − x²) = sin⁻¹(x/a) + C

  ∫ √(a² − x²) dx = (x/2)√(a² − x²) + (a²/2) sin⁻¹(x/a) + C
  ∫ √(x² + a²) dx = (x/2)√(x² + a²) + (a²/2) log|x + √(x² + a²)| + C
  ∫ √(x² − a²) dx = (x/2)√(x² − a²) − (a²/2) log|x + √(x² − a²)| + C     ← ऋण चिह्न

खण्डशः समाकलन
  ∫ u v dx = u ∫v dx − ∫ (du/dx)(∫v dx) dx
  ILATE : प्रतिलोम, लघुगणकीय, बीजीय, त्रिकोणमितीय, चरघातांकी   (u = जो पहले आए)
  ∫ log x dx = x log x − x + C
  ∫ eˣ [ f(x) + f′(x) ] dx = eˣ f(x) + C

आंशिक भिन्न (अंश की घात < हर की घात; अन्यथा पहले भाग दीजिए)
  (x−a)(x−b)                → A/(x−a) + B/(x−b)
  (x−a)²                    → A/(x−a) + B/(x−a)²
  (x−a)(x−b)(x−c)           → A/(x−a) + B/(x−b) + C/(x−c)
  (x−a)²(x−b)               → A/(x−a) + B/(x−a)² + C/(x−b)
  (x−a)(x²+bx+c) अखण्डनीय   → A/(x−a) + (Bx + C)/(x²+bx+c)

त्रिकोणमितीय सरलीकरण
  sin²x = (1 − cos 2x)/2        cos²x = (1 + cos 2x)/2
  sin 2x = 2 sin x cos x        cos 2x = 1 − 2sin²x = 2cos²x − 1
  2 sin A cos B = sin(A+B) + sin(A−B)
  2 cos A cos B = cos(A+B) + cos(A−B)
  2 sin A sin B = cos(A−B) − cos(A+B)

निश्चित समाकल के गुणधर्म
  ∫[a,b] f = −∫[b,a] f  ;  ∫[a,a] f = 0
  ∫[a,b] f = ∫[a,c] f + ∫[c,b] f
  ∫[a,b] f(x)dx = ∫[a,b] f(a + b − x)dx
  ∫[0,a] f(x)dx = ∫[0,a] f(a − x)dx                        ← सबसे काम आने वाला
  ∫[0,2a] f = ∫[0,a] f(x)dx + ∫[0,a] f(2a − x)dx
  ∫[0,2a] f = 2∫[0,a] f  यदि f(2a − x) = f(x) ;  = 0 यदि f(2a − x) = −f(x)
  ∫[−a,a] f = 2∫[0,a] f  यदि f सम ;  = 0 यदि f विषम

  निश्चित समाकल में + C नहीं।  प्रतिस्थापन करते समय सीमाएँ भी बदलिए।
```

## अध्याय 9 — अवकल समीकरण

```
कोटि (ORDER)  = उच्चतम अवकलज की कोटि
घात  (DEGREE) = करणी और भिन्न हटाने के बाद उच्चतम कोटि के अवकलज की घात
                यदि समीकरण अपने अवकलजों में बहुपद न हो तो घात परिभाषित नहीं
                (जैसे sin(dy/dx), log(dy/dx), e^(dy/dx) हों)

चर पृथक्करणीय : f(y)dy = g(x)dx  → दोनों पक्षों का समाकलन, एक ही +C

समघातीय : dy/dx = F(y/x)
  y = vx  और  dy/dx = v + x dv/dx रखिए     ← "+v" अनिवार्य है
  v और x में पृथक कीजिए, समाकलन कीजिए, फिर v = y/x वापस रखिए
  (यदि स्वाभाविक रूप से dx/dy = F(x/y) हो, तो x = vy रखिए)

रैखिक : dy/dx + P(x)y = Q(x)
  समाकलन गुणक (I.F.) = e^(∫P dx)
  y · (I.F.) = ∫ Q · (I.F.) dx + C          ← Q को I.F. से गुणा

  y-रूप : dx/dy + P(y)x = Q(y),  I.F. = e^(∫P dy),  x·(I.F.) = ∫Q·(I.F.)dy + C

I.F. की लघु विधियाँ
  P = k      → e^(kx)        P = 1/x   → x         P = n/x   → xⁿ
  P = −1/x   → 1/x           P = tan x → sec x     P = cot x → sin x
  P = −tan x → cos x

वृद्धि/क्षय : dN/dt = kN  →  N = N₀ e^(kt)
```

```
  a·b = |a||b| cos θ = a₁b₁ + a₂b₂ + a₃b₃           a·a = |a|²
  cos θ = a·b / (|a||b|)
  लम्बवत् ⟺ a·b = 0
  b पर a का प्रक्षेप = a·b/|b|                       (यह अदिश है, ऋणात्मक हो सकता है)
  b पर a का सदिश प्रक्षेप = [ (a·b)/|b|² ] b
  î·î = ĵ·ĵ = k̂·k̂ = 1 ;  î·ĵ = ĵ·k̂ = k̂·î = 0

सदिश (CROSS) गुणनफल
  a × b = सारणिक जिसकी पंक्तियाँ  î ĵ k̂ / a₁ a₂ a₃ / b₁ b₂ b₃
        = î(a₂b₃ − a₃b₂) − ĵ(a₁b₃ − a₃b₁) + k̂(a₁b₂ − a₂b₁)    ← बीच का पद ऋणात्मक
  |a × b| = |a||b| sin θ           a × b = −(b × a)          a × a = 0
  समान्तर ⟺ a × b = 0
  î×ĵ = k̂,  ĵ×k̂ = î,  k̂×î = ĵ

  समान्तर चतुर्भुज का क्षेत्रफल (संलग्न भुजाएँ a, b) = |a × b|
  समान्तर चतुर्भुज का क्षेत्रफल (विकर्ण d₁, d₂)      = ½ |d₁ × d₂|
  त्रिभुज का क्षेत्रफल (दो भुजाएँ a, b)               = ½ |a × b|
  a और b दोनों पर लम्ब एकक सदिश                     = (a × b)/|a × b|

|a × b|² + (a·b)² = |a|² |b|²
|a + b| = |a − b|  ⟺  a ⊥ b
a, b, c एकक सदिश और a + b + c = 0  ⟹  a·b + b·c + c·a = −3/2
```

## अध्याय 11 — त्रिविमीय ज्यामिति (केवल रेखाएँ)

```
AB की दिक्-अनुपात = (x₂ − x₁, y₂ − y₁, z₂ − z₁) ;  दिक्-कोसाइन के लिए |AB| से भाग दीजिए

बिन्दु A(a) से होकर दिशा b वाली रेखा :
  सदिश रूप   : r = a + λb
  कार्तीय रूप : (x − x₁)/a₁ = (y − y₁)/a₂ = (z − z₁)/a₃
  व्यापक बिन्दु : (a₁λ + x₁, a₂λ + y₁, a₃λ + z₁)

A(a) और B(b) से होकर जाने वाली रेखा : r = a + λ(b − a)
  कार्तीय रूप : (x − x₁)/(x₂ − x₁) = (y − y₁)/(y₂ − y₁) = (z − z₁)/(z₂ − z₁)

दो रेखाओं के बीच कोण : cos θ = |b₁·b₂| / (|b₁||b₂|)          ← निरपेक्ष मान
  लम्बवत् : a₁a₂ + b₁b₂ + c₁c₂ = 0
  समान्तर  : a₁/a₂ = b₁/b₂ = c₁/c₂

विषमतलीय रेखाएँ : न समान्तर, न प्रतिच्छेदी

न्यूनतम दूरी
  विषमतलीय : d = | (b₁ × b₂) · (a₂ − a₁) | / | b₁ × b₂ |
  समान्तर   : d = | b × (a₂ − a₁) | / | b |
  d = 0 ⟹ रेखाएँ प्रतिच्छेद करती हैं

P से लम्ब पाद : व्यापक बिन्दु Q(λ) → PQ·b = 0 → λ निकालिए → Q
रेखा में P का प्रतिबिम्ब : P′ = 2Q − P

दिक्-अनुपात पढ़ने से पहले इतना सामान्यीकृत कीजिए कि हर कोष्ठक में x, y, z का गुणांक 1 हो :
  (2y − 1)/4 = (y − ½)/2
```

## अध्याय 12 — रैखिक प्रोग्रामन

```
Z = ax + by  (उद्देश्य फलन) ;  असमिकाएँ ही अवरोध हैं

कोणीय बिन्दु विधि
  1. सभी अवरोध, x ≥ 0, y ≥ 0 सहित
  2. सीमा रेखाएँ और उनके अन्तःखण्ड
  3. ग्राफ़ पेपर पर आलेख, पैमाना लिखा हुआ, रेखाएँ नामांकित
  4. सुसंगत क्षेत्र छायांकित कीजिए (हर असमिका में मूल बिन्दु की जाँच कीजिए)
  5. कोणीय बिन्दु युगपत् समीकरण हल करके निकालिए — ग्राफ़ से पढ़कर नहीं
  6. हर कोणीय बिन्दु पर Z की सारणी
  7. इष्टतम मान लिखिए : मान, बिन्दु, और उच्चिष्ठ/निम्निष्ठ

परिबद्ध क्षेत्र   → उच्चिष्ठ और निम्निष्ठ दोनों होंगे, कोणीय बिन्दुओं पर
अपरिबद्ध क्षेत्र → हो भी सकता है और नहीं भी; जाँचिए :
  M उच्चिष्ठ है ⟺ ax + by > M का सुसंगत क्षेत्र से कोई उभयनिष्ठ बिन्दु नहीं
  m निम्निष्ठ है ⟺ ax + by < m का सुसंगत क्षेत्र से कोई उभयनिष्ठ बिन्दु नहीं

दो कोणीय बिन्दुओं पर Z समान → अनन्त इष्टतम हल, उस पूरे रेखाखण्ड पर
परस्पर विरोधी अवरोध          → रिक्त सुसंगत क्षेत्र → कोई सुसंगत हल नहीं
```

## अध्याय 13 — प्रायिकता

```
सप्रतिबन्ध : P(A|B) = P(A ∩ B)/P(B),  P(B) ≠ 0        ← "दिया है" वाला हर में जाता है
  P(A′|B) = 1 − P(A|B)
  P((A ∪ C)|B) = P(A|B) + P(C|B) − P((A ∩ C)|B)

गुणन नियम : P(A ∩ B) = P(A)P(B|A) = P(B)P(A|B)
  P(A ∩ B ∩ C) = P(A) P(B|A) P(C|A ∩ B)               ← "बिना प्रतिस्थापन"

स्वतंत्र : P(A ∩ B) = P(A)P(B)  ⟺  P(A|B) = P(A)
  P(A ∪ B) = P(A) + P(B) − P(A)P(B)
  P(कोई नहीं) = (1 − P(A))(1 − P(B))
  P(कम से कम एक) = 1 − P(कोई नहीं)
  स्वतंत्र ≠ परस्पर अपवर्जी
  अशून्य प्रायिकता वाली परस्पर अपवर्जी घटनाएँ ⟹ स्वतंत्र नहीं

योग नियम : P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

पूर्ण प्रायिकता : P(A) = Σᵢ P(Eᵢ) P(A|Eᵢ)          (E₁…Eₙ एक विभाजन)

बेज़ प्रमेय : P(Eᵢ|A) = P(Eᵢ)P(A|Eᵢ) / Σⱼ P(Eⱼ)P(A|Eⱼ)
  क्रम : घटनाएँ परिभाषित कीजिए → सभी पूर्व प्रायिकताएँ → सभी सम्भावनाएँ → सूत्र → प्रतिस्थापन
  P(Eᵢ) पूर्व प्रायिकताएँ हैं ; P(Eᵢ|A) उत्तर प्रायिकताएँ हैं

यादृच्छिक चर
  Σ pᵢ = 1  और  pᵢ ≥ 0                               ← अज्ञात अचर इसी से निकालिए
  माध्य = E(X) = Σ xᵢ pᵢ
  (प्रसरण और द्विपद बंटन पाठ्यक्रम से बाहर हैं)
```
